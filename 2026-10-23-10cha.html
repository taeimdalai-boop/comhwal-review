사용자 인터페이스

1GUI(그래픽 사용자 인터페이스)는 명령어를 입력하는 대신 아이콘이나 메뉴 같은 그래픽 요소를 주로 마우스로 선택해 조작하는 방식입니다. 윈도우는 GUI를 사용합니다

3NUI는 몸동작 등 자연스러운 방식으로 조작하는 인터페이스입니다
필기 · 윈도우 10

윈도우 10의 특징

1선점형 멀티태스킹 — 운영체제가 실행 중인 프로세스로부터 CPU 제어권을 회수해 다른 프로세스에 배정할 수 있는 방식입니다
2멀티태스킹 — 전화를 받으면서 인터넷을 쓰는 것처럼 여러 작업을 동시에 수행하는 기능입니다

4OLE — 한 프로그램에서 만든 개체(예: 엑셀 차트)를 다른 프로그램(워드·파워포인트)에 연결하거나 포함하는 기능입니다

파일 이름 규칙

1윈도우 파일 이름은 최대 255자까지 지원하고, 공백과 한글을 쓸 수 있습니다
2사용할 수 없는 문자: \ / : * ? " < > |
3수업에서는 \ · / · : · * · ?를 짚었고, 따옴표·부등호·세로 막대도 같은 목록에 들어갑니다
필기 · 파일 시스템

FAT와 NTFS · exFAT

1FAT16 — 파티션 용량이 약 2GB로 제한되어 지금은 쓰기 어렵습니다
2FAT32 — 파일 하나의 크기가 약 4GB 미만이어야 합니다. 10GB짜리 영상 파일은 FAT32 USB에 저장되지 않습니다
3NTFS — 최근 윈도우가 기본으로 쓰는 방식입니다. 파일·폴더별 접근 권한, 암호화, 압축 같은 기능을 지원합니다. 다른 운영체제에서는 제약이 있을 수 있습니다
4exFAT — 대용량 파일을 지원하고 윈도우·맥, exFAT을 지원하는 안드로이드 기기 등 여러 환경에서 USB를 함께 쓸 때 적합합니다

삽입 모드와 수정 모드

1한글처럼 두 모드를 지원하는 편집 프로그램에서는 Insert 키를 누를 때마다 삽입 모드와 수정 모드가 번갈아 바뀝니다 (수업에서는 한글로 실습했고, 상태 표시줄에 «삽입», «수정»이 표시됩니다)
2수정 모드에서는 입력한 글자가 기존 글자를 대체하며 지웁니다. 스페이스바도 커서 오른쪽 글자를 지우고 공백으로 바꿉니다
3Insert 키를 한 번 더 누르면 삽입 모드로 돌아옵니다
필기 · 기능 키

F2 · F3 · F4 · F5

1F2 — 선택한 파일·폴더의 이름 바꾸기. 엑셀에서는 선택한 셀의 편집 상태로 들어갑니다

필기 · 바로가기

바로가기 아이콘

1바로가기 아이콘은 실제 프로그램·폴더가 아니라 원본을 가리키는 연결 정보(경로 등)를 가진 아이콘입니다. 아이콘 왼쪽 아래에 화살표가 있고 확장자는 .lnk입니다
2파일을 선택하고 Ctrl+Shift를 누른 채 드래그하면 바로가기가 만들어집니다. 같은 원본으로 여러 개 만들 수 있고, 같은 폴더 안에서는 이름이 달라야 합니다
3바로가기를 삭제해도 원본에는 영향이 없습니다. 반대로 원본을 지우거나 연결된 위치를 찾을 수 없는 곳으로 옮기면 링크가 끊어질 수 있습니다
4Ctrl을 누르고 드래그하면 복사, Shift를 누르고 드래그하면 이동입니다
필기 · 에어로

에어로 피크 · 스냅 · 셰이크

1에어로 피크 — 미리 보기. 작업 표시줄 아이콘에 마우스를 올리면 실행 중인 창이 작게 보이고, Win+,(쉼표)를 누르고 있는 동안 바탕 화면이 잠깐 보입니다
2에어로 스냅 — 창을 화면 한쪽에 정렬합니다. Win+방향키(←, →)로 창을 왼쪽·오른쪽에 붙입니다
3에어로 셰이크 — 창 하나를 잡고 흔들면 나머지 창이 최소화되고, 다시 흔들면 돌아옵니다
필기 · 작업 표시줄

작업 표시줄 설정

1작업 표시줄에서 마우스 오른쪽 버튼 › 작업 표시줄 설정을 누르면 설정 창의 개인 설정 › 작업 표시줄로 들어갑니다
2작업 표시줄 잠금을 켜면 마우스로 끌어 작업 표시줄을 옮기거나 크기를 바꾸는 것을 막습니다
3자동으로 숨기기는 화면이 작은 노트북에서 작업 공간을 넓힐 때 씁니다. 위치는 아래쪽 외에 왼쪽·오른쪽·위쪽도 가능합니다
4작업 표시줄 단추 하나로 표시(항상 하나로 묶고 레이블 숨기기)는 같은 앱에서 연 여러 문서를 하나의 단추로 묶어 보여 주는 설정입니다
5모니터를 여러 대 쓰면 모든 디스플레이에 작업 표시줄을 표시할지 정할 수 있습니다
필기 · 작업 표시줄

창 배열과 터치 키보드

1우클릭 메뉴의 창 계단식 배열 · 창 가로 정렬 보기 · 창 세로 정렬 보기는 열려 있는 창을 배열합니다. «아이콘 정렬»이 아닙니다
2터치 키보드 단추 표시 — 작업 표시줄에 키보드 단추가 생기고, 물리 키보드가 고장 났을 때 마우스로 문자를 입력할 수 있습니다
3그 밖에 작업 보기 단추 표시, 연락처 표시, 작업 표시줄 잠금 같은 항목도 이 우클릭 메뉴에 있습니다
필기 · 문제 정리

작업 표시줄 보기, 이렇게 가려냅니다

보기판단이유
우클릭 메뉴에서 개인 설정 선택✕개인 설정은 설정 창에서 합니다
아이콘 형식·자동 정렬✕바탕 화면·탐색기에서 하는 일입니다
절전·전원 관리✕설정 › 시스템에서 합니다
터치 키보드 단추 표시○우클릭 메뉴에 있습니다
작업 표시줄 위치 · 단추 묶기○작업 표시줄 설정에 있습니다
모든 디스플레이에 표시○작업 표시줄 설정에 있습니다

2자주 쓰는 앱은 작업 표시줄에 직접 끌어다 놓아 고정할 수 있지만, 설정 메뉴에 그 옵션이 있는 것은 아닙니다
필기 · 점프 목록

점프 목록 사용

1점프 목록을 지원하는 앱의 작업 표시줄 아이콘을 마우스 오른쪽 버튼으로 누르면 앱과 설정에 따라 최근에 연 문서·자주 쓴 항목 등이 나열됩니다. 이 목록이 점프 목록입니다
2자주 쓰는 항목은 옆의 압정을 눌러 목록에 고정합니다
3고정을 해제하려면 압정을 다시 눌러 뺍니다. Delete 키를 누르는 방식이 아닙니다
실기 · IF

조건 · 참 · 거짓으로
나눠서 읽습니다

문제수식 (B 판매량 · C 목표량 · D 지점)
달성 여부=IF(B2>=C2,"달성","미달")
초과분=IF(B2>C2,B2-C2,0)
본사 · 지사=IF(D2="서울","본사","지사")
1«이상»은 같음을 포함하므로 >=, «초과»는 같음을 포함하지 않으므로 >입니다. 비교 연산자 하나가 틀려도 그 문제는 오답이 됩니다
2초과분 예) 목표 100개에 판매 120개면 20, 목표 120개에 판매 132개면 12, 목표를 넘지 못한 85개는 0으로 표시합니다
3문자와 비교할 때는 "서울"처럼 따옴표를 붙입니다
실기 · 중첩 IF

AVERAGE를 IF 안에 넣고
높은 기준부터 묻습니다

1평균을 먼저 구해 따로 쓰지 않고 AVERAGE(범위)를 IF의 조건식 안에 중첩합니다
290 · 80 · 70점 순서로 높은 기준부터 묻습니다. 결과가 4개(A·B·C·D)이고 마지막 결과를 거짓 값으로 처리하면 IF는 3개입니다
3학생별 수식을 채우기 핸들로 내릴 것이므로 개인 점수 범위(B2:C2)는 절대 참조로 고정하지 않습니다
4중첩 수식은 반복되는 부분(쉼표까지)을 복사해 붙인 뒤 기준값과 결과 문자만 수정하면 빠릅니다. 마지막 거짓 값 뒤에는 중첩한 IF 개수만큼 닫는 괄호를 붙입니다
복습 · IFS

그 밖의 경우는
TRUE로 받습니다

1IFS(조건1,값1,조건2,값2,…)에는 IF 같은 마지막 거짓 자리가 없습니다
2«그 밖에는 F»를 처리하려면 마지막 조건 자리에 TRUE를 넣습니다
3마지막 TRUE 조건이 없고 어느 조건도 참이 아니면 #N/A 오류가 납니다
실기 · IF · MOD

홀수는 1조,
짝수는 2조

1MOD(번호,2)는 번호를 2로 나눈 나머지입니다. 1이면 홀수, 0이면 짝수입니다
2MOD의 결과가 0 또는 1이라 =1 비교를 생략해도 조건으로 쓸 수 있습니다. 이해를 위해서는 =1까지 적어 보는 편이 좋습니다
실기 · IFERROR

오류 날 수식을
IFERROR로 감쌉니다

1VLOOKUP의 기준표는 단일 셀이 아니라 표 전체를 선택하고, 채우기 핸들을 쓸 때는 절대 참조합니다. 과정명은 표의 두 번째 열이라 열 번호는 2이고, 코드와 정확히 일치하는 항목을 찾아야 하므로 FALSE를 씁니다
2기준표에 없는 Z 같은 코드는 #N/A 오류가 납니다
3완성한 VLOOKUP을 IFERROR의 첫 번째 인수에 넣고, 오류일 때 표시할 "미등록"을 두 번째 인수로 적습니다
4VLOOKUP · HLOOKUP · MATCH · SEARCH · FIND는 첫 번째 인수가 찾을 값입니다. 순서를 바꾸지 않습니다
실기 · IF · OR · AND

OR와 AND는 IF 안에서
조건을 묶습니다

=IF(OR(B2<40,C2<40),"과락",
  IF(AND(B2>=60,C2>=60),"합격",
    "재시험"))
1OR는 하나라도 참이면 TRUE, AND는 모두 참이어야 TRUE입니다. 둘 다 TRUE 또는 FALSE 하나만 돌려줍니다
2«과락», «합격» 같은 결과 문구를 표시하려면 IF와 함께 씁니다. 조건식만 필요하면 =AND(B2>=60,C2>=60)처럼 단독으로도 쓸 수 있습니다
3이 자료에서는 조건을 하나씩 따로 적습니다. 범위 비교(B2:C2<40)를 IF의 조건식에 바로 넣으면 결과가 여러 개로 퍼질 수 있으니, 쓴다면 OR · AND 안에서 하나의 논리값으로 묶어 씁니다
실기 · IF · WEEKDAY

숫자 하나로
주말을 가립니다

1WEEKDAY(날짜,2)는 월요일이 1, 토요일 6, 일요일 7입니다
2토·일을 문자로 각각 비교하지 않고 >=6 숫자 조건 하나로 주말을 가립니다
실기 · IF · RIGHT

숫자처럼 보여도
텍스트입니다

1LEFT · MID · RIGHT는 텍스트 추출 함수입니다. 화면에 2026이나 1로 보여도 실제 결과는 텍스트입니다
2텍스트 "1"을 숫자 1과 비교하면 FALSE가 될 수 있습니다. 비교 대상도 "1"처럼 따옴표로 묶습니다
3주민등록번호에서 꺼낸 값 앞에 19나 20을 붙이는 문제에서도 같은 점에 주의합니다
실기 · 조건부 서식

범위는 한 행도 틀리면
안 됩니다

1문제에 A4:F13처럼 범위가 주어졌다면 그 범위만 선택합니다. A3부터 선택하는 순간 범위가 틀립니다
2홈 › 조건부 서식 › 새 규칙 › 수식을 사용하여 서식을 지정할 셀 결정에 조건식 =$F4>=90을 넣습니다. 기준 열 F만 고정하고 첫 행 번호는 상대 참조로 둡니다
3서식 단추에서 굵게와 표준색 빨강을 실제로 지정했는지 마지막에 확인합니다
4대화 상자에서는 함수 입력이 불편하니, 옆 빈 셀에 조건식을 먼저 써서 TRUE/FALSE를 확인한 뒤, 셀 편집 상태(F2)에서 식을 선택해 Ctrl+X로 잘라 규칙에 붙여 넣습니다
실기 · INDEX · MATCH

행 번호와 열 번호를
MATCH 두 개로 구합니다

1INDEX의 배열에는 실제로 돌려줄 급여 값이 있는 영역만 선택하고 절대 참조합니다
2세로 목록(직급)에서 찾은 위치가 행 번호, 가로 목록(근속연수)에서 찾은 위치가 열 번호입니다. 두 MATCH의 자리를 바꾸면 안 됩니다
3MATCH(검색값, 검색 범위, 0) — 검색값, 범위, 정확히 일치 순서이고 검색 범위는 절대 참조합니다
4근속연수 숫자를 그대로 열 번호로 넣을 수 있는 것은 그 숫자가 배열 안의 위치와 같을 때뿐입니다. 위치를 구하려면 MATCH를 씁니다
5출발지·도착지, 청약지역·전용면적처럼 두 기준이 행과 열을 정하는 문제도 같은 방식입니다
실기 · MAX · LARGE

내 값을 전체 범위의
MAX·평균과 비교합니다

1최댓값 여부는 자신의 금액이 전체 범위의 MAX와 같은지 비교해 판단합니다. 전체 범위는 채우기 핸들을 쓰므로 절대 참조합니다
2LARGE(범위,k)는 k번째로 큰 값을 구하며, k에 1, 2, 3을 넣어 큰 금액을 차례로 가져옵니다
3출석률이 평균보다 낮은 사람을 찾는 문제는 개인 출석률이 전체 평균보다 작은지(<AVERAGE(전체 범위)) 비교하는 구조입니다
