RAID와 전원 보호 장치

1RAID는 여러 개의 하드디스크를 하나의 디스크처럼 연결해 사용하는 기술입니다
2전원 관련 장치: UPS(무정전 전원 장치)는 정전되었을 때 일정 시간 전원을 공급하고, AVR(자동 전압 조정기)은 전압을 일정하게 맞춰 주며, 정전압 정주파 장치 · 서지 보호기 · 항온 항습 장치도 함께 정리합니다
3메모리가 부족할 때 대표적인 PC 업그레이드 방법이 RAM 용량 늘리기입니다. RAM은 작업대이므로 용량이 커지면 여러 프로그램을 한꺼번에 올려 작업하기 좋습니다
4같은 조건에서 비교하면 CPU 클럭 속도는 높을수록 좋고, 메모리 접근 시간은 짧을수록 좋습니다. 접근 시간 단위는 ms › μs › ns › ps › fs › as 순으로 작아집니다

시스템 소프트웨어와 응용 소프트웨어

3엑셀 · 파워포인트 · 카카오톡처럼 사용자가 작업에 쓰는 프로그램은 응용 소프트웨어(애플리케이션)이며, 줄여서 «앱»이라고 부릅니다

상용 · 셰어웨어 · 트라이얼 · 프리웨어 · 공개

1상용 소프트웨어는 정식으로 대가를 지불하고 사용하는 소프트웨어입니다
2셰어웨어는 기능이나 사용 기간에 제한을 두고 무료로 배포하는 방식입니다. 일정 기간 써 보고 마음에 들면 결제하는 형태이며 요즘 가장 흔합니다
3트라이얼 버전도 셰어웨어와 비슷하지만, 교재에서는 셰어웨어가 일부 기능을 제외한 대부분을 쓰게 해 주는 데 비해 트라이얼은 아주 일부만 제공하는 것으로 구분합니다. 두 가지의 차이만 비교해 둡니다
4프리웨어는 무료로 쓰는 소프트웨어입니다. 공개(오픈) 소프트웨어는 만든 소스를 모두 공개해 누구나 개발에 참여할 수 있게 한 것으로, 리눅스가 대표적입니다

데모 · 알파/베타 · 패치 · 벤치마크 · 번들

1데모 버전은 프로그램 기능을 홍보하기 위해 기간이나 기능을 제한해 배포합니다. 셰어웨어와 비슷해 보이지만 목적이 홍보입니다
2알파 · 베타는 정식 배포 전에 오류를 찾는 테스트 버전입니다. 개발 회사 안에서 하면 알파, 회사 밖의 사용자가 써 보면 베타입니다. 장소로 구분합니다
3패치는 이미 배포된 프로그램의 오류를 고치거나 성능을 높이는 수정 프로그램입니다(윈도우 패치 등). 벤치마크는 성능을 검사하는 것입니다
4번들은 하드웨어나 소프트웨어를 구입할 때 다른 소프트웨어를 무료로 끼워 주는 것입니다

운영체제의 역할과 평가 요소

1운영체제는 사용자가 컴퓨터 하드웨어를 편리하게 쓰도록 돕는 프로그램의 모임으로, 사용자와 하드웨어(컴퓨터) 사이의 중재자 역할을 하며 시스템의 생산성을 높입니다. 보기에 «컴퓨터» 대신 «하드웨어»라는 단어가 나올 수 있습니다
2좋은 운영체제의 평가 요소는 처리 능력 · 응답 시간 · 사용 가능도 · 신뢰도입니다. 처리 능력 · 사용 가능도 · 신뢰도는 높을수록, 응답 시간은 짧을수록 좋습니다
필기 · 운영체제

종류와 주요 기능, 유틸리티

1운영체제의 종류: Windows · UNIX · Linux · MS-DOS, 그리고 스마트폰의 Android · iOS가 모두 운영체제입니다. 명령 프롬프트(CMD)는 MS-DOS와 비슷한 명령 방식으로 쓰는 창입니다
2주요 기능: 프로세스(작업) 관리, 기억 장치 관리, 주변(입출력) 장치 관리, 파일(데이터) 관리, 자원의 스케줄링 · 공유, 사용자와 시스템 간의 인터페이스 제공
3교재의 운영체제 주요 기능 · 관리 자원 목록에는 «보안»이 없어서, «주요 기능이 아닌 것»을 묻는 문제에 보안이 정답으로 나옵니다(실제 운영체제는 보안 기능도 제공합니다)
4유틸리티(메모장 · 그림판 · 계산기 · 워드패드)는 컴퓨터 운영에 필수적이지 않고 사용 편의를 위해 제공하는 프로그램입니다. «필수적이다»라고 쓴 보기는 틀린 설명입니다
필기 · 운영체제

제어 프로그램과 처리 프로그램

1운영체제는 제어 프로그램과 처리 프로그램으로 나뉩니다. 제어가 먼저입니다
2제어 프로그램: 감시 프로그램, 작업 제어 프로그램, 데이터 관리 프로그램. 수업에서는 앞 글자를 따 «감작대»로 외웠습니다
3처리 프로그램: 언어 번역 프로그램, 서비스 프로그램, 문제 프로그램. «언서문»으로 외웠습니다
4«처리 프로그램이 아닌 것», «제어 프로그램에 해당하는 것»을 묻는 문제에는 두 묶음의 이름이 섞여 나오므로 앞 글자 기억법으로 구분합니다
필기 · 운영 기법

일괄 · 실시간 · 분산 처리

1일괄 처리는 일정량을 모았다가 한꺼번에 처리합니다. 가장 먼저 나온 방식이며 급여 · 공공요금처럼 한 달에 한 번만 처리해도 되는 일에 쓰입니다. 오프라인뿐 아니라 온라인에서도 쓸 수 있으므로 «오프라인으로만 사용한다»는 보기는 틀립니다
2실시간 처리는 데이터가 발생하면 즉시 처리합니다. 항공 · 열차 예약, 은행 거래처럼 바로 반영되어야 하는 업무에 씁니다
3분산 처리는 교재에서는 처리할 자료가 많을 때 지리적으로 떨어진 여러 컴퓨터를 네트워크로 연결해 사용자에게는 한 대의 컴퓨터처럼 동작하게 하는 방식으로 설명합니다
4자료 처리 방식의 발달 과정을 묻는 문제에서는 일괄 › 실시간 › 분산 순서가 정답으로 나왔습니다
필기 · 운영 기법

다중 프로그래밍 · 다중 처리 · 시분할 · 듀얼/듀플렉스

1다중 프로그래밍은 CPU 1개로 여러 프로그램을 동시에 실행하는 것처럼 처리하고, 다중 처리는 CPU 여러 개로 처리합니다. 듀얼 코어 · 쿼드 코어 · 헥사 코어 CPU가 다중 처리의 예입니다. 둘의 차이는 CPU 개수입니다
2시분할은 컴퓨터는 한 대인데 사용자가 여러 명일 때, 시간을 잘게 쪼개(예: 0.1초) 돌아가며 할당해서 각자 혼자 쓰는 것처럼 느끼게 합니다
3듀얼 시스템은 두 시스템이 함께 처리하고, 듀플렉스 시스템은 두 대가 있어도 한 대만 처리하다가 문제가 생기면 대기하던 한 대가 동작합니다
필기 · 운영체제

임베디드 시스템

1임베디드 시스템은 컴퓨터 하드웨어와 소프트웨어가 조합된 전자 제어 시스템입니다. 냉장고 · 세탁기 · 에어컨처럼 제어가 필요한 전자 기기 안에 프로그램이 내장되어 모드별로 동작합니다
2자원이 제한된 임베디드 시스템에는 용량이 큰 윈도우보다 그 기능에 맞게 작게 만들어 제품에 포함시킨 전용 운영체제를 주로 쓰며, 교재에서는 Windows CE를 예로 듭니다
3임베디드 시스템이 무엇인지 설명하는 보기를 고르는 문제에서는 «전자 제품에 내장되는 제어 시스템»이라는 뜻을 기억합니다
필기 · 프로그래밍 언어

저급 언어와 고급 언어

1프로그래밍 언어는 저급 언어와 고급 언어로 나뉩니다. 저급 언어는 기계가 알아듣기 쉬운 언어로 기계어와 어셈블리어가 있습니다
2기계어는 컴퓨터가 직접 이해하는 언어입니다. 어셈블리어는 기계어와 1:1로 대응되는 간단한 명령어를 쓰는 언어로, 기계를 빠르게 동작시켜야 할 때 쓰지만 사람이 작성하기는 매우 어렵습니다
3고급 언어는 사람이 일상에서 쓰는 자연어와 비슷한 형태와 구조를 갖는 언어입니다. 기계어로 번역하는 과정이 필요합니다
필기 · 프로그래밍 언어

문제 중심 언어와 절차 중심 언어

1문제 중심 언어는 특정 분야의 문제를 풀기 위해 만든 언어입니다. LISP(인공지능에서 리스트 처리), GPSS(시뮬레이션), SPSS · SAS(확률 · 통계 계산)가 있습니다
2절차 중심 언어는 정해진 문법에 맞게 처리 절차를 순서대로 기술하는 언어로 C · COBOL · FORTRAN · PASCAL · ALGOL이 있습니다. 교재에서는 자연어에 가까워 작성이 쉬운 쪽으로 분류하지만 문법을 익히기는 어렵습니다
3«프로그래밍 언어가 아닌 것» 문제에는 UNIX · Linux 같은 운영체제 이름이 섞여 나옵니다
필기 · 프로그래밍 언어

프로그래밍 기법: 객체 지향

1프로그래밍 기법에는 구조적 · 절차적 · 객체 지향 · 비주얼 프로그래밍 등이 있습니다
2객체 지향은 객체를 중심으로 프로그램을 구성하는 기법입니다. 한 번 정의한 구조를 계속 재사용할 수 있어 중복이 줄고 유지보수가 쉽습니다
3객체 지향의 특징은 추상화 · 캡슐화 · 상속성 · 다형성(수업에서는 «다양성»)입니다. 보기에 «그룹화»처럼 다른 단어가 섞여 있으면 그 보기가 틀린 설명입니다
4비주얼 프로그래밍은 화면에서 눈으로 보면서 만드는 방식이며, 지난 시간의 매크로 기록은 비주얼 베이직 계열(VBA) 코드로 저장되었습니다
필기 · 언어 번역 프로그램

컴파일러는 전체, 인터프리터는 한 줄씩

1언어 번역 프로그램에는 컴파일러 · 인터프리터 · 어셈블러가 있습니다. 어셈블러는 어셈블리어를 기계어로 번역합니다. 번역은 한글 ↔ 영어가 아니라 기계어로 바꾸는 것입니다
2컴파일러는 프로그램 전체를 한꺼번에 번역(통번역)해 번역본인 목적 프로그램을 만듭니다. 번역은 오래 걸리지만 한 번 만들면 바로 실행되어 실행 속도가 빠릅니다
3인터프리터는 한 줄씩 바로 번역(동시통역)하고 목적 프로그램을 만들지 않습니다. 번역 속도는 빠르지만 실행할 때마다 다시 번역하므로 실행 속도는 느립니다
필기 · 웹 프로그래밍 언어

HTML · DHTML · HTML5 · SGML · XML · VRML

1HTML은 하이퍼텍스트 문서를 만드는 인터넷 표준 언어로, 정해진 태그를 붙여 작성합니다. 호환되는 웹 브라우저만 있으면 여러 컴퓨터 · 스마트폰에서 열 수 있어 교재에서는 호환성이 좋다고 설명합니다
2DHTML은 교재에서 동적인 웹 페이지를 만드는 언어(방식)로 설명합니다. HTML5는 ActiveX 설치 없이 웹 브라우저에서 비디오 · 오디오 같은 최신 멀티미디어를 볼 수 있게 한 언어입니다

4VRML은 3차원 가상 공간(가상 현실)을 웹에 표현하고 조작하는 언어입니다. 이름에 «VR»이 붙으면 가상 현실입니다

인터넷의 특징과 관련 용어

1인터넷은 미국 국방성에서 시작되어 TCP/IP를 연결해 쓰는 전 세계 네트워크이며, 중앙 통제 기구가 없습니다. 도메인 주소는 전 세계는 ICANN, 우리나라는 KISA(한국인터넷진흥원)가 관리하지만 이 기관들이 인터넷을 통제하는 것은 아닙니다

IPv4는 8비트 4부분, 32비트

1IPv4 주소는 숫자 8비트씩 네 부분, 모두 32비트로 구성되고 각 부분은 10진수로 쓰며 점(.)으로 구분합니다
2각 부분이 0부터 255까지이므로 표현해야 하는 값이 256가지이고, 256 = 2⁸이므로 한 부분에 8비트가 필요합니다. RGB 색상 값(0~255)과 같은 원리입니다
3교재에서는 네트워크 부분의 길이에 따라 A에서 E까지의 클래스로 구분한다고 설명합니다. 이 정도만 알아 두면 됩니다
4컴퓨터에 부여된 IP 주소가 부족해지면서 만든 것이 IPv6입니다

IPv6는 16비트 8부분, 128비트

1IPv6 주소는 16비트씩 8부분, 모두 128비트입니다. 각 부분을 16진수로 쓰고 콜론(:)으로 구분합니다. 16진수 한 자리가 4비트이므로 네 자리가 16비트입니다
2«16비트 8개 부분»을 «8비트 16개 부분»으로 바꿔 쓴 보기에 주의합니다. 각 부분 앞쪽의 0은 생략할 수 있고, 연속된 0 부분은 주소 전체에서 한 번만 콜론 두 번(::)으로 줄일 수 있습니다
3IPv4의 주소 부족을 해결하려고 만들었고, 교재에서는 IPv4에 비해 보안 · 확장성 · 호환성 · 멀티미디어 지원 등이 뛰어나다고 설명합니다
4전송 방식은 유니캐스트(1:1), 멀티캐스트(1:다수), 애니캐스트(주변에서 가장 가까운 한 대)입니다. IPv4에서 모두에게 뿌리는 방식은 브로드캐스트이며, IPv6는 브로드캐스트 대신 멀티캐스트를 씁니다

도메인 네임 구성과 DNS

1도메인 네임은 숫자로 된 IP 주소를 기억하기 힘들어 문자로 만든 주소입니다. 예를 들어 www.example.co.kr에서는 왼쪽부터 호스트, 기관 이름, 기관 유형, 국가를 나타냅니다
2기관 유형은 co(기업) · com(상업 기관) · ac(대학 · 교육 기관) · go(정부 기관), 국가는 kr(한국)처럼 씁니다
3도메인 이름은 임의로 만들어 쓰는 것이 아니라 등록기관의 정책에 따라 등록해서 쓰며, 일반적으로 비용을 내고 일정 기간 사용한 뒤 갱신합니다. 교재에서는 인터넷에 연결된 컴퓨터를 식별하는 주소를 도메인 이름이 아니라 IP 주소로 설명하며, 같은 네트워크에서 같은 IP 주소를 중복해 쓰면 IP 충돌이 생기며, 인터넷에서 직접 쓰는 공인 IP 주소는 전 세계에서 겹치지 않게 할당합니다
4DNS는 도메인 이름을 IP 주소로 바꿔 주는 시스템입니다

2중간에 있는 계열처럼 드래그로 해결되지 않으면 계열을 선택해 Delete를 누릅니다. 계열이 작아 선택이 어려우면 서식 탭의 «현재 선택 영역»에서 계열 이름을 골라 선택합니다
3지울 항목이 데이터 계열(범례에 나오는 항목)이면 계열을 선택해 Delete합니다. 지울 항목이 계열이 아니라 가로 축의 항목으로 나와 있으면 그대로는 계열로 선택되지 않으므로, 차트 디자인 › 행/열 전환으로 그 항목이 범례 쪽 계열이 되게 바꾼 뒤 선택해 Delete하고, 다시 행/열 전환으로 되돌립니다(수업에서 설명한 방법)
4계열 추가는 추가할 데이터를 필드명(머리글)까지 선택해 Ctrl+C, 차트를 선택하고 Ctrl+V로 붙여 넣습니다. 잘 안 되면 Ctrl+Z로 되돌린 뒤 범위를 다시 선택합니다

1차트 제목은 차트 디자인 › 차트 요소 추가 › 차트 제목 또는 차트 오른쪽의 + 버튼으로 넣고, 직접 입력하거나 셀과 연결할 수 있습니다
2셀 연결: 제목을 클릭해 테두리가 실선인 상태(안에 커서가 없는 상태)로 선택한 뒤, 수식 입력줄에 =을 입력하고 연결할 셀을 클릭해 Enter를 누릅니다. 시트에 있는 글자를 그대로 가져옵니다
3글꼴 · 크기 같은 서식은 개체를 실선으로 선택한 상태에서 홈 탭에서 바꿉니다. 글꼴 이름 칸에 «굴림», 크기 칸에 «16»을 직접 입력하고 Enter를 눌러도 됩니다
4값(세로) 축을 더블클릭하면 오른쪽 작업 창의 축 옵션에서 최소값 · 최대값 · 단위(주) · 표시 단위를 바꿀 수 있습니다. 단위(주)는 문제에서 «기본 단위»라고도 표현합니다. 축 제목은 차트 요소 추가 › 축 제목 › 기본 세로 / 기본 가로 / 보조 세로로 넣고, 글자 방향(세로)은 서식에서 바꿉니다

혼합(콤보) 차트와 보조 축

1두 계열의 값 크기가 크게 다르면(예: 생산량 수만 단위, 불량률 0.01~0.05) 작은 값의 계열이 바닥에 붙어 거의 보이지 않습니다. 이때 혼합(콤보) 차트를 사용합니다. 버전에 따라 «콤보 차트»라고도 부릅니다
2순서: ① 먼저 데이터 계열 하나를 선택 ② 차트 디자인 › 차트 종류 변경 › 혼합 ③ 계열별 차트 종류를 고르고(예: 표식이 있는 꺾은선형) ④ 보조로 옮길 계열의 보조 축에 체크 ⑤ 확인. 수업에서는 계열 하나를 선택하고 들어가야 차트 전체의 종류가 한꺼번에 바뀌어 다시 작업하는 일을 피할 수 있다고 안내했습니다
3보조 축이 생기면 오른쪽에 세로 축이 하나 더 생기고, 이 축도 더블클릭해서 최댓값 · 단위(주)를 따로 조절합니다(예: 최댓값 0.05, 단위 0.01)
4값 차이가 큰 계열이 세 개 이상이면 한 차트에 모두 표현하기 어려우므로 차트를 나누는 것이 좋습니다

데이터 레이블 · 범례 · 추세선 · 눈금선

1데이터 레이블: 계열을 한 번 클릭하면 계열 전체, 한 번 더 클릭하면 요소 하나만 선택됩니다. 선택한 상태에서 우클릭 › 데이터 레이블 추가. 값이 큰 곳처럼 의미 있는 요소에만 달아 강조합니다
2레이블을 우클릭 › 데이터 레이블 서식에서 레이블 내용(값 · 항목 이름)과 위치(위쪽 · 안쪽 끝 · 바깥쪽 끝 등)를 정합니다. «항목 이름을 표시»하라는 문제는 값 체크를 빼고 «범주 이름»(레이블 내용 항목)에 체크합니다
3범례 위치는 차트 요소 추가 › 범례 › 위쪽 · 아래쪽 · 왼쪽 · 오른쪽 메뉴로 정합니다. 문제가 «위쪽»처럼 위치를 지정하면 마우스로 끌어 맞추지 말고 이 메뉴로 지정하라고 수업에서 안내했습니다
4추세선은 계열을 선택하고 차트 요소 추가 › 추세선으로 넣어 전체적인 방향을 보여 줍니다. 눈금선은 차트 요소 추가 › 눈금선(기본 주 가로 · 세로)으로 넣고, 눈금선을 선택해 Delete를 누르면 지울 수 있습니다

스타일 · 채우기 · 테두리 · 그림자

1서식을 적용할 요소(예: 차트 영역)를 먼저 선택합니다. 서식 탭 › 도형 스타일 갤러리에서는 스타일의 이름은 세로 방향으로 찾고 번호는 가로 방향으로 찾아 들어갑니다(예: 미세 효과)
2채우기는 서식 탭의 도형 채우기나 작업 창의 채우기 및 선(페인트 통)에서 정합니다. 단색 · 그라데이션 · 질감 · 그림 등이 있고, 그라데이션은 미리 설정된 색(이름과 번호를 같은 방식으로 찾음), 종류(선형 · 방사형 · 사각형 · 경로), 방향(예: 가운데에서)을 정합니다
3테두리는 선 › 실선 → 색 → 너비(칸에 직접 입력, 예: 2pt) → 둥근 모서리에 체크하는 순서입니다. 꺾은선 계열은 같은 곳에서 선의 색 · 너비와 완만한 선을 지정합니다
4효과 › 그림자 › 미리 설정 › 바깥쪽의 오프셋: 오른쪽 아래처럼 문제가 지정한 위치를 고릅니다

막대 모양을 바꾸는 두 가지 수치

1데이터 계열을 선택하고 작업 창의 계열 옵션에서 계열 겹치기와 간격 너비를 조절합니다
2계열 겹치기: 양수이면 같은 묶음의 막대끼리 겹치고(예: 50%), 0이면 서로 붙고, 음수이면 막대 사이가 떨어집니다
3간격 너비는 막대 묶음 사이의 빈 공간입니다. 간격 너비를 좁히면(0%) 막대가 굵어지고, 넓히면(예: 100%) 막대가 가늘어집니다. 말을 보고 막대 모양을 머릿속에 그려 봅니다
4데이터 표는 차트 요소 추가 › 데이터 표(범례 표지 포함 / 범례 표지 없음)로 넣어 차트에 쓴 데이터를 표로 보여 줍니다. 완성된 차트를 보고 계열 겹치기 · 간격 · 눈금선 · 데이터 표 · 데이터 레이블이 어떻게 설정되었는지 읽어 낼 수 있어야 합니다
