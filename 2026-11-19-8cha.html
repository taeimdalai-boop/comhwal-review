2조건식은 «점수가 60 이상입니까?»라는 질문이고, 결과는 TRUE 또는 FALSE입니다
3SUMIF의 조건, 데이터베이스 함수의 조건 목록, IF의 조건식은 쓰는 형태가 다릅니다
4아래로 채울 때는 B5 → B6 → B7처럼 행마다 셀 하나를 검사하므로 범위를 넣지 않습니다
IF 함수

188점이면 ① 아니요 → ② 예 → B가 되고 거기서 끝납니다
2결과가 5가지이면 조건식은 4개, 즉 IF를 4번 씁니다
3높은 구간(90)부터 묻습니다. 60부터 물으면 90점도 80점도 첫 질문에서 참이 되어 모두 D가 됩니다
IF 함수

거짓 자리에 다음 IF를 넣는다

1=IF(B5>=90,"A",IF(B5>=80,"B",IF(B5>=70,"C",IF(B5>=60,"D","F"))))
2중첩 위치는 앞 IF의 거짓일 때 값 자리입니다. 대화 상자에서 현재 입력 위치를 확인합니다
3쉼표나 괄호 하나만 틀려도 오류가 납니다. IF를 연 개수만큼 닫고, 괄호 색으로 여는 괄호와 닫는 괄호의 짝을 확인합니다
IF 함수

조건식이 두 개 이상일 때

1=IF(AND(B5>=80,E5>=28),"장학생","")
2AND — 모든 조건식이 참이어야 TRUE · OR — 하나라도 참이면 TRUE
3AND의 닫는 괄호는 조건식 끝에서 닫고, 그 뒤에 참일 때 값 · 거짓일 때 값을 적습니다
4표시할 것이 없을 때는 스페이스 한 칸이 아니라 큰따옴표 두 개 ""를 씁니다
IF 응용 · 필기 문제

같은 줄은 AND, 줄과 줄은 OR

1=IF(OR(B2>=90,AND(C2>=80,D2>=80)),"통과","") — 열 위치는 예시입니다
2조건 목록(데이터베이스 함수)과 같은 규칙입니다: 같은 줄은 AND, 다른 줄은 OR
3머릿속에서 조건이 무엇에 해당하는지(둘 다인지, 하나라도 되는지) 먼저 정리합니다
IF 함수

1=IFS(B22>=90,"A",B22>=80,"B",B22>=70,"C",B22>=60,"D",TRUE,"F")
2마지막 TRUE는 «위의 조건이 모두 아니면»이라는 뜻입니다. 책에 따라 1로 쓰기도 합니다
3TRUE 조건이 없는데 앞 조건이 모두 거짓이면 #N/A 오류가 납니다
4시험 범위에 포함되므로 사용법을 익혀 둡니다
IF 함수

오류가 나면 대신 보여 줄 말

3어떤 종류의 오류든 같은 값으로 바뀌므로, 오류 원인을 확인한 뒤 쓰는 것이 안전합니다

3사원코드 마지막 글자: =IF(MOD(RIGHT(A7),2)=1,"남","여") — RIGHT의 글자 수를 생략하면 1글자이고, 문제에서 홀수=남 · 짝수=여로 정했을 때의 식입니다
4MOD(수, 2)는 홀수면 1, 짝수면 0입니다. 이 값을 IF의 조건식으로 비교합니다

필기 함수 문제

눈으로 찾고 머릿속으로 계산

1필기에서는 보기의 수식이 맞는지를 인수 순서 · 의미로 판단합니다
2결과를 묻는 문제는 표에서 조건에 맞는 칸을 눈으로 찾고 직접 계산합니다
3필기 함수 문제 풀이는 오픈북으로 했고, 함수 인수를 적는 연습은 오픈북 없이 합니다
필기 함수 문제

인수 순서를 알면 표에서 바로 합한다

1=SUMIFS(합계범위,조건범위1,조건1,조건범위2,조건2)
2SUMIFS의 조건은 모두 만족(AND)해야 합니다. 연필이면서 서울인 행만 합합니다
3표에서 해당 행을 눈으로 찾고 200 + 300 = 500처럼 직접 더합니다

1=AVERAGEIF(A2:A6,"체리",B2:B6) → 125
2AVERAGEIF · SUMIF는 조건 범위, 조건, (평균 · 합계) 범위 순서입니다
3SUMIFS · AVERAGEIFS는 계산할 범위가 맨 앞에 옵니다

COUNTIF 조건에 함수를 연결할 때는 &

1=COUNTIF(C7:C14,">="&AVERAGE(C7:C14)) → 4
2">=AVERAGE(C7:C14)"처럼 통째로 따옴표에 넣으면 문자로 읽혀 함수가 계산되지 않습니다
3IF의 조건식은 C3>=AVERAGE($C$3:$C$7)처럼 따옴표 · &를 쓰지 않고, 아래로 채우면 AVERAGE 범위는 절대 참조합니다
필기 함수 문제

COUNT는 0도 센다

1=AVERAGEIF(B2:B7,"<>0")
2"<>0"은 «0이 아닌 값»이라는 조건입니다. 숫자 범위를 조건 범위로 쓸 때는 합계(평균) 범위를 생략해도 됩니다
3COUNT는 숫자가 있는 셀을 모두 세므로 0도 포함됩니다. 그래서 SUMIF("<>0")를 나눌 때는 COUNT가 아니라 COUNTIF("<>0")를 씁니다. IF 조건식에 배열을 넣는 방식은 실기에서는 거의 나오지 않고 필기에서 나왔습니다
필기 함수 문제

기준표 방향을 먼저 본다

1방향은 검색값이 기준표의 첫 열인지 첫 행인지로 판단합니다. 보통 쓰는 표는 VLOOKUP입니다
2코드처럼 정확히 일치해야 하면 FALSE(0)를 씁니다
3점수 구간처럼 오름차순 구간표에서 근삿값을 찾을 때는 TRUE(생략 가능)를 씁니다
필기 함수 문제

검색값 · 기준표 · 열 번호 · 방식

1=IFERROR(VLOOKUP(A3,$B$3:$F$6,2,FALSE),"없음") — 범위는 예시입니다
2기준표에 없는 값을 찾으면 #N/A가 나므로, IFERROR의 첫 인수에 VLOOKUP을 넣어 가립니다
3IFERROR의 첫 번째 인수는 결과를 구하는 수식, 두 번째 인수가 오류일 때 보여 줄 값입니다
4기준표의 열 수보다 큰 열 번호를 쓰면 #REF! 오류가 납니다
필기 함수 문제

안쪽 함수가 만든 값을 검색값으로

1=VLOOKUP(LARGE(A2:A9,4),A2:E9,5,FALSE) → 88 — 범위는 예시입니다
2안쪽부터 — LARGE 부분이 82라는 값이 되고, 그 값이 VLOOKUP의 첫 인수가 됩니다
3다섯 번째 열은 기준표 안에서 센 5번째 열입니다
필기 함수 문제

점수는 0, 기록은 1

1=RANK.EQ(B2,$B$2:$B$6,1) — 기록이 작을수록 1등
2전체 범위는 채우기 핸들을 쓰므로 절대 참조이고, 내 값은 상대 참조입니다
3CHOOSE(RANK.EQ(…),"A","B","C","D")에서 순위가 3이면 세 번째 값을 돌려줍니다
다시 보기 · INDEX

번호는 범위 안에서 센 순서

1=INDEX(B2:D11,3,3) → 범위의 세 번째 행 · 세 번째 열 = 960만원
2시트의 4행이 아니라 선택한 범위(B2부터)에서 세어 세 번째 행입니다
3이름 정의로 점수(B2:D6)를 만들면 =AVERAGE(INDEX(점수,2,1),MAX(점수))처럼 쓸 수 있습니다. 수업 문제에서는 INDEX(점수,2,1)=80, MAX(점수)=100이라 (80 + 100) ÷ 2 = 90이었습니다
다시 보기 · INDEX MATCH

같은 결과를 내는 여러 수식

1VLOOKUP은 검색값이 기준표 첫 열에 있어야 합니다. 가져올 열이 찾는 열의 왼쪽이면 INDEX와 MATCH를 씁니다
2FIND(찾을 값, 문자열) · SEARCH(찾을 값, 문자열) — 찾을 값이 먼저입니다
3같은 결과를 내는 수식이 여러 개이므로, 보기의 인수 순서를 하나씩 확인합니다
