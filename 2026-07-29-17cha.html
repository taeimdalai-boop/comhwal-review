🖥필기 기출 정리 (강사님이 다룬 문제)

🔐 정보 보안 · 컴퓨터 범죄

공격 스니핑(패킷 엿보기)·스푸핑(주소 위장)·피싱(기관 사칭)·파밍(정상 URL도 가짜 유도)·키로거(키 입력 탈취).
예방 해킹 여부 정기 점검, 의심 메일은 열지 말고 삭제(님다는 열기만 해도 감염), 백신 최신, 정기 백업.
시험: "패킷 엿봐 계정 탈취=스니핑". 의심 메일 "열어서 확인 후 삭제"는 오답.

🔡 문자 표현 코드 · WWW

비트 순서 BCD(6비트, 소문자 X) → ASCII(7비트, 개인·통신) → EBCDIC(8비트, 대형) → 유니코드(16비트, 전 세계·2바이트). 해밍 코드=오류 검출·교정(문자 코드 아님, 함정).
WWW HTTP 프로토콜·하이퍼텍스트·서버/클라이언트. HTML은 언어(Language)지 프로토콜이 아님(프로토콜은 끝에 P). 웹 언어=HTML/DHTML/HTML5/ASP/PHP/JSP/자바스크립트. DXDIAG는 유틸리티(웹 언어 아님).
시험: "6·7·8·16" 순서, "해밍=오류 검출", "HTML=언어(프로토콜 X)".

💾 주기억장치 · 검색 · 프린터

주기억장치 ROM=비휘발성·바이오스·글꼴·POST(자가 진단) 저장 / RAM=휘발성·프로그램 실행. RAM=DRAM(주기억 적재)+SRAM(캐시·버퍼·빠름). "ROM이 대량 영구 보관"은 오답.
검색 상자 작업 표시줄 돋보기=Win+S(앱·문서·웹까지 검색). 파일 탐색기 검색은 Ctrl+F(Win+F는 피드백 허브).
프린터 네트워크 프린터=IP 주소/이름으로 지정 / 포트(COM·LPT) 지정은 로컬 프린터. VR=3차원, 벡터=점·선·곡선(비트맵과 구분).
시험: "POST=ROM 저장", "Win+S=검색", "포트 지정=로컬 프린터".

📗실기 기출 정리 (강사님이 다룬 문제)

🔤 문자 함수 · 연결 · 대문자

추출 LEFT(왼쪽 n글자)·RIGHT(오른쪽 n글자). (MID는 가운데.)
연결 사이의 하이픈은 &"-"&로 붙임(표에서 "-" 하나 넣는 것과 같음).
대문자 결과 전체를 UPPER()로 한 번에 감싸기. 예: =UPPER(LEFT(A2,3)&"-"&RIGHT(B2,2)&"-"&LEFT(C2,2)). 함수는 최대한 적게.
시험: "네 문자로 표시"면 전체를 UPPER로 감싼다(따로따로도 정답이지만 적게).

🔎 VLOOKUP + ROUNDDOWN · RANK

VLOOKUP 청구량=사용량×(1−할인율). 할인율=VLOOKUP(사용량, 기준표(F4 절대참조), 열 번호, TRUE(유사값)). "이상"은 표시 형식일 뿐 실제 값은 0·100·200….
ROUNDDOWN "소수 둘째 자리에서 내림→첫째까지 표시"면 결과 전체를 ROUNDDOWN(값, 1)로 감쌈. 올림/내림 문구가 아니라 표시 결과 자릿수를 본다.
RANK RANK.EQ(값, 범위(F4), 옵션). 0/생략=내림차순(점수 등수) / 1=오름차순(기록·시간 빠른 순).
시험: 기록 순위는 옵션 1. VLOOKUP 기준표·RANK 범위는 F4 절대참조 필수.

🎨 조건부 서식 · 고급 필터 · 표시 형식

조건부 서식 ①범위(레코드만) 선택 ②"수식을 사용" ③IF의 조건식만 입력(예: =$E4<$F4). 행 전체 서식이면 열 고정 절대참조($E4). 규칙은 1개만. 글꼴색/채우기색은 지시 그대로.
고급 필터 조건 같은 줄=AND, 다른 줄=OR. 예: (직책=대리 AND 경력≥4) OR (토익 500~699). 조건을 말로 풀어 읽는 연습.
표시 형식 조건 [>5]처럼 대괄호로 조건 지정. 별표(*)는 "뒤 문자를 공백만큼 반복" 코드라, 그냥 별표를 표시하려면 "*"(따옴표)로. 원(₩)·명 등 추가 문자도 따옴표.
기타 이름 정의: 첫 글자=문자/밑줄, 공백 X, 통합 문서 단위(시트 달라도 중복 X). 매크로 이름은 밑줄로 시작 못 함. 연도==YEAR(TODAY()). 목표값 찾기=한 개 값만 변경.
시험: 행 전체=열 절대참조, 규칙 1개, 표시 형식 별표는 따옴표로 감싸기.

⭐ 차트 함정

추세선·3차원 가능 여부를 헷갈려요

원형·도넛·방사·표면·3차원·누적은 추세선 X. 도넛·분산·거품·방사·주식은 3차원 X.

추세선 O=막대·꺾은선·영역·분산·거품(비누적 2차원). 그림 2~3 참고.

실기 · 자주 틀림

RANK 순위 옵션을 반대로 써요

점수 등수는 0/생략(내림차순), 기록·시간처럼 작은 값이 1등이면 1(오름차순)이에요.

기록 문제=옵션 1. 범위는 반드시 F4 절대참조.

실기 · 자주 틀림

조건부 서식에서 절대참조를 안 걸어요

"행 전체" 서식인데 상대참조로 두면 색이 밀려요. 열을 고정한 절대참조($E4)여야 합니다.

범위는 레코드만 선택, 열 절대참조, 규칙은 딱 1개.

실기 · 자주 틀림

원형 차트에서 한 계열을 Delete로 지워요

원형은 계열이 1개라 지우면 차트가 통째로 사라져요.

데이터 선택→차트 데이터 범위를 다시 지정(원하는 항목만).

실기 · 자주 틀림

표시 형식에서 별표(*)를 그냥 써요

별표는 "뒤 문자를 공백만큼 반복"하는 코드예요. 별표 자체를 보이려면 "*"(따옴표)로 감싸야 해요.

추가 문자(별표·명·원)는 따옴표로. 예: "*"0"명".

실기 · 자주 틀림

VLOOKUP 기준표에 절대참조를 안 걸어요

채우기 핸들로 내리면 기준표가 밀려서 오류가 나요.

기준표 범위는 F4로 절대참조, 유사값이면 TRUE(1).

필기 · 자주 틀림

ROM이 데이터를 영구 보관한다고 생각해요

ROM은 비휘발성이지만 바이오스·POST 같은 부팅 정보를 담는 곳이지 대량 영구 저장소가 아니에요.

대량 영구 보관=보조기억장치. ROM=BIOS·POST, RAM=실행(휘발성).

필기 · 자주 틀림

해밍 코드를 문자 표현 코드로 골라요

해밍 코드는 오류 검출·교정 코드예요. 문자 코드는 BCD·ASCII·EBCDIC·유니코드.

"오류 검출·교정=해밍"으로 분리해서 기억.
