📌오늘 배운 핵심 요약

[필기] 펌웨어 = 하드웨어 속의 소프트웨어

ROM에 저장되어 하드웨어를 제어하는 프로그램입니다. 하드웨어를 바꾸지 않고 업그레이드만으로 성능을 높일 수 있어요. 냉장고·세탁기·스마트폰의 «펌웨어 업데이트»가 바로 이것입니다.

바이오스가 대표적인 펌웨어

[필기] CMOS 셋업에서 «부팅 순서»를 바꾼다

전원을 켤 때 Delete나 F2 같은 키로 들어가는 검은 화면입니다. 시스템 날짜·시간, 부팅 순서, 전원 관리, 시스템(셋업) 암호를 설정합니다.

윈도우 로그인 암호와는 다른 암호

[필기] SATA의 S = 시리얼(직렬)

예전 PATA(병렬)는 케이블이 넓어 먼지가 쌓이고 통풍이 나빴습니다. SATA(직렬)는 선이 얇고 전송 속도가 빠르며 핫 플러그인을 지원해요.

USB의 S와 같은 «시리얼»

[필기] ★제어는 감·작·데, 처리는 언·서·문

운영체제는 제어 프로그램(감시·작업 관리·데이터 관리)과 처리 프로그램(언어 번역·서비스·문제 해결)으로 나뉩니다. 외우지 않으면 풀 수 없는 문제가 나옵니다.

ㅈ(제어)이 먼저, ㅊ(처리)이 나중

[필기] 다중 프로그래밍 vs 다중 처리 = CPU 개수

다중 프로그래밍은 CPU 한 개로 여러 프로그램을, 다중 처리는 CPU 여러 개로 처리합니다. 듀얼은 두 대가 동시에, 듀플렉스는 한 대가 쉬다가 고장 나면 투입됩니다.

발달 순서는 «일괄»이 처음, «분산»이 마지막

[필기] 컴파일러 = 통번역, 인터프리터 = 줄번역

컴파일러는 전체를 한꺼번에 번역해 목적 프로그램을 만들고, 번역은 느리지만 실행은 빠릅니다. 인터프리터는 한 줄씩 번역해 목적 프로그램이 없습니다.

HTML5는 액티브X 없이 멀티미디어 재생

[실기] 차트 서식은 «작업창 3칸»에 다 있다

요소를 더블클릭하면 오른쪽 작업창이 열립니다. 채우기 및 선(그라데이션·질감·패턴·둥근 모서리) · 효과(그림자) · 축 옵션(최대·기본 단위·표시 단위) 세 칸을 기억하세요.

데이터 레이블 내용만 오른쪽 버튼

[실기] 40분·70점 — 푸는 순서가 점수다

1-2 · 1-3 → 분석 작업(3번) → 매크로·차트(4번) → 계산 작업(함수) → 남으면 1-1 입력. 함수는 맨 나중에, 그리고 Ctrl+S를 수시로.

먼저 — 오늘 배운 순서와 어제 틀린 것

오전 필기 4장 복습 → 바이오스·CMOS 셋업·펌웨어 → 하드디스크 연결 방식(SATA) → 5장 전체(소프트웨어 사용권 · 운영체제 · 운영 기법 · 프로그래밍 언어 · 웹 언어).
오후 실기 차트 서식을 끝까지 다루고, 기출 문제 푸는 순서를 배운 뒤 40분 실전 연습과 자가 채점을 했습니다.
어제 퀴즈에서 세 문항이 기준 미달이었습니다 — 처리 속도 단위 54%, 매크로 Alt+F11 69%, 차트 F11 69%. 뒤의 둘은 사실 같은 뿌리(F 키 단축키 혼동)라 아래에서 한 장으로 묶어 정리했습니다.
앞으로 필기는 6·7·8장이 남았고(내일 6·7장 예정), 스프레드시트 필기 보강은 추석 이후입니다. 실기는 진도가 끝나 기출 30회분을 계속 풉니다.

⏱ [복습] 처리 속도 단위 — 어제 54%, 오늘 다시 짚은 것

가장 많이 틀린 문항이었고, 강사도 "외워야 풀 수 있는 문제"라고 오늘 다시 강조했습니다. 생각해서 푸는 문제가 아니라 순서를 외워야 하는 문제예요.
외우는 말 밀 · 마 · 나 · 피 · 펨 · 아 — 밀리 → 마이크로 → 나노 → 피코 → 펨토 → 아토.
지수는 3씩 10⁻³ → 10⁻⁶ → 10⁻⁹ → 10⁻¹² → 10⁻¹⁵ → 10⁻¹⁸. 숫자가 작아질수록 빠릅니다.
문제 푸는 법 「가장 빠른 것은?」이 나오면 보기에서 뒤쪽 글자를 찾습니다. as가 없으면 fs, 그것도 없으면 ps… 이렇게 내려오며 고르면 됩니다.
같이 나오는 것 기억 용량 단위 B → KB → MB → GB → TB → PB → EB(한 칸마다 2¹⁰배)와 접근 속도 레지스터 › 캐시 › 주기억 › 보조기억. 세 줄 모두 «순서»를 묻습니다.

⌨️ [복습] F 키 네 개 — 어제 69% 두 문항이 여기서 갈렸습니다

왜 틀렸나 매크로의 Alt+F8·Alt+F11과 차트의 Alt+F1·F11이 서로 섞여서 두 문항 모두 69%가 됐습니다. 네 개를 한 자리에 놓고 갈라 두면 헷갈리지 않습니다.
Alt + F8 매크로 대화상자 — 실행·편집·삭제는 되지만 여기서 기록은 시작할 수 없습니다. 기록은 개발 도구(또는 보기) 탭의 「매크로 기록」 단추로 시작하고, 이 단추에는 단축키가 없습니다.
Alt + F11 VBA 편집기 — 기록된 코드를 보고 고칩니다.
Alt + F1 선택한 범위로 같은 워크시트 안에 기본 차트를 넣습니다.
F11 (Alt 없이) 선택한 범위로 별도의 «차트 시트»를 새로 만듭니다.
외우는 요령 Alt가 붙은 셋은 «창이 열리거나 제자리», Alt 없는 F11만 «새 시트»로 나갑니다.

🔧 [필기] 바이오스 · CMOS 셋업 · 펌웨어

바이오스(BIOS) 컴퓨터를 켰을 때 기본 입출력 장치와 하드웨어를 동작시키는 데 필요한 것들을 모아 둔 프로그램입니다. ROM에 들어 있어 «ROM-BIOS»라고도 불러요. 자가 진단 프로그램 POST도 여기에 들어 있습니다.
펌웨어(Firmware) 이처럼 ROM(칩) 안에 프로그램이 함께 들어 있는 형태를 말합니다. 하드웨어의 성격과 소프트웨어의 성격을 모두 가지고 있어요. 바이오스가 대표적인 펌웨어입니다.
펌웨어의 장점 하드웨어를 교체하지 않고 업그레이드만으로 성능을 높일 수 있습니다. 스마트폰·냉장고·세탁기·밥솥의 「펌웨어 업데이트」가 그것이고, 펌웨어로 작성된 프로그램을 마이크로 프로그램이라고도 부릅니다.
CMOS 셋업 바이오스의 설정값을 저장해 두는 곳으로, 전원을 켤 때 Delete나 F2 같은 키를 눌러 들어갑니다(기종마다 다름). 검은 화면에 영어만 나오는 그 화면이에요.
CMOS 셋업에서 바꾸는 것 시스템 날짜·시간, 부팅 순서(CD나 USB를 먼저 읽게 바꿔 운영체제를 새로 설치할 때 씁니다), 전원 관리, 그리고 시스템 암호. 이 암호는 윈도우 로그인 암호가 아니라, 컴퓨터를 켤 때 또는 이 셋업 화면에 들어갈 때 묻는 본체 자체의 암호입니다.

🔌 [필기] 하드디스크 연결 방식 — PATA와 SATA

연결 방식 이름들 IDE → EIDE(앞에 E가 붙으면 «확장») → SCSI 등이 있습니다. 컴활 2급은 PATA와 SATA의 차이만 확실히 알면 됩니다.
PATA (Parallel ATA) 병렬 방식. 케이블이 넓어서 데이터를 한꺼번에 보내지만, 본체 안에서 자리를 많이 차지하고 먼지가 쌓이며 통풍이 나빴습니다.
SATA (Serial ATA) 직렬 방식. 선이 얇고 전송 속도는 오히려 더 빠르며, 통풍도 좋습니다. 요즘 쓰는 방식이 이것이고, 핫 플러그인(전원이 켜진 상태에서 연결)도 지원합니다.
외우는 요령 S = Serial = 직렬. USB의 S와 같습니다 — 「선이 얇은데 더 빠르다」가 핵심이에요.
파티션 하나의 하드디스크를 여러 개로 나누는 것. 나누는 이유는 데이터 보관을 분리하고 서로 다른 운영체제를 설치할 수 있게 하기 위해서입니다(「모든 파티션에 같은 운영체제만」은 틀린 보기). 파티션마다 파일 시스템(FAT·exFAT·NTFS)을 지정합니다.

📦 [필기] 5장 ① — 소프트웨어 사용권에 따른 분류

먼저 큰 분류 시스템 소프트웨어(운영체제·언어 번역 프로그램·펌웨어·라이브러리·부트로더·장치 드라이버)와 응용 소프트웨어(엑셀·한글 등)로 나뉩니다.
사용권 분류 — 표 전체가 출제 범위입니다. 최근까지 계속 나오고 있어요.
상용 돈을 내고 사서 쓰는 것 · 셰어웨어 기능이나 기간을 제한해 배포하고 마음에 들면 구입 · 트라이얼 셰어웨어와 비슷하지만 일부 기능만 맛보기로 제공 · 프리웨어 무료로 쓸 수 있는 것(저작권은 제작자에게 있어 수정·재배포는 제한될 수 있습니다).
공개 소프트웨어(오픈 소스) 소스 코드까지 공개한 것(리눅스 등) · 데모 홍보 목적으로 잠깐 제공 · 번들 다른 제품을 살 때 끼워 주는 것.
알파 ↔ 베타 — 차이는 «장소» 알파는 개발자(회사) 쪽에서, 베타는 일반 사용자가 자기 자리에서 테스트합니다. 「베타 테스터 모집」 광고를 떠올리세요.
패치 오류 수정·성능 향상을 위해 일부만 고쳐 내놓는 것(반창고) · 벤치마크는 성능을 비교·검사하는 것입니다.

🖥 [필기] 5장 ② — 운영체제의 구성 (외우지 않으면 못 풉니다)

운영체제란 컴퓨터 하드웨어를 효율적으로 쓸 수 있게 도와주는 소프트웨어입니다. 윈도우·macOS·유닉스·리눅스·MS-DOS, 그리고 스마트폰의 iOS·안드로이드도 운영체제예요.
운영체제의 목적 4가지 신뢰도 · 사용 가능도 · 처리 능력 향상 · 응답 시간 단축. 앞 글자를 따 「신·사·처·응」으로 외웁니다.
★ 구성 — 제어 프로그램과 처리 프로그램 제어(ㅈ)가 먼저, 처리(ㅊ)가 나중입니다.
제어 프로그램 = 감 · 작 · 데 감시 프로그램 · 작업 관리 프로그램 · 데이터 관리 프로그램.
처리 프로그램 = 언 · 서 · 문 언어 번역 프로그램 · 서비스 프로그램 · 문제(해결) 프로그램. 「다음 중 처리 프로그램이 아닌 것은?」에 감시 프로그램을 끼워 넣는 식으로 나옵니다.
유틸리티 메모장·그림판·계산기처럼 사용자의 편의를 위한 프로그램. 컴퓨터 동작에 «필수적»이지 않습니다 — 「필수적」이라는 말이 나오면 틀린 보기예요.
운영체제가 관리하는 자원 기억장치·프로세스·주변장치·파일 등입니다. 「보안」은 자원이 아니라는 점이 작년에 출제됐습니다.

⚙️ [필기] 5장 ③ — 운영체제의 운영 기법

일괄 처리 자료를 모았다가 한꺼번에 처리. 급여 계산·공공요금처럼 지금도 씁니다. 「오프라인에서만 가능」은 틀린 보기 — 온라인·오프라인 모두 됩니다.
실시간 처리 즉시 처리해야 하는 것 — 항공기·열차 좌석 예약, 은행 업무.
시분할 컴퓨터는 한 대인데 사용자가 여럿일 때, 아주 짧은 시간으로 쪼개 돌아가며 씁니다. 사용자는 혼자 쓰는 것처럼 느껴요.
분산 처리 지역적으로 떨어져 있는 컴퓨터들을 하나처럼 연결해 처리합니다.
★ 다중 프로그래밍 ↔ 다중 처리 — 차이는 CPU 개수 다중 프로그래밍은 CPU 한 개로 여러 프로그램을 번갈아, 다중 처리는 CPU 여러 개로 처리합니다.
★ 듀얼 ↔ 듀플렉스 둘 다 컴퓨터가 두 대인데, 듀얼 시스템은 두 대가 동시에 일하고, 듀플렉스 시스템은 한 대만 일하고 다른 한 대는 대기하다가 고장 나면 투입됩니다.
임베디드 시스템 가전제품 등에 내장된 시스템. 일반 운영체제 대신 가벼운 것을 쓰는데, 대표가 Windows CE입니다.
발달 순서 일괄 처리가 가장 먼저 → 다중 프로그래밍·다중 처리 → 시분할·실시간 → 다중 모드 → 분산 처리가 가장 나중. 처리할 데이터가 많아진 요즘 방식이 분산이라고 생각하면 순서가 잡힙니다.

💻 [필기] 5장 ④ — 프로그래밍 언어와 번역 프로그램

저급 언어 ↔ 고급 언어 기준은 사람이 이해하기 쉬운가입니다. 저급은 기계가 알아듣기 쉬운 쪽 — 기계어(0과 1)와 어셈블리어. 고급은 사람 말에 가까운 쪽 — C, 베이직, 코볼 등.
용도로 외우는 언어 LISP 인공지능 · GPSS 시뮬레이션 · SPSS·SAS 확률·통계 처리. 이 네 개가 가장 많이 나옵니다.
객체 지향 관련된 것들을 묶어서(객체) 재사용하므로 코드가 짧아지고 유지·보수가 쉽습니다. 특징 네 가지는 추상화 · 캡슐화 · 상속성 · 다형성(「그룹화」 같은 말이 보이면 틀린 보기). 대표 언어는 C++·Java·C#입니다.
언어 번역 프로그램 사람이 쓴 코드를 기계가 알아듣게 바꿔 주는 «번역가»입니다. 어셈블러는 어셈블리어 전용이고, 시험은 컴파일러와 인터프리터의 차이를 묻습니다.
컴파일러 = 통번역 전체를 한꺼번에 번역합니다. 번역본에 해당하는 목적 프로그램이 생기고, 번역 속도는 느리지만 실행 속도가 빠릅니다.
인터프리터 = 줄번역 한 줄씩 번역해 바로 실행합니다. 목적 프로그램이 없고, 번역은 빠르지만 실행은 느립니다.

🌐 [필기] 5장 ⑤ — 웹 프로그래밍 언어

HTML 웹 문서를 만드는 가장 기본 언어. 태그가 미리 정해져 있습니다. (매일 받는 이 복습자료도 HTML 문서예요.)
DHTML HTML에 동적인 효과·애니메이션을 더한 것. 「애니메이션 강화」가 보이면 DHTML입니다.
HTML5 액티브X 같은 별도 프로그램을 설치하지 않고도 웹 브라우저에서 동영상 등 멀티미디어를 재생할 수 있게 한 표준. 요즘 액티브X를 안 깔아도 되는 이유입니다.
XML HTML의 한계를 보완해 사용자가 새로운 태그를 직접 정의할 수 있는 언어. 그래서 데이터를 구분해 담기 좋습니다(한글의 .hwpx도 이 방식이라 AI가 더 잘 읽습니다). SGML은 전자 문서를 전송·처리하기 위한 언어입니다.
VRML V = Virtual — 가상현실 모델링 언어. 「가상」이 보이면 앞에 V가 붙은 것을 고르세요.
서버에서 동작하는 웹 언어 ASP · JSP · PHP. 그리고 자바스크립트·VB스크립트처럼 «스크립트»가 붙은 것들도 웹 페이지용입니다.
파이썬 교재에는 없지만 작년부터 출제되고 있습니다. 인공지능·빅데이터 분석에 가장 많이 쓰이고, 인스타그램·넷플릭스도 이 언어로 만들어졌습니다.

📊 [실기] 차트 서식 — 작업창 세 칸에 다 있습니다

차트 넣기 데이터 범위를 선택하고 Alt + F1 또는 F11. 범위는 필드명(범례가 됩니다)과 가로 항목축이 될 열을 함께 잡아야 하고, Ctrl을 누르면 떨어져 있는 열도 선택할 수 있습니다.
Alt를 누른 채 이동·크기 조절하면 차트가 셀에 꼭 맞게 붙습니다(시험엔 안 나오지만 실무에서 깔끔합니다).
요소를 더블클릭하면 오른쪽 작업창이 열리고, 위쪽에 아이콘 세 칸이 있습니다 — 무엇이 어디 있는지만 알면 끝입니다.
① 채우기 및 선 채우기 없음 / 단색 / 그라데이션(미리 설정·종류: 선형·방사형·사각형·경로형) / 그림 또는 질감(데님·모래·파랑 박엽지 등) / 패턴. 그리고 테두리 항목 안에 「둥근 모서리」가 숨어 있습니다 — 어디 있는지 묻는 문제가 나옵니다.
② 효과 그림자(미리 설정 → 바깥쪽 → 오프셋: 오른쪽 아래), 네온, 부드러운 가장자리, 3차원 서식.
③ 축 옵션 (축을 더블클릭했을 때) 최소값·최대값·기본 단위, 그리고 표시 단위(천·백만 단위로 줄여 표시).
리본 쪽은 차트 디자인(차트 요소 추가·빠른 레이아웃·색 변경·스타일·행/열 전환·차트 종류 변경)과 서식(현재 선택 영역·도형 스타일) 두 개뿐입니다.

📈 [실기] 차트 — 혼합 차트 · 데이터 레이블 · 추세선

혼합(콤보) 차트 값의 크기가 크게 다른 계열이 있으면 작은 쪽이 보이지 않습니다. 계열 하나를 먼저 선택하고 차트 디자인 → 차트 종류 변경 → 혼합으로 들어가세요. (그냥 들어가면 엑셀이 엉뚱한 계열을 마음대로 바꿔 놓습니다.)
거기서 문제가 지정한 계열을 표식이 있는 꺾은선형 등으로 바꾸고 보조 축에 체크합니다. 이름을 꼼꼼히 확인하세요 — 「생산량 계열을」이라고 했는데 엑셀이 불량률을 바꿔 놓은 채로 확인을 누르면 틀립니다.
데이터 레이블 계열 전체가 아니라 특정 요소 하나만 붙일 수 있습니다 — 막대를 한 번 클릭(계열 전체) → 한 번 더 클릭(그 요소만) 한 뒤 추가하세요.
내용·위치 바꾸기 오른쪽 버튼 → 데이터 레이블 서식(레이블을 더블클릭해도 같은 작업창이 열립니다)으로 들어가면 «값·항목 이름» 선택과 위치(안쪽 끝·바깥쪽 끝·위쪽)를 지정할 수 있습니다. 수업에서는 오른쪽 버튼 쪽이 확실하다고 안내했습니다.
추세선 특정 계열 하나를 선택한 뒤 차트 요소 추가 → 추세선 → 선형 또는 지수. 값이 어떤 흐름인지 선으로 보여 줍니다.
차트 제목 직접 입력하거나, 실선이 되도록 선택한 뒤 수식 입력줄에 =를 치고 셀을 클릭해 연결합니다. 글꼴·크기를 바꿀 때도 블록을 잡지 말고 실선 상태에서 바꾸세요 — 빠뜨리는 글자가 생기지 않습니다.

⏱ [실기] 기출 문제 푸는 순서 — 40분에 70점

시험 구성 4개 파트를 40분 안에 풀고 70점 이상이면 합격입니다. 오늘부터 이 순서로 연습합니다.

② 분석 작업(3번) 6가지 기능 중 2개가 나와 20점. 클릭 위주라 확실히 챙깁니다.
③ 기타 작업(4번) — 매크로와 차트 매크로 10점(5+5), 차트 10점(2점×5). 순서만 지키면 확보되는 점수입니다.
④ 계산 작업(함수) 맨 마지막에 풉니다. 모르는 문제는 건너뛰고 풀 수 있는 것만 고르세요.
⑤ 남는 시간에 1-1 입력 5점이라도 건집니다.
시험 중 반드시 지킬 두 가지 ① 시트를 확인하세요 — 문제마다 「계산작업 시트」처럼 적혀 있습니다 ② Ctrl + S를 수시로 — 다 풀어 놓고 저장을 안 해 떨어지는 경우가 실제로 있습니다.
