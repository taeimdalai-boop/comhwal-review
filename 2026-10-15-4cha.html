복습 · 표시 형식

쉼표 하나는
세 자리를 줄입니다

표시 형식입력한 값보이는 모양
#,###0빈 칸
#,##000
#,##0,456789457
#,##0,,12345678901,235
1# 은 의미 없는 0을 표시하지 않고, 0 은 표시합니다. 0 값이 보이게 하려면 끝자리를 0 으로 씁니다
2형식 끝에 쉼표를 하나 붙이면 천 단위, 둘이면 백만 단위로 줄여 보여 줍니다. 버리는 것이 아니라 반올림해서 보이는 것이고, 셀의 실제 값은 그대로입니다
3문자 데이터는 @ 로 불러오고, 덧붙일 글자는 큰따옴표 안에 씁니다. @"요일" 이면 월 → 월요일
4날짜·요일 코드 ddd · dddd · aaa · aaaa 의 차이를 다시 구분하세요
복습 · 틀 고정

셀을 고르면
왼쪽과 위쪽이 고정됩니다

1선택한 셀의 왼쪽 열과 위쪽 행이 함께 고정됩니다. 예) B4 → A열과 1~3행
2창 나누기를 실행하면 앞서 한 틀 고정은 없어지고 창 나누기만 남습니다
3새 창으로 같은 통합 문서를 두 번 열고, 모두 정렬 → 세로로 나란히 놓을 수 있습니다
4엑셀과 인터넷 창처럼 다른 프로그램은 윈도우의 Win+← · → (에어로 스냅)로 나란히 놓습니다
페이지 설정 · 페이지 탭

용지 방향과 배율은
페이지 탭입니다

1페이지 설정은 탭이 네 개입니다 — 페이지 · 여백 · 머리글/바닥글 · 시트
2페이지 탭: 용지 방향, 용지 크기, 인쇄 품질, 배율, 시작 페이지 번호
3가로로 긴 표는 가로 방향으로 바꿉니다
4글꼴 크기와 열 너비를 일일이 고치지 않고 배율(약 150~160%)로 크게 인쇄할 수 있습니다. 배율 범위는 10%~400%
5자동 맞춤에서 너비·높이를 각각 1페이지로 하면 여러 쪽이 한 쪽에 맞춰집니다
인쇄 설정은 서식을 마무리한 뒤에행 높이나 열 너비를 바꾸면 쪽이 나뉘는 위치가 달라집니다. 표를 다 만든 다음 확인하세요.
페이지 설정 · 여백 탭

표를 가운데에 놓으려고
빈 열을 끼우지 않습니다

1여백 탭: 위·아래·왼쪽·오른쪽 여백, 머리글/바닥글 거리, 페이지 가운데 맞춤
2표를 용지 가운데에 놓으려면 빈 행이나 열을 넣지 말고 가로·세로 가운데 맞춤을 체크합니다
페이지 설정 · 머리글/바닥글

머리글은 왼쪽·가운데·
오른쪽 세 구역

1머리글 편집·바닥글 편집을 누르면 왼쪽 · 가운데 · 오른쪽 세 구역이 나옵니다
2아이콘으로 글꼴, 페이지 번호, 전체 페이지 수, 날짜, 시간, 파일 경로, 파일 이름, 시트 이름, 그림을 넣습니다. 파일 이름과 시트 이름 아이콘을 헷갈리지 마세요
3수업에서는 오른쪽 머리글에 날짜, 가운데 바닥글에 학원 이름을 넣었습니다. 회사 로고는 그림 아이콘으로 넣습니다
4코드는 &[날짜] 처럼 & 로 시작합니다. 글자 & 자체를 표시하려면 && 로 씁니다
5여러 쪽 문서에는 페이지 번호를 넣어 두는 것이 좋습니다
페이지 설정 · 시트 탭

여러 쪽 표는
제목 행을 반복합니다

1시트 탭: 인쇄 영역 · 반복할 행/열 · 눈금선 · 행/열 머리글 · 흑백 · 간단하게 인쇄 · 메모 · 페이지 순서
2반복할 행은 둘째 쪽부터 사라지는 필드명(제목) 행을 모든 쪽에 되풀이합니다. 제목이 여러 행이면 $1:$3 처럼 범위로 지정합니다
3인쇄 미리 보기 화면에서는 인쇄 영역·반복할 행·반복할 열이 비활성화됩니다. Esc 로 나와 페이지 레이아웃 탭에서 페이지 설정을 열어 지정합니다
4틀 고정은 화면용입니다. 인쇄할 때 제목을 반복하려면 반복할 행입니다
인쇄 · 인쇄 옵션

눈금선과 행/열 머리글은
체크하면 인쇄됩니다

1눈금선을 체크하면 셀 테두리를 따로 그리지 않아도 눈금선이 인쇄됩니다 (셀 서식의 테두리와는 다릅니다)
2행/열 머리글을 체크하면 위의 A, B, C와 왼쪽의 1, 2, 3이 인쇄됩니다
3흑백은 배경색 등을 빼서 토너를 아낍니다. 간단하게 인쇄는 도형·차트 같은 개체를 빼고 입력한 내용 위주로 인쇄합니다
4숨긴 시트·행·열은 인쇄되지 않습니다
5도형과 차트는 따로 설정하지 않아도 함께 인쇄됩니다. 특정 도형만 빼려면 도형 서식 작업창에서 개체 인쇄 체크를 해제합니다
6차트를 선택한 채 Ctrl+P 를 누르면 선택한 차트만 인쇄됩니다
인쇄 영역

인쇄 영역은
페이지 레이아웃에서

1인쇄할 범위를 선택하고 페이지 레이아웃 → 인쇄 영역 → 인쇄 영역 설정
2없앨 때는 인쇄 영역 해제를 고릅니다
3프린터 선택은 페이지 설정이 아니라 인쇄 화면(Ctrl+P)에서 합니다
인쇄 미리 보기

미리 보기에서도
여백을 끌어 맞춥니다

1인쇄 미리 보기 오른쪽 아래의 여백 표시를 누르면 여백선과 열 너비 조절점이 나타납니다
2선과 조절점을 드래그하면 되고, 열 너비를 바꾸면 실제 워크시트에도 반영됩니다
3여백선으로 대략 맞춘 뒤 페이지 설정의 여백 탭에서 정확한 수치를 맞출 수 있습니다
4미리 보기 오른쪽 아래의 확대/축소는 화면 크기만 바꿀 뿐 실제 인쇄 크기에는 영향이 없습니다
페이지 나누기 미리 보기

점선은 자동,
실선은 수동

1보기 → 페이지 나누기 미리 보기에서 쪽 경계를 봅니다
2엑셀이 잡은 자동 나누기는 점선, 사용자가 넣었거나 끌어서 옮긴 수동 나누기는 실선입니다
3자동 선을 끌어 옮기면 실선으로 바뀌고, 수동 선을 쪽 바깥으로 끌면 제거됩니다
4행 높이·열 너비를 바꾸면 자동 나누기 위치가 함께 달라집니다
5나누기 미리 보기와 페이지 레이아웃 보기에서도 데이터를 입력·편집할 수 있습니다. 페이지 레이아웃 보기에는 머리글·바닥글 영역이 보입니다
정렬 · 기본

점수는 내림차순,
순위는 오름차순

1오름차순은 작은 값에서 큰 값(가나다순), 내림차순은 큰 값에서 작은 값입니다
2이름·번호는 보통 오름차순, 점수는 높은 사람이 먼저 오도록 내림차순입니다
3등급, 달리기 기록처럼 숫자가 작을수록 좋은 데이터는 오름차순입니다
4오름차순 순서: 숫자 → 특수문자 → 영문 → 한글 → 논리값(FALSE → TRUE) → 오류값. 빈 셀은 오름차순·내림차순 모두 맨 마지막입니다
정렬 · 대화 상자

기준은 최대 64개,
색으로도 정렬합니다

1데이터 → 정렬 대화 상자에서 정렬 기준을 여러 개 추가합니다. 기준은 최대 64개입니다
2정렬 기준은 셀 값뿐 아니라 셀 색 · 글꼴 색 · 조건부 서식 아이콘도 됩니다. 색은 실제로 지정된 색만 목록에 나옵니다
3옵션에서 왼쪽에서 오른쪽을 고르면 행이 아니라 열 전체가 재배치됩니다 (뒤섞인 1월·2월·3월 열을 순서대로 놓을 때)
4대/소문자 구분도 옵션에 있습니다
정렬 · 사용자 지정 목록

직급 순서는
목록으로 만듭니다

1직급(부장 · 차장 · 과장 · 대리 · 사원)은 오름차순·내림차순으로 원하는 서열을 만들 수 없어서 사용자 지정 목록을 씁니다
2정렬 대화 상자의 순서에서 사용자 지정 목록을 고르고, 항목을 입력한 뒤 반드시 추가를 눌러 목록에 보이게 한 다음 선택합니다
3사용자 지정 목록은 정렬 기준이 셀 값일 때만 쓸 수 있습니다
정렬 전에 풀어 둘 것병합된 셀이 섞여 있으면 정렬되지 않고(병합 셀의 크기가 같아야 합니다), 숨긴 행·열의 데이터는 정렬에 포함되지 않고 제자리에 남습니다. 정렬하기 전에 병합과 숨기기를 풀어 두세요.
자동 필터

필터는 지우는 게
아니라 숨기는 것

1데이터 → 필터(Ctrl+Shift+L)를 누르면 필드명마다 목록 단추(▼)가 생깁니다
2모두 선택을 해제하고 원하는 항목(예: 대리)만 체크하면 그 데이터만 보입니다. 안 보이는 행은 삭제된 것이 아니라 숨겨진 것입니다
3필터가 걸린 필드는 단추 모양이 달라지고 행 번호 색이 바뀌어 적용 여부를 알 수 있습니다
4서로 다른 필드에 걸면 두 조건을 모두 만족하는 행만 남습니다 (그리고)
5필터 결과만 Ctrl+P 로 인쇄하거나 다른 곳에 복사할 수 있습니다
자동 필터 · 숫자 필터

비교 연산자는
정해진 순서로 씁니다

기호뜻
>=이상 (크거나 같음)
<=이하 (작거나 같음)
>초과
<미만
<>같지 않음
1기호의 순서를 바꿔 쓰면 안 됩니다. 이상은 >= 이고 => 는 틀립니다
2숫자 필터에서 크거나 같음에 90 을 넣으면 90점 이상만 보입니다
3상위 10 필터는 상위 항목 수뿐 아니라 상위 백분율(%)도 고를 수 있습니다. 예) 지원자 상위 10%만 1차 합격
4서로 다른 필드를 또는으로 묶는 조건(부서가 A이거나 직급이 대리)은 자동 필터로 처리하기 어렵고 고급 필터를 씁니다. 고급 필터는 다음 수업에서 배웁니다
오늘의 함정

여기서 많이 틀립니다

1인쇄 미리 보기에서 반복할 행을 지정하려고 함
미리 보기에서는 비활성화됩니다. Esc로 나와 페이지 레이아웃에서 설정합니다.

3틀 고정을 인쇄에도 적용된다고 생각함
제목을 반복 인쇄하는 것은 반복할 행입니다.
4회색 영역의 데이터가 지워진 줄 앎

6필터가 행을 삭제한다고 생각함
숨길 뿐이고 해제하면 모두 돌아옵니다.
7#,###과 #,##0 의 0 표시를 같다고 생각함
#,### 은 0을 감추고 #,##0 은 0을 보여 줍니다.
