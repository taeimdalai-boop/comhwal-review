DAY 1 — 엑셀과 첫 만남

실기: 실행·화면 구성·데이터 입력  |  필기: 데이터 인식 규칙  ·  예상 소요 60~90분

오늘의 지도 — 실기화면 구성 요소 → 셀 이동 → 입력 기술 3가지   필기문자냐 숫자냐(정렬 규칙) → 날짜의 정체 → Alt+F4 vs Ctrl+F4
한 줄 요약: "엑셀은 화면 구성 요소와 단축키를 정확히 아는 만큼 손이 빨라진다."

실기1. 화면 구성 — 이름 상자와 수식 입력줄

  • 이름 상자: 지금 선택한 셀의 주소(예: B2)를 보여줍니다.
  • 수식 입력줄: 셀의 실제 입력 내용을 보여줍니다. 화면엔 7이 보여도 실제로는 =5+2가 입력돼 있을 수 있어요.
  • 리본 메뉴 최소화/표시: Ctrl+F1 (탭 이름 더블클릭도 동일)
  • 새 시트 추가: Shift+F11 · 화면 확대/축소: Ctrl+마우스 휠
현재 선택한 셀의 실제 입력 내용(수식 등)을 확인할 수 있는 곳은?
정답: 수식 입력줄. 이름 상자는 셀 주소, 상태 표시줄은 평균·개수 등 요약 정보.

실기2. 셀 포인터 이동 — 마우스 없이 표 만들기

키이동 방향비고
Enter / Shift+Enter아래 / 위이동 방향은 옵션에서 변경 가능
Tab / Shift+Tab오른쪽 / 왼쪽범위 선택 시 범위 안에서만 이동

표를 입력할 때 오른손은 숫자, 왼손은 Tab — 마우스를 놓는 순간 입력 속도가 2배가 됩니다.

실기3. 데이터 입력 기술 3가지

① Alt+Enter vs Ctrl+Enter — 이름이 비슷해서 실수 1위

  • Alt+Enter: 셀 하나 안에서 줄바꿈. (예: "울산" 다음 Alt+Enter → "우리컴퓨터학원")
  • Ctrl+Enter: 범위를 먼저 선택하고 내용 입력 후 누르면 선택한 모든 셀에 같은 내용이 한 번에 입력.
"여러 셀에 동일한 값을 한 번에 입력하는 방법은?" → 정답은 Ctrl+Enter. Alt+Enter를 고르게 만드는 함정이 단골로 나옵니다.

② 입력 취소 3형제 — Esc / Backspace / Ctrl+Z

키언제 쓰나
Esc입력 중인 내용(아직 Enter 안 누름)을 통째로 취소
Backspace글자를 한 글자씩 지움
Ctrl+Z이미 완료된 명령(입력·서식 등)을 되돌림
시트를 삭제한 뒤 Ctrl+Z를 누르면?
정답: 복원되지 않는다(영구 삭제). 대부분 되돌려지지만 시트 삭제만은 예외 — 이 예외가 시험 포인트.

③ 날짜·시간 즉시 입력

  • 오늘 날짜: Ctrl+;  ·  현재 시간: Ctrl+Shift+;
DAY 1 손 풀기 (엑셀 켜고 3분)
① A1에 자기 이름 입력 → Tab으로 B1 이동 확인   ② B1에서 Alt+Enter로 두 줄 주소 입력   ③ A3:C3 선택 → "확인" 입력 → Ctrl+Enter로 한 번에 채우기   ④ D1에 Ctrl+; 눌러 오늘 날짜 입력 → 정렬 방향(오른쪽!) 확인 — 이 "오른쪽"의 이유는 아래 필기 파트에서.

필기4. 문자냐 숫자냐 — 판별 순서로 외우기

정렬 방향, 자동완성, 계산 가능 여부가 전부 이 판별에서 시작됩니다.

  • ① 숫자만 있으면 숫자 데이터 → 오른쪽 정렬
  • ② 문자가 하나라도 섞이면 무조건 문자 데이터 → 왼쪽 정렬 ("2급"은 왼쪽, "70"은 오른쪽)
  • ③ 날짜·시간 형식으로 인식되면 예외적으로 오른쪽 정렬
  • 자동완성은 문자 데이터 전용 — 숫자·날짜·시간은 앞부분이 같아도 자동완성되지 않음
"2급"처럼 숫자와 문자가 섞인 데이터의 기본 정렬은?
정답: 왼쪽 정렬 — 문자가 하나라도 섞이면 문자 데이터.

필기5. 날짜의 진짜 정체 — "숫자를 날짜처럼 보여주는 것"

  • 기준: 1900년 1월 1일 = 1, 하루 지날 때마다 1씩 증가하는 일련번호(숫자)로 저장
  • 시간: 하루를 1로 보고 0~1 사이 소수 (자정=0, 낮 12시=0.5)
  • 두 자리 연도: 00~49는 2000년대, 50~99는 1900년대 (31-7-6 → 2031년, 50-7-6 → 1950년)
"날짜와 시간이 왜 오른쪽 정렬인가?" → 내부적으로 숫자로 저장되기 때문. 이 한 문장이 정렬·계산·함수 문제 전부를 관통합니다.

필기6. Alt+F4 vs Ctrl+F4 — 브라우저 탭으로 이해하기

  • Alt+F4: 프로그램 전체 종료 (바탕화면에서 누르면 Windows 종료 대화상자)
  • Ctrl+F4: 프로그램은 그대로, 현재 문서·탭 하나만 닫음
  • 함정: 탭이 1개만 남았을 때 Ctrl+F4를 누르면 프로그램 자체가 종료될 수 있음 — "탭 개수에 따라 결과가 달라진다"까지 기억

🚨 DAY 1 — 이렇게 실수해요 (실강 수강생 실제 사례)

전화번호를 숫자로 입력해서 앞자리 0이 사라져요
010으로 시작하는 번호를 그냥 입력하면 엑셀이 숫자로 인식해 맨 앞 0을 지웁니다.
앞에 작은따옴표(')를 붙여 '01012345678로 입력 → 문자 데이터가 되어 0이 유지됩니다.
#### 표시를 오류라고 오해해요
숫자·날짜가 셀 너비보다 길면 ####로 표시될 뿐, 값이 틀린 게 아닙니다.
열 머리글 경계를 드래그(또는 더블클릭)해 열 너비를 넓히면 정상 표시.
자동완성이 숫자나 날짜에도 될 거라고 생각해요
같은 열에 앞부분이 같은 문자를 입력할 때만 자동완성됩니다.
자동완성 = 문자 데이터 전용. 숫자·날짜·시간은 적용 안 됨.
시트를 삭제한 뒤 Ctrl+Z로 되돌리려 해요
시트 삭제는 예외적으로 영구 삭제 — 복원 불가.
삭제 전 한 번 더 확인하는 습관. (시험에서도 이 예외를 묻습니다)
