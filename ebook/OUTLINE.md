## 교재 구성 원칙

1. 차시(수업 순서)가 아니라 **시험 과목 순서**로 재배열한다 — 독자는 내 수업을 안 들은 사람이다.
2. 각 챕터 공통 골격 (기존 복습자료 구조 그대로 재활용):
   - 핵심 개념 요약카드 → 그림/도해 → **"이렇게 실수해요"(함정 모음)** → 기출 포인트 → 데일리 퀴즈 10문항
3. "이렇게 실수해요" 섹션은 실강에서 나온 실제 수강생 실수 — **경쟁 교재가 못 베끼는 차별점**이므로 전 챕터에 필수 포함.
4. 퀴즈는 앱과 연동: 챕터 끝 QR → 스무날 동행 앱 해당 Day 퀴즈.

## 목차 ↔ 차시 매핑표 (★필기·실기 동시 진행 — 우리 과정 구조 그대로)

> 매일 = **실기 파트 + 필기 파트** 이중 트랙. 필기를 뒤로 몰지 않고 실강처럼 매일 병행한다.
> 실기는 실습 흐름 순서, 필기(컴퓨터일반)는 하드웨어→소프트웨어→인터넷→멀티미디어→보안 순으로 분산 배치.

| Day | 실기 파트 (스프레드시트) | 필기 파트 | 원료 차시 |
|---|---|---|---|
| 1 | 실행·화면구성·데이터 입력 (이름상자/수식입력줄, Alt+Enter vs Ctrl+Enter, 입력취소 3형제) | 데이터 인식 규칙 (문자/숫자 판별·정렬, 날짜=일련번호, Alt+F4 vs Ctrl+F4) | **1차시** |
| 2 | 편집 도구 (채우기핸들·유효성검사·메모·윗주·찾기바꾸기) | Windows 기본 (바로가기 키, 파일·폴더 관리, 휴지통) | **2·3차시** + 샘플ch1 |
| 3 | 표시형식·시트보호·틀고정·문서암호 | Windows 설정 (제어판 경계, 작업관리자, 레지스트리) | **3·4차시** + 샘플ch1 |
| 4 | 인쇄 설정·페이지 나누기 | 프린터와 스풀, 디스크 관리·조각모음·메모장 | **4·5·12차시** |
| 5 | 정렬·자동필터·고급필터 기초 | 자료 표현 단위·진법 변환 (★단골, 수강생 제보 문제) | **5·13차시** |

| 8 | SUMIF/SUMIFS·COUNTIF·DB 함수 | CPU 구조 (제어장치+연산장치) | **6·13차시** |

| 11 | 텍스트 함수(LEFT/MID/RIGHT/FIND/TRIM)·RANK·SMALL/LARGE | 소프트웨어 사용권·컴파일러 vs 인터프리터 | **7·9·15차시** |

| 14 | 조건부서식(수식 조건) | 인터넷② IP·프로토콜·포트·이메일 | **10·15차시** |
