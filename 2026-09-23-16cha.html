📌오늘 배운 핵심 요약

[필기] 6장은 용어를 외웁니다

강사가 수업 중에 "상담해 보니 6장을 제일 어려워한다"고 했습니다. 새로 생각할 게 있는 단원이 아니라 이름과 역할을 짝지어 외우는 단원이라서 그렇습니다.

먼저 외울 자리를 정하고 시작하세요

[필기] 전송 방식 세 개 — 예시로 외웁니다

단방향=TV·라디오, 반이중=무전기, 전이중=전화·인터넷. 인터넷을 반이중으로 고르는 실수가 많습니다.

「동시에 되느냐」를 확인하세요

★[필기] 장비 여섯 개는 한 단어씩

NIC=랜카드, 허브=회선 모음, 리피터=신호 증폭, 브리지=LAN끼리, 라우터=최적 경로, 게이트웨이=다른 네트워크 출입구.

신호 변환은 장비가 아니라 «모뎀»

★[필기] IPv4와 IPv6 — 가장 많이 나옵니다

IPv4는 8비트 × 4칸 = 32비트, 10진수, 점(.). IPv6는 16비트 × 8칸 = 128비트, 16진수, 콜론(:).

숫자를 서로 바꿔 내는 문제가 단골

[필기] 메일은 보내기·받기를 구분합니다

SMTP=보낼 때, POP3=받을 때, MIME=메일 안의 그림·동영상 같은 파일을 다루게 해 주는 표준.

SMTP는 Simple Mail Transfer Protocol

[실기] 기출은 «기본 작업 2번»부터

1번 입력 문제는 시간이 오래 걸리고 배점은 작습니다. 2번 셀 서식부터 시작해 클릭으로 끝나는 점수를 먼저 챙기고, 입력은 마지막에 합니다.

시트 이름과 셀 포인터부터 확인

[실기] 고급 필터 — 필드만 뽑을 때

원하는 열만 결과로 뽑으려면 복사 위치에 필드명을 먼저 붙여넣고, 그 필드명 범위 전체를 복사 위치로 지정합니다.

한 셀만 찍으면 전체 열이 다 나옵니다

[실기] 차트 제목은 «수식 입력줄»로

제목을 셀과 연동하라는 지시가 나오면 제목을 한 번 클릭해 테두리를 만든 뒤, 수식 입력줄에 =시트!$A$1을 넣습니다. 직접 타이핑하면 오답입니다.

글자가 같아도 연동이 아니면 감점

먼저 — 오늘 배운 순서

1교시 5장 빠른 복습(SATA · PC 관리 장치 · 소프트웨어 분류 · 운영체제 · 언어) → 6장 시작(정보 통신의 이해 · 전송 방식 · 네트워크 운영 방식 · 통신망 종류).
2교시 네트워크 장비 6종 → 인터넷·인트라넷·엑스트라넷 → 주소 관리 기관 → IPv4 · IPv6 → 도메인·DNS·URL → 프로토콜·OSI 7계층 → 전자우편·FTP·WWW.
3교시 웹 브라우저와 쿠키 → ICT 신기술 13가지 → 여기서 실기 기출 풀이 시작(기본 작업 2번 · 셀 서식 · 표시 형식 · 이름 정의 · 고급 필터).
4교시 분석 작업(피벗 · 시나리오) → 기타 작업(매크로 · 차트) → 계산 작업 함수 5문제 → 마지막에 기본 작업 1번 입력.
어제 퀴즈는 전 문항 77% 이상이었습니다(평균 9.2 · 9월 들어 가장 높음). 다시 짚어야 할 문항이 없어 오늘은 새 내용에 전부 배정했습니다.

📡 [필기] 정보 전송 방식 — 「동시에 되느냐」를 확인합니다

단방향 한쪽은 보내기만, 한쪽은 받기만. TV · 라디오가 예시입니다.
반이중 양쪽 다 보내고 받지만 동시에는 안 됩니다. 무전기가 예시예요. 말할 때는 못 듣습니다.
전이중 보내면서 동시에 받습니다. 전화 · 인터넷이 예시입니다(교재 기준).
인터넷을 반이중으로 고르는 실수가 가장 많습니다. 전화 통화를 떠올리면 됩니다 — 둘이 동시에 말해도 소리가 갑니다.

🌐 [필기] 통신망 종류와 네트워크 운영 방식

범위 순서 LAN › MAN › WAN — 근거리 → 도시권 → 광역. 순서를 묻습니다.
무선 LAN에 필요한 것 세 가지 — 무선 랜카드 · AP(액세스 포인트) · 안테나.
클라이언트/서버 서버가 따로 있고 나머지는 받아 쓰는 방식.
P2P(동배간) 각 컴퓨터가 서버도 되고 클라이언트도 됩니다. 전용 서버가 없어 구성은 간단하지만 중앙에서 관리하기 어려워 보안과 자료 관리에 불리합니다. 파일을 주고받다 악성코드에 감염되거나 개인정보가 새어 나갈 수 있습니다.

★🔌 [필기] 네트워크 장비 여섯 개 — 한 단어씩 붙여 외웁니다

NIC 랜카드. 컴퓨터를 네트워크에 붙이는 카드.
허브 여러 회선을 한곳에 모아 연결해 주는 집선 장치입니다.
리피터 멀리 가면서 약해진 신호를 증폭·재생합니다.
브리지 LAN과 LAN을 연결합니다.
라우터 최적 경로를 찾아 줍니다. 보기에 「최적 경로」가 나오면 라우터입니다.
게이트웨이 서로 다른 네트워크 사이의 출입구. 고정 IP를 넣을 때 적는 「기본 게이트웨이」가 이것입니다.
주의 — 신호를 바꾸는 건 장비 여섯 개가 아니라 «모뎀»입니다. 아날로그 ↔ 디지털을 변환하는 변복조 장치. 브리지 설명에 이 내용을 끼워 넣어 틀린 보기를 만듭니다.

★🌐 [필기] IPv4와 IPv6 — 오늘 가장 중요합니다

강사가 "이건 꼭 외워야 한다"고 못 박은 부분입니다. 숫자를 서로 바꿔 놓고 묻는 문제가 단골로 나옵니다.
IPv4 — 8비트씩 4부분, 합쳐서 32비트. 10진수로 쓰고 점(.)으로 나눕니다. 예: 192.168.0.1
IPv6 — 16비트씩 8부분, 합쳐서 128비트. 16진수로 쓰고 콜론(:)으로 나눕니다. 0이 이어지면 콜론으로 줄여 쓸 수 있습니다.
IPv6가 왜 나왔나 IPv4 주소가 모자라서입니다. 덤으로 보안성·확장성·융통성·연동성이 좋아졌습니다.
IPv6 주소 세 가지 유니캐스트(1 대 1) · 멀티캐스트(1 대 다) · 애니캐스트(가장 가까운 하나). IPv6에는 브로드캐스트가 없습니다 — 이 점을 구분 포인트로 냅니다.

🔗 [필기] 도메인 · DNS · URL

도메인 네임 숫자로 된 IP 주소를 사람이 외우기 쉽게 바꾼 문자 주소입니다.
DNS 도메인 네임을 IP 주소로 바꿔 주는 서비스. 「변환」이라는 단어가 붙습니다.
주소 관리 기관 국내는 KISA(한국인터넷진흥원), 국제는 ICANN.
URL 순서 프로토콜 → 호스트(서버 주소) → 포트 번호 → 파일 경로. 포트 번호와 경로는 생략할 수 있습니다. 순서를 바꿔 내는 문제가 나옵니다.

✉️ [필기] 프로토콜 — 보내기와 받기를 구분합니다

프로토콜 컴퓨터끼리 통신할 때 지키는 약속(규약)입니다. 계층 구조의 기본은 OSI 7계층.
SMTP 메일을 보낼 때. 정식 이름은 Simple Mail Transfer Protocol입니다.
POP3 메일을 받을 때 — 서버에 있는 메일을 내 컴퓨터로 내려받습니다. (수신에는 IMAP도 쓰입니다.)
MIME 메일에 글자 말고 그림·동영상·첨부 파일을 실을 수 있게 해 주는 확장 표준입니다. 이름 그대로 Multipurpose Internet Mail Extensions.
나머지 FTP=파일 전송, HTTP=하이퍼텍스트 문서 전송, WWW=인터넷 정보를 거미줄처럼 연결한 서비스(프로토콜이 아닙니다), HTML=웹 문서를 만드는 언어(역시 프로토콜이 아닙니다).

💡 [필기] ICT 신기술 — 키워드 한 단어로 구분합니다

클라우드 컴퓨팅 하드웨어·소프트웨어를 빌려 씁니다. 내 컴퓨터에 안 깔고 인터넷으로.
그리드 컴퓨팅 흩어진 컴퓨터를 묶어 한 대의 고성능 컴퓨터처럼 씁니다.
스마트 그리드 전기의 생산부터 소비까지 관리하는 지능형 전력망.
IoT(사물 인터넷) 사물에 인터넷을 붙여 데이터를 주고받습니다. 보안이 쉬워진다는 보기는 틀립니다 — 오히려 연결이 늘어 보안 걱정이 커집니다.
RFID 전자태그로 인식 · USN 센서로 온도·습도·위치를 수집·감시.
텔레매틱스 자동차 + 통신 · LBS 위치 기반 · 와이브로 이동하면서 쓰는 무선 인터넷 · 핀테크 금융 + IT(카카오페이·토스).

📝 [실기] 기출은 «기본 작업 2번»부터 — 오늘 배운 푸는 순서

왜 2번부터인가 기본 작업 1번은 입력 문제라 타자 시간이 오래 걸립니다. 배점은 작은데 시간을 많이 먹어요. 그래서 클릭으로 끝나는 2번 셀 서식부터 잡고, 입력은 맨 마지막에 합니다.
문제를 열면 먼저 ① 시트 이름을 확인하고 ② 셀 포인터를 문제가 말한 위치에 둡니다. 기본 작업 1 시트에서 2번 문제를 푸는 실수가 가장 흔합니다.
셀 서식에서 나오는 것 병합하고 가운데 맞춤 · 글꼴과 크기 · 셀 스타일(예: 황금색, 강조 4) · 글꼴 색 · 굵게·기울임 · 테두리. 지시문에 적힌 이름 그대로 찾습니다. 테마 색과 표준 색은 다른 칸이니 이름을 확인하세요.
사용자 지정 표시 형식 #,##0.00원 같은 형태 — #,##0은 천 단위 쉼표, .00은 소수 둘째 자리까지, 원은 뒤에 붙는 글자입니다.
이름 정의 하나씩이면 이름 상자에 직접, 여러 개를 한꺼번에면 범위를 잡고 수식 → 선택 영역에서 만들기(Ctrl+Shift+F3)로 첫 행이나 왼쪽 열 값을 이름으로 씁니다.

🔍 [실기] 고급 필터 — 원하는 «열»만 뽑을 때

기본 순서 빈 곳에 조건 목록을 만들고 → 데이터 탭 → 고급 → 목록 범위 · 조건 범위 · 복사 위치 세 칸을 채웁니다.
조건 배치 같은 줄에 쓰면 AND(둘 다), 다른 줄에 쓰면 OR(둘 중 하나)입니다.
원하는 필드만 뽑으라면 — 복사 위치에 아무 셀이나 찍으면 전체 열이 다 나옵니다. 먼저 결과가 들어갈 자리에 필드명을 복사해 붙여넣고, 그 필드명 범위 전체를 복사 위치로 지정해야 그 열만 나옵니다.
조건 목록의 필드명도 원본에서 복사해서 씁니다. 손으로 치면 띄어쓰기나 글자가 달라져 결과가 안 나옵니다.

📊 [실기] 분석·기타 작업에서 오늘 다시 나온 것

피벗 테이블 삽입 탭에서 만들고 행·열·값에 필드를 놓습니다. 값을 «합계»가 아니라 «최대»로 바꾸라는 지시를 놓치는 일이 잦습니다 — 값 필드를 눌러 값 필드 설정에서 바꿉니다.
시나리오 변경 셀과 결과 셀을 정하고 요약을 만듭니다. 이름 정의를 먼저 해 두면 요약 보고서에 셀 주소 대신 이름이 찍힙니다. 요약을 만들 때 «표시» 단추를 누르면 원본 값이 바뀌어 버립니다 — 누르지 말고 요약으로 갑니다.
매크로 셀 포인터를 바깥에 두고 → 기록 → 작업 → 기록 중지 → 단추나 도형에 지정 → 눌러서 검증. 지정만 하고 안 눌러 보면 틀린 채로 제출됩니다.
차트 데이터 범위 수정 · 특정 계열만 꺾은선으로 바꾸는 혼합 차트 · 값 차이가 크면 보조 축 · 계열 겹치기(음수면 막대가 벌어집니다) · 간격 너비(항목 사이 간격) · 도형 스타일.
차트 제목을 셀과 연동하라면 제목을 한 번 눌러 테두리를 만든 뒤 수식 입력줄에 =를 치고 셀을 클릭합니다. 글자를 직접 타이핑하면 보기엔 같아도 연동이 아닙니다.

🧮 [실기] 계산 작업 — 오늘 푼 함수 다섯 문제

① INDEX + MATCH + DMAX 조건에 맞는 최댓값을 DMAX로 찾고 → 그 값이 몇 번째 줄인지 MATCH로 찾고 → 그 줄의 다른 열 값을 INDEX로 가져옵니다. 안쪽부터 차례로 씁니다.
② HLOOKUP + RANK.EQ RANK.EQ로 순위를 구하고 → 그 순위로 기준표에서 지급률을 찾습니다. 기준표는 찾을 값이 들어 있는 행이 맨 위가 되도록 잡고, 수식을 복사할 것이므로 절대참조(F4)를 겁니다. 점수 순위는 높을수록 1등이라 내림차순(0 또는 생략)입니다.
③ IF + MEDIAN MEDIAN으로 중간값을 구해 「이상이면 ○○」을 판정합니다.
④ CHOOSE + INT + AVERAGE 평균을 INT로 정수로 만든 뒤 그 숫자로 CHOOSE에서 문구를 고릅니다. 해당 없는 자리는 빈칸이 아니라 ""를 넣어야 합니다.
⑤ MODE.SNGL + COUNTIF 가장 많이 나온 값을 MODE.SNGL로 찾고, 그 값이 몇 개인지 COUNTIF로 셉니다.
마지막 한 글자에서 8점이 날아갑니다 — 「~권」, 「~명」처럼 뒤에 붙이라는 글자를 빠뜨리는 실수. 수식 뒤에 &"권"을 붙입니다.
