필기 · 파일 탐색기

탐색 창 · 목록 · 미리 보기

1윈도우 10의 파일 탐색기는 파일 · 홈 · 공유 · 보기로 구성된 리본 메뉴를 씁니다 (윈도우 11은 화면이 다릅니다)
2왼쪽 탐색 창은 파일과 폴더를 계층 구조로 보여 줍니다. 화살표가 아래쪽이면 하위 항목이 펼쳐진 상태, 오른쪽이면 펼칠 수 있는 상태입니다
3미리 보기 창은 문서를 열지 않고 내용을 확인할 때 씁니다. 사진은 큰 아이콘으로, 일반 파일은 자세히 보기로 두면 편합니다
4자세히 보기에서 이름 · 날짜 같은 필드명을 누르면 오름차순 · 내림차순으로 정렬됩니다
필기 · 숨김

숨김 속성과 숨긴 항목 표시

1확장명 표시를 켜면 .exe .xlsx .png .hwp .hwpx 같은 확장명이 보입니다
2파일 속성에서 숨김을 지정해도 숨긴 항목 표시가 켜져 있으면 흐리게 보입니다. 완전히 감추려면 숨김 속성과 표시 설정을 함께 처리합니다
3보호된 운영 체제 파일은 잘못 지우면 시스템이 동작하지 않을 수 있어 기본적으로 숨겨져 있습니다
4숨김 속성은 폴더 옵션에서 일괄 해제할 수 없고, 각 항목의 속성에서 해제합니다
5대화 상자의 적용은 창을 남겨 두고 적용하고, 확인은 적용한 뒤 창을 닫습니다
필기 · 폴더 옵션

클릭 방식 · 최근 파일 · 검색

1기본 설정은 파일을 두 번 클릭해서 여는 것입니다. 한 번 클릭해서 열기로 바꾸면 내용을 보려고 클릭만 해도 창이 열려 잘 쓰지 않습니다
2공용 PC에서는 개인 정보 보호 항목에서 최근에 사용한 파일을 표시하지 않도록 끌 수 있습니다
3검색 옵션에서 색인되지 않은 위치도 파일 이름과 내용을 함께 검색하도록 설정할 수 있고, 이때 검색 속도가 느려질 수 있습니다
필기 · 디스크 포맷

포맷할 때 보는 항목

1포맷은 저장 장치를 초기화하는 작업입니다. 파일 시스템(FAT32 · NTFS · exFAT)을 고릅니다
2할당 단위 크기는 데이터를 저장하는 블록 크기이며 기본값을 쓰는 것이 적절합니다. 볼륨 레이블은 장치에 표시할 이름입니다
3빠른 포맷은 파일 위치 정보를 새로 만드는 방식이라, 지운 자료가 복구 프로그램으로 되살아날 수 있습니다
4내가 계속 쓸 장치는 빠른 포맷을 써도 되지만, 남에게 주거나 판매할 장치는 빠른 포맷만으로 충분하지 않으므로 매체에 맞는 안전한 삭제 절차를 따라야 합니다
필기 · 파일 · 폴더

이름 · 속성 · 바로가기

1한 폴더 안에는 같은 이름의 파일이나 폴더가 함께 존재할 수 없습니다. 이름은 최대 255자이고 위 9개 문자는 쓸 수 없지만 공백은 쓸 수 있습니다
2일반 폴더의 속성 창에서는 위치와 하위 폴더 · 파일 개수를 확인할 수 있고, 여기서 위치를 옮기거나 특정 하위 폴더만 삭제할 수는 없습니다
3하나의 파일 · 폴더에 바로가기 아이콘을 여러 개 만들 수 있습니다
4디스크에 자료가 저장되는 기본 단위는 폴더가 아니라 파일입니다

필기 · 휴지통

휴지통을 거치지 않는 삭제

1휴지통은 삭제한 파일을 임시 보관하는 곳이며, 드라이브별로 각 드라이브의 $Recycle.Bin 폴더에 구성됩니다 (C 드라이브의 것이 대표적)
2위 경우(이동식 USB나 네트워크 드라이브는 구성에 따라 다를 수 있음)와 덮어쓴 파일은 휴지통에 보관되지 않습니다. 삭제하려는 파일이 해당 드라이브의 휴지통 최대 용량보다 크면 보관되지 않고 바로 삭제됩니다
3Shift+Delete는 휴지통을 거치지 않고 바로 삭제하는 키입니다
4삭제 전에 확인하는 습관이 안전합니다. 명령어로 파일을 지우는 도구는 휴지통을 거치지 않을 수 있습니다

3윈도우가 사용자 편의를 위해 제공하는 메모장 · 워드패드 · 그림판 · 계산기 같은 프로그램을 유틸리티라고 합니다

필기 · 시스템 · 개인 설정 · 앱

디스플레이 · 개인 설정 · 앱

1디스플레이 — 여러 모니터는 복제 또는 확장하고, 원하는 화면을 주 모니터로 지정할 수 있습니다. 주 모니터가 꼭 왼쪽일 필요는 없습니다
2해상도는 화면을 구성하는 픽셀의 수입니다. 모니터의 기본(권장) 해상도에서 가장 선명하고, 같은 배율에서는 해상도가 높을수록 아이콘이 상대적으로 작아 보입니다
3개인 설정 — 배경, 테마색, 잠금 화면, 화면 보호기, 글꼴, 시작 메뉴 · 작업 표시줄 설정이 있습니다. 화면 보호기는 같은 화면이 오래 표시되어 생기는 잔상을 줄이려고 움직이는 화면을 보여 줍니다
4앱 — 프로그램 제거, 확장자별 기본 앱, 시작 프로그램을 관리합니다. 시작 프로그램이 많으면 부팅 시간이 길어질 수 있습니다
필기 · 계정 · 접근성

사용자 계정과 접근성 기능

1관리자 계정은 표준 사용자보다 넓은 권한으로 시스템 설정을 변경할 수 있습니다(필요하면 승인을 거침). 표준 사용자 계정은 설치된 앱 실행과 개인 테마 · 바탕 화면 · 암호 설정 등은 가능하지만, 하드웨어 · 앱 설치와 시스템 · 보안 설정 변경 등은 제한됩니다. 이름과 달리 모든 작업이 가능한 계정은 아닙니다
2접근성은 몸이 불편하거나 화면을 보기 어려운 사용자를 돕는 기능입니다. 텍스트 · 마우스 포인터 · 커서 확대와 색 변경, 돋보기, 내레이터, 고정 키 등이 있습니다
3돋보기 단축키: 실행 Win++, 종료 Win+Esc, 전체 화면 Ctrl+Alt+F, 렌즈 Ctrl+Alt+L, 도킹 Ctrl+Alt+D
복습 · 10차시

다시 짚어 두는 3가지

1FAT32 — 파일 하나의 크기가 약 4GB 미만(정확히는 4GiB−1바이트까지)이어야 합니다. 10GB 같은 큰 영상 파일은 FAT32 USB에 저장되지 않습니다. 여러 운영체제에서 대용량 파일을 쓰려면 exFAT이 적합합니다
2작업 표시줄 우클릭의 계단식 · 가로 · 세로 정렬은 열려 있는 창을 배열합니다. 아이콘 정렬이 아닙니다
3중첩 IF — 결과가 4가지이고 마지막 결과를 거짓 값으로 처리하면 IF는 3개입니다. 다음 질문은 앞 IF의 거짓 자리에 넣습니다
실기 · 텍스트 나누기

구분 기호로 열을 나눕니다

1CSV는 쉼표로 값을 구분해 저장하는 텍스트 형식입니다
2한 열에 몰린 데이터를 선택하고 데이터 탭 › 텍스트 나누기를 실행합니다. 1단계에서 구분 기호로 분리됨을 고릅니다
32단계에서 쉼표나 세미콜론 같은 구분 기호를 지정하면 미리 보기에서 열이 나뉘는 모습을 확인할 수 있습니다
43단계에서는 열마다 데이터 서식을 지정하거나, 필요 없는 열을 선택하고 열 가져오지 않음(건너뜀)을 지정합니다. 이 위치를 자주 못 찾으므로 기억해 둡니다
실기 · 고급 필터

함수식을 조건으로 쓰는 고급 필터

1생년월일에서 월이 5월인 자료를 뽑으려면 MONTH 함수로 월을 구하는 수식 조건을 만듭니다. 예) =MONTH(B4)=5 (B4는 데이터의 첫 번째 레코드의 생년월일 셀)
2조건에 함수나 수식을 쓸 때는 조건 영역의 필드명을 생략하거나 원본 필드명과 다른 이름으로 적습니다. «월», «조건»처럼 원본에 없는 이름이면 됩니다
3일반 조건(>=80 등)과 달리, 수식 조건에는 원본 필드명을 그대로 쓰지 않는다는 점이 핵심입니다
4같은 행에 놓은 조건은 AND, 서로 다른 행에 놓은 조건은 OR로 처리됩니다
실기 · 부분합

부분합은 정렬이
먼저입니다

1부분합은 자동으로 정렬해 주지 않습니다. 그룹 기준 필드를 먼저 정렬한 뒤 실행합니다. 그룹 기준은 문제의 «○○별»에 해당하는 필드입니다
2대화 상자에서 그룹화할 항목, 사용할 함수, 부분합 계산 항목을 지정합니다. 계산 항목은 기존 체크 상태를 믿지 말고 스크롤하며 모두 확인합니다
3윤곽 단추 1은 총합계만, 2는 그룹별 요약, 3은 전체 세부 데이터를 보여 줍니다
4잘못 만들었으면 직접 고치려 하지 말고 모두 제거한 뒤 처음부터 다시 작성합니다
실기 · 부분합 · 기출 작업

두 번째 부분합은
«대치»를 해제합니다

1다중 기준 정렬은 열의 정렬 단추를 차례로 누르지 말고 정렬 대화 상자에서 기준을 추가합니다
2두 번째 부분합을 기존 결과를 유지하며 누적하려면 새로운 값으로 대치를 해제합니다. 첫 번째 부분합을 만들 때나 기존 결과를 교체할 때는 선택된 상태입니다
3수행 순서가 중요합니다. 같은 그룹에 기본 설정으로 부분합을 추가하면 나중에 만든 부분합 행이 기존 행 위에 표시될 수 있으니, 결과 모양만 보고 순서를 반대로 판단하지 않습니다
4평균 결과의 소수 자릿수는 ROUND 함수가 아니라 홈 탭의 표시 형식으로 조정합니다
실기 · 표 · 슬라이서

표를 만들면 필터가 편해집니다

1데이터를 선택하고 홈 탭의 표 서식이나 Ctrl+T로 표를 만들면 미리 정의된 서식과 필터 단추가 적용됩니다
2표 옵션에서 필터 단추와 줄무늬 행 등을 켜거나 끌 수 있습니다
3슬라이서는 단추를 눌러 데이터를 빠르게 필터링하고, 여러 개를 조합해 다중 선택도 할 수 있습니다
실기 · 피벗 테이블

원본을 행 · 열 · 값으로
돌려 봅니다

1피벗 테이블은 원본 데이터를 행 · 열 · 값 영역으로 회전해 원하는 분석표를 만드는 기능입니다
2예) 부서를 행, 직위를 열, 기본급을 값에 놓고, 기본 집계인 합계를 값 필드 설정에서 평균으로 바꿉니다
3실수령액을 값 영역에 추가해 평균으로 바꿀 수 있습니다. 값이 두 개 이상이면 열 영역의 Σ 값을 행 영역으로 옮겨 세로로 긴 표를 만듭니다
4셀 포인터가 피벗 테이블 안에 있어야 전용 리본이 나타납니다. 필드 목록이 보이지 않으면 피벗 테이블 분석 탭에서 필드 목록을 선택합니다
실기 · 피벗 테이블

빈 셀 · 총합계 · 새로 고침

1비어 있는 셀은 0이나 하이픈 같은 값으로 표시하도록 설정할 수 있습니다
2오른쪽 총합계는 행 총합계(각 행의 합계), 아래쪽 총합계는 열 총합계(각 열의 합계)입니다. 화면에 놓인 방향이 아니라 어떤 데이터의 합계인지로 판단합니다
3Excel 2021에서는 원본 데이터를 수정해도 피벗 테이블이 자동으로 바뀌지 않으므로 새로 고침해야 합니다. 원본이 일반 셀 범위이고 범위 밖으로 데이터가 늘어나면, 새 피벗 테이블을 만들지 않고 데이터 원본 범위를 변경합니다(원본이 표이면 보통 새로 고침만 하면 됩니다)
4피벗 테이블은 문제에서 지정한 위치(새 워크시트 또는 기존 워크시트)에 만듭니다. 계산 필드와 피벗 차트는 피벗 테이블 분석 탭의 각 명령에서 다룹니다
