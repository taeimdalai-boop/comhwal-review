📌오늘 배운 핵심 요약

★부분합은 «정렬»이 먼저다

부분합은 스스로 정렬해 주지 않습니다. 그룹으로 묶을 항목(부서·과목 등)으로 먼저 정렬한 뒤에 데이터 → 개요 → 부분합으로 들어갑니다.

필기 단골 함정 — "자동 정렬되나?" → 아니오

합계 위에 평균을 함께 두려면

두 번째 부분합에서 「새로운 값으로 대치」 체크를 해제합니다. 해제하지 않으면 앞서 만든 합계가 덮어써져 사라집니다.

나중에 한 것이 위로 올라옵니다

✂️ 텍스트 나누기 = 구분 기호로 열 쪼개기

한 칸에 쉼표로 붙어 있는 데이터를 여러 열로 나눕니다. 범위 선택 → 데이터 탭 → 텍스트 나누기 → 구분 기호. 필요 없는 항목은 「열 가져오지 않음」으로 건너뜁니다.

클릭만으로 끝나는 쉬운 배점

🔢 ROW·COLUMN은 «번호», ROWS·COLUMNS는 «개수»

ROW()는 지금 셀의 행 번호, ROWS(범위)는 그 범위의 행 개수입니다. 복수형(S)이 붙으면 개수로 외웁니다.

인수를 생략하면 현재 셀 기준

줄무늬는 MOD와 ROW의 조합

짝수 행만 칠하려면 =MOD(ROW(),2)=0. 행 번호는 어느 열에서나 같으므로 여기서는 열 절대참조가 필요 없습니다.

홀수 행이면 결과를 1과 비교

🗂 폴더 옵션에서 «안 되는» 것

숨김 파일 표시·한 번/두 번 클릭·검색 방식은 됩니다. 그러나 숨김 «속성»을 해제하는 것과 파일 형식을 새로 등록하는 것은 폴더 옵션의 기능이 아닙니다.

폴더 옵션은 «보이게 할지»만 정합니다

💾 빠른 포맷은 «완전 삭제»가 아니다

파일을 지워도 실제로는 연결 정보만 끊깁니다. 그래서 복구가 가능해요. 저장장치를 남에게 넘길 때는 「빠른 포맷」 체크를 해제하고 포맷해야 안전합니다.

중고로 USB를 팔 때 꼭 기억할 것

🗑 휴지통에 «안 가는» 경우

Shift+Delete, USB·네트워크 드라이브, 명령 프롬프트 삭제, 휴지통 크기 0MB 설정. 이 네 가지는 바로 지워집니다. 휴지통은 드라이브마다 따로 설정됩니다.

휴지통 안에서는 실행·이름 바꾸기 불가

💡개념 다시 보기

시작 전에 — 어제 가장 많이 틀린 것 되짚기

어제 퀴즈에서 한 문항이 64%였습니다. 「합계가 190점 이상인 셀을 강조하려면 어디로 들어가나」를 묻는 문제였어요.
답은 「기타 규칙」입니다. 셀 강조 규칙 메뉴에는 보다 큼·보다 작음·같음은 있는데 「크거나 같음」이 없습니다.
왜 헷갈리나 메뉴 이름이 「셀 강조 규칙」이라 여기서 다 될 것 같지만, 부등호에 «같음»이 붙는 순간 목록에서 사라집니다.
오늘 4교시에 다시 해 봤습니다. 조건부 서식 → 셀 강조 규칙 → 기타 규칙 → 「셀 값 >= 190」.

📊 부분합 — 정렬이 먼저, 그리고 「새 값으로 대치」

1단계 · 정렬 그룹으로 묶을 항목 기준으로 먼저 정렬합니다. 부분합은 자동으로 정렬해 주지 않아서, 정렬하지 않으면 같은 항목이 여기저기 흩어진 채 소계가 여러 번 생깁니다.
2단계 · 부분합 셀 포인터를 데이터 안에 두고 데이터 탭 → 개요 → 부분합. 「그룹화할 항목」·「사용할 함수」(합계·평균·최대·최소)·「부분합 계산 항목」을 지정합니다.
3단계 · 두 번째 부분합 합계 위에 평균까지 함께 두려면, 두 번째로 부분합을 실행할 때 「새로운 값으로 대치」 체크를 해제합니다. 해제하지 않으면 앞의 합계가 지워집니다.
윤곽 단추 왼쪽 위의 1은 총합계만, 2는 그룹 요약까지, 3은 전체를 펼쳐 보여 줍니다.
잘못 만들었다면 부분합 대화상자의 「모두 제거」를 눌러 되돌린 뒤 다시 합니다.

🔢 ROW · COLUMN — 번호를 돌려주는 함수

ROW / COLUMN =ROW()는 지금 셀의 행 번호, =COLUMN()은 열 번호를 돌려줍니다. 괄호 안을 비우면 현재 셀 기준이고, =ROW(A5)처럼 셀을 넣으면 그 셀의 번호입니다.
ROWS / COLUMNS 범위를 넣으면 그 범위의 행 개수 · 열 개수를 돌려줍니다. =ROWS(A2:A21)은 20이에요. 레코드가 몇 건인지 셀 때 씁니다.
구분하는 말 복수형(S)이 붙으면 개수입니다. ROW는 번호 하나, ROWS는 개수.
줄무늬 만들기 조건부 서식에 =MOD(ROW(),2)=0을 넣으면 짝수 행만 칠해집니다. 홀수 행이면 =1과 비교하세요.
여기선 열 절대참조가 필요 없습니다 행 번호는 어느 열에서 보든 같은 값이라 $를 붙일 대상이 없습니다. (조건부 서식이라고 무조건 $F4는 아닙니다.)

✂️ 텍스트 나누기 — 한 칸에 붙은 데이터를 열로 쪼개기

언제 쓰나 「홍길동,영업부,과장」처럼 한 칸 안에 쉼표로 붙어 들어온 데이터를 각각의 열로 나눌 때 씁니다.
순서 나눌 열을 선택 → 데이터 탭 → 텍스트 나누기 → 「구분 기호로 분리됨」 → 구분 기호 체크(쉼표·탭·공백 등) → 마침.
필요 없는 항목은 빼기 3단계 미리 보기에서 그 열을 클릭하고 「열 가져오지 않음(건너뜀)」을 고르면 그 항목은 시트에 들어오지 않습니다.
주의 나뉜 결과가 오른쪽 칸을 덮어씁니다. 오른쪽에 데이터가 있으면 미리 빈 열을 넣어 두세요.

🗂 필기 — 파일 탐색기와 폴더 옵션

파일 탐색기로 할 수 있는 일 파일·폴더의 복사·이동·이름 바꾸기·삭제, 폴더 공유, 마우스 오른쪽 클릭으로 바로 인쇄까지 됩니다.
폴더 옵션에서 되는 것 ①숨김 파일 및 폴더 표시 ②보호된 운영 체제 파일 숨기기(기본은 숨김) ③한 번 클릭/두 번 클릭으로 열기 ④검색 탭에서 파일 «내용»까지 검색하도록 설정.
폴더 옵션에서 안 되는 것 ①숨김 «속성» 자체를 해제하는 것 — 폴더 옵션은 숨은 파일을 보이게 할지만 정합니다. 속성을 없애려면 그 파일의 속성 창에서 「숨김」 체크를 풉니다. ②파일 형식(확장자)을 새로 등록 — 확장자를 확인할 수는 있어도 등록하는 기능은 아닙니다.
내용 검색은 느립니다 뒤져야 할 양이 크게 늘어나기 때문입니다. 평소엔 꺼 두고 필요할 때만 켜세요.
속성 창(Alt+Enter)에서 볼 수 있는 것 만든 날짜·수정한 날짜·액세스한 날짜, 그리고 하위 폴더와 파일의 개수. 다만 거기서 특정 하위 폴더를 삭제하는 기능은 없습니다(그건 탐색기에서 합니다).

💾 필기 — 디스크 포맷과 파일 이름 규칙

파일을 지우면 실제로 무슨 일이 일어나나 파일 하나는 디스크의 여러 공간에 나뉘어 저장되고 서로 연결돼 있습니다. 삭제하면 이 연결 정보만 끊어 쓸 수 없는 상태로 만들 뿐, 내용은 그 자리에 남아 있습니다.
그래서 복구가 가능합니다 수사에서 말하는 「포렌식」이 이 원리를 이용합니다. 다만 그 자리에 새 데이터를 계속 덮어쓰면 복구가 어려워집니다.
중고로 넘길 때는 「빠른 포맷」을 해제 빠른 포맷은 실제 데이터 영역을 덮어쓰지 않아 복구 가능성이 남습니다. USB를 팔거나 남에게 줄 때는 체크를 풀고 포맷하세요.
포맷 대화상자에 있는 것 용량, 파일 시스템(NTFS·exFAT 등), 할당 단위 크기, 볼륨 레이블, 빠른 포맷 체크.
파일·폴더 이름 규칙 같은 폴더 안에 같은 이름은 둘 수 없습니다. 최대 255자까지 쓸 수 있고, 공백은 사용할 수 있지만 일부 특수문자(\ / : * ? " < > |)는 쓸 수 없습니다.

🔍 필기 — 검색 · 드래그 · 클립보드

검색 상자는 두 개, 범위가 다릅니다 파일 탐색기 검색은 지금 열려 있는 폴더 안을 찾습니다(F3 또는 Ctrl+F를 누르면 검색 상자로 이동), 작업 표시줄 검색은 앱·문서·설정·웹까지 넓게 찾습니다(Windows+S).
드래그는 «어느 드라이브인가»에 따라 달라집니다 같은 드라이브 안에서 끌면 이동, 다른 드라이브로 끌면 복사가 기본입니다.
키로 바꿀 수 있습니다 복사하고 싶으면 Ctrl, 이동하고 싶으면 Shift를 누른 채 끕니다. Ctrl+Shift면 바로가기 아이콘이 만들어집니다.
클립보드 여러 프로그램이 함께 쓰는 임시 저장 공간입니다. 주기억장치(RAM)에 저장되므로 컴퓨터를 끄면 사라집니다.
화면 캡처 Print Screen은 화면 전체를, Alt+Print Screen은 현재 활성 창만 클립보드에 담습니다.

🗑 필기 — 휴지통

무엇인가 삭제한 파일을 임시로 보관하는 공간입니다. 드라이브마다 따로 설정되고, 크기도 드라이브별로 정할 수 있습니다.
휴지통에 가지 않고 바로 지워지는 경우 ①Shift+Delete ②USB·메모리카드 등 이동식 저장장치 ③네트워크 드라이브 ④명령 프롬프트(도스)에서 삭제 ⑤휴지통 속성에서 최대 크기를 0MB로 두거나 「파일을 휴지통에 버리지 않고 바로 제거」를 켠 경우.
가득 차면 가장 오래된 항목부터 자동으로 지워집니다.
휴지통 «안»에서는 못 하는 일 파일을 실행하거나 이름을 바꿀 수 없습니다. 먼저 복원한 뒤에 해야 합니다.
복원 방법 「복원」 단추를 쓰거나, 잘라내기 → 붙여넣기로 꺼냅니다. 복사해서 붙여넣는 방식은 안 됩니다.
휴지통 비우기를 하면 그 파일은 휴지통에서 다시 되살릴 수 없습니다.

📝 필기 — 메모장과 워드패드

메모장은 «텍스트 전용»입니다 글자만 다룹니다. 그림·차트·OLE 개체는 넣을 수 없고, 문단 정렬이나 문단 간격도 설정할 수 없습니다.
메모장에서 되는 것 찾기·바꾸기, 자동 줄 바꿈, 글꼴 설정, 그리고 파일 → 페이지 설정에서 용지 크기·방향·여백·머리글/바닥글.
F5 — 날짜와 시간 넣기 커서 자리에 현재 날짜와 시간이 입력됩니다.
.LOG — 열 때마다 시간이 기록됩니다 문서 첫 줄에 대문자로 .LOG라고 적어 두면, 그 파일을 열 때마다 날짜·시간이 자동으로 덧붙습니다.
워드패드와의 차이 워드패드는 메모장보다 기능이 많아 문단 설정과 OLE 개체 삽입이 가능합니다.
