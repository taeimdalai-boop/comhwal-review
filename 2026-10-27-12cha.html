4작업 관리자는 CPU · 메모리 · 네트워크 사용 상태와 실행 중인 앱을 확인하는 도구입니다

4수동으로 네트워크를 설정하는 화면에서는 IP 주소 · 서브넷 마스크 · 게이트웨이 · DNS 주소를 입력합니다. 자동으로 받게 하면(DHCP 등) 이 값들이 자동으로 할당됩니다

1가공하기 전의 데이터는 자료, 이를 분석해 의사 결정에 도움이 되는 형태로 만든 것이 정보입니다. 피벗 테이블의 결과가 정보의 예입니다. 입력한 자료가 좋아야 좋은 정보가 나온다는 말을 GIGO로 외웁니다
2처리 능력에 따라 슈퍼 › 메인프레임 › 미니 › 마이크로컴퓨터 순서입니다. 마이크로컴퓨터에는 데스크톱 · 노트북 · 태블릿 · 웨어러블 등이 있습니다

필기 · 컴퓨터 분류

디지털과 아날로그를 반대로 외우지 않습니다

1디지털 컴퓨터는 문자 · 숫자 같은 비연속 데이터를 산술 · 논리 연산하고 논리 회로와 프로그램, 기억 장치를 사용합니다
2아날로그 컴퓨터는 전류 · 전압 · 온도 · 속도 같은 연속적인 데이터를 미분 · 적분 방식으로 처리하고 증폭 회로를 사용합니다. 용도가 정해져 있고 정밀도는 제한적입니다
3두 방식의 데이터 · 회로 · 연산 방식을 서로 바꿔 외우지 않습니다
필기 · 자료 단위

비트에서 데이터베이스까지

1비트는 0 또는 1을 저장하는 최소 단위이고, n비트는 2ⁿ가지를 표현합니다. 니블은 4비트(16가지, 16진수 한 자리), 바이트는 8비트(256가지, 0~255)입니다. 2비트가 1바이트가 아닙니다
224비트 트루컬러에서는 RGB 각 색을 8비트(0~255)로 표현하므로 모두 24비트입니다
3워드는 CPU가 한 번에 처리하는 데이터의 기본 단위이고 크기는 컴퓨터 구조에 따라 다릅니다. 수업에서는 풀 워드를 32비트, 더블 워드를 64비트로 정리했습니다. CPU의 처리 단위를 바이트로 외우지 않습니다
4교재 설명에서는 영문 · 숫자를 1바이트, 한글 · 한자를 2바이트로 셉니다 (실제 크기는 문자 인코딩 방식에 따라 달라집니다)
5필드 › 레코드 › 파일 › 데이터베이스 순으로 커집니다
필기 · 문자 코드

BCD · ASCII · EBCDIC · 유니코드

1BCD는 6비트로 64가지를 표현하며 영문 소문자는 표현하지 못합니다
2ASCII는 기본 7비트로 개인용 컴퓨터와 통신에 쓰이고, 확장 ASCII는 8비트입니다. EBCDIC은 8비트(256가지)로 대형 컴퓨터에서 씁니다
3유니코드는 전 세계 문자를 하나의 체계로 표현하는 코드입니다. 교재에서는 2바이트(16비트)로 설명하며 한글은 완성형과 조합형을 모두 지원합니다
필기 · 오류 검출 코드

패리티 비트와 해밍 코드

1패리티 비트는 전송 오류를 검출하기 위해 데이터에 덧붙이는 비트입니다. 단순 패리티는 오류가 있다는 것까지 알 수 있고 위치를 찾아 고치지는 못합니다
2해밍 코드는 오류를 검출하고 교정할 수 있는 코드입니다
3둘 다 BCD · ASCII 같은 문자 표현 코드가 아니라 오류 검출 · 교정용 코드입니다
필기 · 부분합 옵션

옵션 3가지의 뜻

1그룹 사이에서 페이지 나누기 — 그룹이 바뀔 때마다 인쇄 페이지를 나눕니다
2데이터 아래에 요약 표시 — 기본은 아래쪽에 표시하고, 해제하면 각 그룹 위쪽에 요약이 나타납니다. 실기 형태는 아래쪽에 표시하는 것입니다
3새로운 값으로 대치 — 선택하면 기존 부분합을 새 부분합으로 바꿉니다. 첫 번째 부분합을 유지한 채 두 번째를 추가하려면 해제합니다
실기 · 부분합

합계와 평균을 차례로 누적합니다

1진료 과목별 인원 합계를 먼저 만들고, 이어서 연령대 평균을 두 번째 부분합으로 추가합니다. 두 번째는 «새로운 값으로 대치»를 해제합니다
2예제에서는 결과에 합계가 아래줄, 평균이 윗줄로 나타나야 합니다. 줄 순서도 채점 대상이므로 순서를 바꿔 만들면 오답입니다
3잘못 만들었다면 고치려 하지 말고 모두 제거한 뒤 처음부터 다시 작성합니다
실기 · 피벗 테이블

원본 범위를 확인하고 위치는 지시대로

1원본 데이터 주변에 단위나 별도 합계가 없으면 데이터 안의 셀 하나만 선택해도 범위가 자동 인식됩니다. 주변에 다른 내용이 있으면 정확한 원본 범위를 직접 선택합니다
2피벗 테이블은 삽입 탭에서 만듭니다. 위치는 문제에서 지정한 곳(예: 기존 워크시트의 A21)에 만듭니다
3값 필드가 둘이면 표시 형식도 값 필드마다 따로 지정합니다.
실기 · 피벗 옵션

새로 고침 · 총합계 · 그룹화

1Excel 2021에서는 원본 데이터를 고쳐도 피벗 테이블이 자동으로 바뀌지 않으므로 새로 고침해야 합니다. 원본이 범위 밖으로 늘어나면 데이터 원본 범위를 변경합니다
2행 총합계 · 열 총합계는 보이는 위치가 아니라 어떤 데이터의 총합계인지로 구분합니다. 설정은 디자인 탭이나 피벗 테이블 옵션(요약 및 필터)에서 합니다
3비어 있는 셀은 0이나 하이픈 같은 값으로 표시할 수 있습니다
4날짜 그룹화는 피벗의 날짜 항목 셀(이 예에서는 날짜 행 레이블 셀)에 셀 포인터를 둬야 그룹 메뉴가 활성화됩니다. 연 · 분기를 해제하고 월 단위만 남길 수 있습니다
실기 · 데이터 표

모서리 셀과 입력 셀을 구분합니다

1데이터 표는 입력값이 바뀔 때 결과가 어떻게 변하는지 여러 조합을 한 번에 표로 계산합니다 (데이터 탭 › 예측 › 가상 분석 › 데이터 표)
2표의 왼쪽 위 모서리에는 원래 결과 수식을 연결합니다. 결과 셀을 복사해 붙이면 상대 참조가 이동하므로, 수식 편집 상태에서 수식을 복사하거나 =B5처럼 직접 연결합니다
3가상 값이 가로(행)로 놓이면 행 입력 셀, 세로(열)로 놓이면 열 입력 셀에 원본 데이터의 입력 셀을 지정합니다 (예: 상환 기간은 행 입력 셀 B4, 연 이율은 열 입력 셀 B3)
실기 · 시나리오

이름을 정의하고 «요약»으로 마무리

1시나리오 관리자는 증가 · 감소처럼 몇 가지 상황을 저장해 비교합니다 (많은 조합을 한꺼번에 보는 것은 데이터 표)
2변경 셀과 결과 셀에 이름을 정의하면 요약에 E4 같은 주소 대신 A반품수량, 매출액합계 같은 이름이 표시됩니다. 이름에는 공백을 쓸 수 없습니다. 이름 정의는 문제 지시에 따라 수행합니다
3시나리오를 모두 만든 뒤 «요약»을 선택해 요약 시트를 만들고(«표시»는 선택한 시나리오 값을 원본 시트에 적용해 보는 기능), 결과 셀에는 문제에서 요구한 셀만 남깁니다
4현재 값은 따로 작성한 시나리오가 아니므로 작성한 시나리오 수에 포함하지 않습니다. 생성된 요약 시트는 문제가 지정한 원본 시트 바로 오른쪽으로 옮깁니다
실기 · 목표값 찾기

세 칸의 역할을 말로 설명할 수 있게

1입력 셀 하나를 바꿔 원하는 결과 하나를 찾습니다. 데이터 표보다 비교 조건이 적습니다
2수식 셀은 수식이 들어 있는 결과 셀, 찾는 값은 그 수식이 가져야 할 결과값, 값을 바꿀 셀은 수식이 참조하는 입력 셀입니다
3예) 월 상환액을 20,000원으로 만들려면 상환 기간을, 광고 비용 합계를 5,000만 원으로 만들려면 계열 C의 광고 비용을 바꿔 구합니다
실기 · 통합

레이블을 기준으로 합칩니다

1떨어져 있는 여러 표를 같은 레이블끼리 합계 · 평균 · 최대값 등으로 하나의 결과로 계산합니다 (데이터 › 통합)
2문제에서 결과 레이블 영역이 주어지면 그 영역을 먼저 정확히 선택한 뒤 통합을 실행합니다. 결과 영역 안에 셀 포인터만 두지 않습니다
3각 참조 영역은 필드명과 왼쪽 레이블을 포함해 선택하고 반드시 «추가»를 누릅니다. 레이블 기준으로 통합할 때는 첫 행 · 왼쪽 열을 체크해야 위치가 아니라 이름이 같은 항목끼리 계산됩니다
4불필요한 병합 제목이나 쓰지 않을 필드는 참조 영역에 포함하지 않습니다. 현대* · *코리아처럼 와일드카드 레이블을 만들어 최대값 통합을 하는 예도 다뤘습니다

2✕ 기본 프린터를 로컬 · 네트워크마다 한 대씩 지정함○ 기본 프린터는 종류와 관계없이 한 대만 지정합니다.
3✕ 대기 중인 문서의 용지 방향을 바로 바꾸려 함○ 인쇄를 취소한 뒤 설정을 바꿔 다시 인쇄합니다.
4✕ 디지털과 아날로그의 회로 · 연산을 반대로 외움○ 디지털은 논리 회로와 산술 · 논리 연산, 아날로그는 증폭 회로와 미분 · 적분입니다.
5✕ 패리티 비트와 해밍 코드를 문자 표현 코드로 분류함○ 둘은 오류 검출 · 교정 코드입니다. 문자 코드는 BCD · ASCII · EBCDIC · 유니코드입니다.
6✕ 두 번째 부분합에서 «새로운 값으로 대치»를 그대로 둠○ «대치»를 해제합니다. 그대로 두면 첫 번째 부분합이 지워집니다.
7✕ 데이터 표 모서리에 결과 셀을 복사해 붙여 넣음○ 모서리에 =B5처럼 직접 연결합니다. 복사하면 상대 참조가 밀립니다.
8✕ 시나리오를 만든 뒤 «표시»만 누르고 끝냄○ «요약»을 선택해 요약 시트를 만들고, 지정한 위치로 옮깁니다.
9✕ 통합에서 참조 영역만 고르고 «추가»를 안 누름○ 참조 영역마다 «추가»를 눌러 목록에 올립니다.
