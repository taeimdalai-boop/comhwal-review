다시 짚어 두는 것: 보조 축

1생산량(수만 단위)과 불량률(0.01~0.05)처럼 값의 크기가 크게 다른 두 계열을 한 차트에 그리면 작은 값의 계열이 바닥에 붙어 보이지 않습니다. 이때 한 계열을 보조 세로 축에 표시하면 차트 오른쪽에 두 번째 세로 축이 생기고 두 계열이 모두 보입니다
2순서: 계열 하나를 선택 › 차트 디자인 › 차트 종류 변경 › 혼합 › 보조로 옮길 계열의 보조 축에 체크 › 확인
3기본 가로 축은 항목(월 등)을 나타내는 축이고, 데이터 표는 값을 표로 보여 주는 요소입니다. 두 가지 모두 값의 크기 차이를 해결하는 방법이 아닙니다

프로토콜과 OSI 7계층

1프로토콜은 통신 규약입니다. 주소와 내용이 어디에 들어가는지 형식을 맞춰 두어야 기계들끼리 서로 알아듣습니다. AI 분야에서 쓰는 MCP도 프로토콜의 하나입니다
2데이터 통신에서 기본으로 사용하는 계층 모델이 OSI 7계층입니다. 낮은 계층부터 물리 › 데이터 링크 › 네트워크 › 전송 › 세션 › 표현 › 응용 순서입니다. 수업에서는 약어가 ISO가 아니라 OSI(개방형 시스템 간 상호 연결)라는 점을 짚었습니다
3수업에서는 계층을 전부 외우기보다 «통신에서 OSI 7계층을 사용한다»는 점부터 기억하라고 안내했습니다. 시험에는 HTTP가 속한 계층, TCP와 IP가 각각 속한 계층이 보기로 나온다고 했고, 이 내용은 요약집에 정리되어 있습니다
필기 · 6장 인터넷 서비스

전자우편과 프로토콜

1전자우편(E-mail) 주소는 사용자 ID@메일 서버의 도메인 이름 형식입니다(예: ID@naver.com)
2SMTP는 사용자가 작성한 메일을 상대방 계정이 있는 곳으로 전송하고, POP3는 메일을 가져와 받습니다. 보기에서 두 가지가 서로 바뀐 채로 나오므로, 수업에서는 SMTP의 S를 Send(보내다)로 외우도록 안내했습니다(암기용이며 정식 이름은 Simple Mail Transfer Protocol입니다)
3IMAP은 메일에 접근하기 위한 표준 프로토콜이고, MIME은 전자우편에 그림 · 동영상 같은 멀티미디어를 실어 보낼 수 있게 한 확장 규격이며, 수업에서는 웹 브라우저가 지원하지 않는 멀티미디어를 실행하는 프로토콜로도 설명했습니다. M은 멀티미디어로 기억합니다(정식 이름은 Multipurpose Internet Mail Extensions)
4네이버 · Gmail 같은 계정은 대부분 SMTP와 POP3를 제공합니다. MS 오피스를 설치하면 같이 설치되는 아웃룩은 여러 메일 계정의 메일을 내 컴퓨터로 받아 한 프로그램에서 관리합니다
필기 · 6장 인터넷 서비스

스팸 · FTP · WWW · HTTP

1스팸 메일은 받는 사람이 원하지 않는데 일방적으로 보내는 광고성 메시지입니다
2FTP(File Transfer Protocol)는 파일을 주고받는 인터넷 서비스입니다. 파일 전송 하면 FTP를 고릅니다
3WWW(월드 와이드 웹)는 인터넷에 있는 그림 · 동영상 등 모든 자원을 연결해 놓은 것으로, 멀티미디어 정보도 제공합니다. 웹 페이지는 서버가 정보를 제공하고 클라이언트가 웹 브라우저로 검색해 받아 보는 방식입니다
4HTTP는 웹 브라우저와 서버 사이에서 하이퍼텍스트 문서를 전송하는 프로토콜입니다. 주소 앞에 붙는 HTTPS는 보안이 적용된 방식입니다. 웹 페이지를 만드는 언어는 HTML입니다
필기 · 6장 인터넷 서비스

웹 브라우저의 종류와 관련 용어

1웹 브라우저는 인터넷의 웹 페이지를 열어 볼 수 있게 해 주는 프로그램입니다. 윈도우 기본은 엣지(예전에는 인터넷 익스플로러)이고, 크롬 · 파이어폭스 · 사파리 · 웨일 등이 있습니다. 수업에서는 확장 프로그램이 많다는 이유로 크롬을 추천했습니다
2플러그인은 웹 브라우저의 기능을 확장합니다. 히스토리는 방문 기록이라 남기고 싶지 않으면 지웁니다. 북마크는 즐겨찾기처럼 자주 가는 사이트를 저장합니다
3쿠키는 특정 웹 사이트의 정보를 저장해 두는 것으로, 이를 이용하면 매번 아이디와 비밀번호를 입력하지 않아도 됩니다. 검색한 정보도 쿠키에 쌓여 광고에 쓰이기 때문에, 정보를 주고 싶지 않으면 쿠키 허용을 거부할 수 있습니다
4웹 브라우저에서는 전자우편 보내기, FTP 서버 접속, 웹 페이지 저장 · 인쇄, 사이트 주소 관리가 가능합니다. 반면 멀티미디어 편집기를 선택하는 기능은 없고, 동영상 편집기는 따로 설치해서 씁니다

캐싱 · 포털 · 미러 사이트 · 검색 엔진

1캐싱은 자주 사용하는 사이트의 정보를 저장해 두었다가, 다시 들어갔을 때 빠르게 보여 주는 방식입니다
2포털 사이트는 검색 · 뉴스 · 메일 같은 서비스를 한곳에 모아 둔 사이트입니다. 미러 사이트는 사용자가 몰려 사이트가 다운되는 것을 막기 위해 똑같은 내용의 사이트를 여러 곳에 만들어 두는 것입니다
3검색 엔진은 단어(키워드)별, 주제(디렉터리)별, 여러 검색 엔진의 결과를 모으는 메타 검색 엔진 방식이 있습니다. 수업에서는 이름만 언급했고 세부 내용은 요약집에서 확인하라고 안내했습니다
필기 · 6장 ICT 신기술

클라우드 · 그리드 · 스마트 그리드

1클라우드 컴퓨팅은 하드웨어나 소프트웨어를 필요한 만큼 빌려 쓰고 사용한 만큼 요금을 지불하는 방식입니다. 구글 드라이브처럼 일정 용량까지만 무료이고 그 이상은 요금을 내는 서비스가 예입니다
2그리드 컴퓨팅은 분산 처리처럼 지리적으로 떨어져 있는 컴퓨터를 초고속 인터넷망으로 연결해 하나의 컴퓨터처럼 처리하는 기술입니다
3스마트 그리드는 전기의 생산부터 소비까지 전 과정의 효율을 높이기 위해 만든 지능형 전력망 시스템입니다

사물 인터넷(IoT)과 만물 인터넷

1사물 인터넷(IoT)은 인간과 사물, 사물과 사물 사이에서 언제 어디서나 소통할 수 있게 하는 환경입니다. 모든 사물에 인터넷을 붙여 정보를 받고, 정해 둔 조건에 따라 사물이 동작하도록 만듭니다(집 밖에서 보일러 켜기 등)
2사물 인터넷은 빅데이터를 수집하고, 사람 · 사물 · 공간의 상태를 예측 · 판단하는 데 쓰입니다. 발전하면 단순히 연결하는 단계를 넘어 수집한 데이터를 분석해 사물이 스스로 의사 결정을 내리는 단계로 갑니다
3수업에서는 만물 인터넷을 IoT에서 한 단계 진화해 연결 대상이 더 넓어진 것으로 설명했습니다(사물뿐 아니라 사람 · 데이터 · 프로세스까지 연결하는 개념). 연결되는 사물마다 IP 주소가 필요하므로 주소가 더 부족해집니다
4«통신 비용이 줄고 정보 보안 기술이 쉬워진다»는 보기는 틀린 설명입니다. 연결된 기기가 늘수록 정보 보안이 더 중요해집니다
필기 · 6장 ICT 신기술

RSS · 시맨틱 웹 · 텔레매틱스 · LBS · 빅데이터 · 와이브로

1RSS는 웹 사이트의 새 정보를 자동으로 가져와 읽어 주는 기술입니다. 시맨틱 웹은 컴퓨터가 정보의 뜻을 이해하고 조작할 수 있는 차세대 지능형 웹입니다
2텔레매틱스는 자동차에 정보 통신 · 정보 처리 기술을 융합해 여러 가지 서비스를 제공하는 것입니다. LBS(위치 기반 서비스)는 지도 앱에서 내 위치를 기준으로 길 찾기 · 주변 맛집을 알려 주는 서비스입니다
3빅데이터는 엄청나게 많은 데이터와 이를 처리하는 기술을 말합니다. 와이브로는 Wi-Fi보다 범위가 넓은 무선 광대역 서비스로, 이동하면서 언제 어디서나 인터넷에 접속할 수 있게 합니다
필기 · 6장 ICT 신기술

유비쿼터스와 RFID · USN

1유비쿼터스는 컴퓨터나 네트워크를 의식하지 않고도 언제 어디서나 인터넷을 쓸 수 있는 환경입니다
2RFID는 전자 태그를 사물에 붙여 정보를 읽는 기술입니다. 버스 카드를 찍거나, 도서관 책의 태그로 대출 · 반납을 처리하거나, 출퇴근을 태그로 기록하는 것이 모두 RFID입니다. 보기에 «전자 태그»가 나오면 RFID를 고릅니다
3USN(유비쿼터스 센서 네트워크)은 모든 사물에 붙은 RFID 태그나 센서가 탐지한 사물의 인식 정보를 주변에 알려 주는 것입니다. 수업에서는 산불 감시에 센서를 뿌려 두면 일정 열 이상에서 센서끼리 통신해 중계기로 알리는 예로 설명했습니다
4NFC는 가까이 대면 통신하는 태그 기술이고, RFID 기술의 하나로 설명했습니다
필기 · 6장 ICT 신기술

통신 기술 이용 현황 문제

1교재 문제는 «이런 상황에 쓰는 기술은?»을 묻습니다. 노트북 핫스팟 연결은 Wi-Fi, 헤드폰과 핸드폰 연결은 블루투스, 출퇴근 태그와 도서 대출 · 반납은 RFID입니다
2«핸드폰 · 노트북 · PDA 같은 모바일 기기로 언제 어디서나 인터넷에 접속»은 와이브로입니다. Wi-Fi는 범위에 제약이 있고 와이브로는 그보다 넓다고 설명했습니다
3«지리적으로 분산된 컴퓨터를 초고속 인터넷망으로 연결»은 그리드 컴퓨팅입니다. 수업에서는 이 단원에 새 용어가 더 나올 수 있으니 말씀드린 단어를 더 생각해 보라고 안내했습니다
필기 · 6장 ICT 신기술

블록체인 · 메타버스 · NFT · 핀테크

1이 네 가지는 교재의 ICT 신기술 표에는 나와 있지 않지만, 수업에서 뉴스에 자주 나오는 용어로 짚었습니다(메타버스는 멀티미디어 활용 부분에도 나옵니다)
2블록체인은 거래 기록을 여러 컴퓨터에 나눠 저장하는 기술로, 비트코인 · 이더리움 같은 가상 화폐가 대표 활용처입니다. 메타버스는 가상의 공간에서 회의 · 쇼 · 박람회를 하는 3차원 가상 세계입니다. NFT는 대체 불가능한 토큰으로, 디지털 그림 같은 자료를 사고파는 데 쓰입니다
3핀테크는 금융과 IT 기술을 융합한 서비스로, 네이버페이 · 카카오페이 같은 간편 결제가 예입니다. 시험에 계속 나온다고 했으며, «금융 기술»이라는 설명이 나오면 핀테크를 고릅니다
필기 · 7장 멀티미디어

멀티미디어의 특징과 하이퍼미디어

1멀티미디어는 다중(multi)과 매체(media)의 합성어로, 텍스트 · 그래픽 · 이미지 · 오디오 · 비디오를 모두 포함합니다
2특징: 디지털화(아날로그 신호를 디지털로 변환), 상호작용성(사용자가 선택해 가며 정보를 주고받음), 비선형성(원하는 정보를 선택해 이동함. 선형은 테이프처럼 순서대로만 가는 것), 정보의 통합성(여러 미디어를 통합해 처리)
3«선형성»이 특징이라고 나오는 보기는 틀립니다. 미디어별 파일 형식이 획일화되었다는 보기도 틀립니다. 오히려 형식이 다양해져서 표준을 정합니다. 대용량 동영상도 MP4(MPEG-4)처럼 압축 기술이 이미 발달해 있습니다(MP3는 오디오 압축입니다)
4하이퍼텍스트는 글자를 연결한 것이고, 하이퍼미디어는 하이퍼텍스트와 멀티미디어를 연결한 것입니다. 글자를 클릭하면 동영상이 나오는 경우가 예입니다. «하이퍼텍스트는 동영상 · 그래픽을 연결한 멀티미디어 형식»이라는 보기는 틀립니다
필기 · 7장 멀티미디어

모델링 · 렌더링 · 디더링

1모델링은 3차원 입체 개체를 만들기 위해 먼저 뼈대를 세우는 단계로, 렌더링 전에 하는 작업입니다. 그림으로 치면 스케치입니다

3JPG는 문자 · 선 · 격자처럼 고주파 성분이 많은 이미지를 변환하면 GIF나 PNG보다 품질이 떨어집니다
4GIF는 인터넷 표준 그래픽이고 애니메이션을 표현할 수 있습니다. PNG는 GIF를 대체해 웹에서 쓰는 고화질 형식이며 투명층을 표현할 수 있어서 도장 · 로고 이미지에 씁니다. 애니메이션은 GIF, 투명층은 PNG로 구분합니다

3암호화는 데이터를 받는 사람 외에는 알 수 없게 바꾸는 기법이고, 침입 탐지 시스템은 컴퓨터가 비정상적으로 사용되지 않도록 감시합니다

DDoS · 웜 · 트로이 목마 · 백도어

1디도스(DDoS, 분산 서비스 거부 공격)는 대량의 데이터를 한 서버에 집중적으로 보내 서버가 제 기능을 하지 못하게 합니다. 수업에서는 대규모 행사에 사람이 몰려 트래픽이 한곳에 쏠리는 장면을 떠올리라며 예로 들었습니다
2웜은 감염 대상 없이 스스로 복제해 시스템의 부하를 높입니다. «감염 대상을 갖고 있지 않지만 자신을 복제»라는 설명이 나오면 웜입니다
3트로이 목마는 프로그램 안에 숨어 있다가 그 프로그램이 동작할 때 활성화되어 부작용을 일으킵니다. 복제는 하지 않습니다. 백도어는 보안이 제거된 비밀 통로로, 유지보수를 위해 일부러 만들거나 코딩 실수로 생기기도 합니다

스니핑 · 스푸핑 · 키로거 · 피기백

1스니핑은 «옆보기»로, 정보를 패킷이라는 단위로 끊어 전송할 때 그 안에 있는 계정과 패스워드 등을 알아내는 행위입니다. 스푸핑은 «눈속임»으로, 정상적이지 않은 프로그램이나 사람이 정상인 척하는 행위입니다
2키로거는 키보드로 입력하는 내용을 빼내 갑니다. 금융 사이트에서 키보드 보안 프로그램이 동작하는 이유입니다
3피기백은 교재에서 정당한 사용자가 시스템을 종료하지 않고 자리를 떠났을 때 권한 없는 사람이 이를 사용하는 것으로 설명합니다. PC방 등에서 로그아웃하지 않고 자리를 비우면 대화 기록이나 사용량을 다른 사람이 쓸 수 있으므로 로그아웃까지 하라고 안내했습니다
