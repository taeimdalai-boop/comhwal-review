숨김 속성과 숨긴 항목 표시는 따로입니다

1속성의 숨김과 숨긴 항목 표시는 서로 다른 스위치입니다. 숨김 파일이 흐리게 보이면 표시가 켜져 있는 것입니다
2보호된 운영 체제 파일은 일부를 지우면 부팅 실패나 시스템 오작동이 생길 수 있어 기본으로 숨겨져 있습니다
3숨김과 관련해 폴더 옵션은 숨긴 항목의 표시 여부만 바꿉니다. 숨김 속성은 해당 항목의 속성에서 해제하고, 여러 항목을 함께 선택해 바꿀 수도 있습니다

일반 · 보기 · 검색 탭

1폴더 옵션은 보기 탭 › 옵션에서 엽니다. 탭이 세 개(일반 · 보기 · 검색)입니다
2한 번 클릭해서 열기는 속성만 보고 싶어도 파일이 열려서 불편해 권하지 않았습니다. 두 번 클릭이 기본입니다
3같은 창에서 폴더 열기가 기본입니다. 새 창으로 바꾸면 탐색기 창이 수십 개 쌓일 수 있습니다

1FAT32는 파일 하나가 약 4GB 미만이어야 해서 10GB 영상은 저장되지 않습니다. 여러 기기에서 큰 파일을 쓰려면 exFAT입니다
2빠른 포맷은 지운 자료가 포렌식·복구 프로그램으로 되살아날 수 있습니다. 중고로 팔 장치는 안전한 삭제 절차를 따릅니다
3볼륨 레이블에 연락처를 적어 두면 잃어버린 유에스비를 찾아 주는 데 도움이 됩니다
필기 · 파일과 폴더

이름 규칙 · 속성 창 · 바로가기

1하나의 폴더 안에는 확장명까지 같은 이름이 없습니다. 다른 폴더에서는 같은 이름을 써도 됩니다
2속성 창은 내용을 확인·설정하는 곳이고, 폴더를 옮기거나 하위 폴더를 지우는 곳이 아닙니다. 둘은 구분해서 외웁니다
3Ctrl+Shift를 누르고 끌면 바로가기 아이콘이 만들어지고, 한 대상에 여러 개를 만들 수 있습니다

검색 범위와 드래그 기본 동작

1D 드라이브(USB)에서 C 드라이브(바탕 화면)로 끌면 글자가 «복사»로 뜨고, Shift를 누르면 «이동»으로 바뀝니다
2같은 드라이브에서 Ctrl을 누르고 끌면 복사입니다. 기본 동작이 바뀐다고 외웁니다
3시험에는 검색 방법 표(탐색기 F3 · Ctrl+F / 작업 표시줄 Win+S)가 나옵니다. Win+F가 아닙니다

2클립보드 기록을 켠 뒤 Win+V로 열면 25개까지 보이고, 하나를 골라 다시 붙일 수 있습니다
3활성 창 캡처는 Alt+PrtSc입니다. Ctrl이 아닙니다

이럴 때는 휴지통을 거치지 않습니다

1드라이브마다 휴지통이 따로 있습니다. 교재 기준으로 USB 메모리 같은 이동식 장치는 휴지통을 거치지 않고 바로 삭제됩니다(구성에 따라 다를 수 있음)
2Shift+Delete와 명령어(DOS 모드) 삭제는 휴지통에서 꺼낼 수 없는 삭제로 외웁니다
3인공지능에게 파일 정리를 시킬 때는 삭제하지 말고 버전별로 보관하라고 지시해 두면 안전하다고 설명했습니다

복원 · 용량 · 이름 바꾸기

1복원은 복원 단추 · 끌어 놓기 · 잘라내기(Ctrl+X) 후 붙여넣기로 합니다. 시험에는 복사 후 붙여넣기가 틀린 보기로 나옵니다
2휴지통 안의 파일은 실행 · 이름 변경이 안 됩니다. 복원하고 나서 합니다
3휴지통 크기는 10~20%가 아니라 교재 기준 5~10%가 자동 설정입니다. 업무에 맞게 바꿀 수 있고 0도 가능합니다

1첫 줄 왼쪽에 대문자 .LOG를 쓰고 저장해야 합니다. 소문자나 둘째 줄이면 동작하지 않습니다. 삽입된 내용은 다시 저장해야 남습니다

3교재에서는 메모장 개요에 마크다운 형식 지원도 소개합니다(윈도우 기본 문서 작성 앱)

디스플레이 · 소리 · 전원 및 절전 · 정보

2주 모니터는 원하는 모니터로 정할 수 있습니다. «왼쪽 모니터만 된다», «해상도가 높은 것만 된다»는 틀린 설명입니다

2잠금 화면의 화면 시간 제한 설정을 누르면 시스템의 전원 및 절전이 열립니다. 개인 설정 항목이 아닙니다

프린터 · 마우스 · 기본 앱 · 시작 프로그램

1관리자는 시스템을 바꾸는 권한이 넓고(필요하면 승인), 표준 사용자는 제한됩니다. 이름과 달리 모든 작업이 가능한 계정은 아닙니다

3업데이트 및 보안은 시험에서 볼 것이 거의 없다고 했습니다

교재 모의고사 기준 배점

1계산 작업(함수)은 한 문제 8점짜리 5문제입니다. 가장 점수 비중이 큽니다
2분석 작업은 기능이 여러 개이고 시험에는 두 문제가 나옵니다. 오늘 부분합과 피벗을 배웠습니다
3채점 서비스는 수식이 달라도 결과가 같으면 틀리게 나올 수 있어 100% 믿지 않고 참고만 합니다
실기 · 조건부 서식 복습

=MONTH($B5)=10 — 월은 숫자입니다

1=MONTH($B5)=10 — B는 입사일 열(예시). 열만 고정해서 행 전체를 칠합니다
2MONTH는 월을 숫자로 돌려주므로 10과 바로 비교합니다. LEFT · MID · RIGHT 결과는 문자라서 숫자와 비교할 때 따옴표를 맞춰야 합니다
3수식의 행 번호는 범위의 첫 레코드 행 기준으로 씁니다(범위가 5행부터면 B5)
복습 · 9차시

IFS 마지막 TRUE · 줄무늬 MOD(ROW(),2)

1=IFS(A2>=90,"A",A2>=80,"B",TRUE,"C") — 맞는 조건이 없을 때의 값은 마지막 조건 자리에 TRUE를 쓰고 그 뒤에 씁니다
2=MOD(ROW(),2)=0 / =MOD(ROW(),2)=1 — 첫 레코드의 행 번호가 짝수인지 홀수인지부터 봅니다
3이 두 가지는 지난 퀴즈에서 정답률이 낮았습니다. 오늘 퀴즈에서 다시 묻습니다
실기 · 고급 필터

수식 조건의 위 칸은 필드명을 쓰지 않습니다

1=MONTH(C4)=5 — 수식을 쓸 때 위 칸에는 원본 필드명(생년월일)을 쓰지 않습니다
2첫 번째 레코드 셀을 상대 참조로 쓰면 다른 레코드도 차례로 검사됩니다. 결과가 TRUE인 레코드만 추출됩니다
3같은 행의 조건은 AND, 서로 다른 행의 조건은 OR입니다. 일반 조건(>=80 등)은 원본 필드명을 그대로 씁니다
실기 · 고급 필터

목록 범위 · 조건 범위 · 복사 위치

1데이터 탭 › 정렬 및 필터 › 고급에서 엽니다. 목록 범위가 자동으로 잡히지만 한 번 확인합니다
2조건 범위를 잡을 때는 필드명 자리의 이름 칸과 수식 칸을 함께 선택합니다
3시험에서는 복사 위치가 문제에 지정되어 있습니다. 연습할 때는 옆 빈 곳에 해도 같습니다
실기 · 텍스트 나누기

13단계에서 열을 선택해 열 가져오지 않음(건너뜀)을 지정하는 위치를 자주 까먹습니다. 꼭 기억합니다
2데이터 탭에는 텍스트/CSV 파일에서 가져오는 명령도 있지만, 이미 시트에 들어온 데이터는 텍스트 나누기를 씁니다
3실기에서 가장 쉬운 문제 중 하나입니다. 문제가 나오면 점수를 챙깁니다
실기 · 분석 작업 · 부분합

정렬이 먼저입니다

1부분합은 자동으로 정렬해 주지 않습니다. 그룹 기준(문제의 «○○별»)을 먼저 정렬합니다
2대화 상자에서 그룹화할 항목 · 사용할 함수 · 부분합 계산 항목을 고릅니다. 계산 항목은 체크된 것을 믿지 말고 스크롤하며 확인합니다
3필기에서는 화면을 보여 주고 윤곽 단추를 몇 번 눌렀는지 묻습니다. 1은 총합계만, 번호가 커질수록 줄이 많아집니다
실기 · 분석 작업 · 부분합

두 번째 부분합은 «대치»를 해제합니다

1대치 해제는 누적해서 결과를 보려고 할 때 씁니다. 필기에서도 «계산 결과를 계속 보려면 어떻게 하나»를 묻습니다
2수업 예시: 합계를 먼저, 평균을 나중에 만들었더니 평균 줄이 합계 줄 위에 나타났습니다. 결과 모양만 보고 순서를 반대로 판단하지 않습니다
3삽입 · 편집 · 삭제 중 편집이 안 되면 삭제 후 다시 삽입합니다. 부분합은 모두 제거가 삭제입니다
실기 · 분석 작업 · 피벗

끌어다 놓기만 하면 표가 만들어집니다
