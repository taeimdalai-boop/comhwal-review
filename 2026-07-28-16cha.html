💣 7장 ② 공격 유형 · 침해 기법

스니핑 네트워크 패킷을 몰래 엿봐 아이디·비밀번호 탈취(도청). 스푸핑=신뢰 주소로 위장해 접근.
피싱·파밍 가짜 사이트로 개인정보 낚기. 파밍은 정상 URL을 입력해도 가짜로 유도(DNS 변조). 키로거=키 입력 가로채기.
DDoS 여러 컴퓨터로 대량 트래픽을 한 서버에 몰아 마비시키는 분산 서비스 거부. 랜섬웨어=파일 암호화 후 금전 요구. 백도어=인증 우회 통로.
허니팟 일부러 허술한 서버를 만들어 공격자를 유인, 공격 기법을 수집·분석. 디지털 워터마킹=저작권 정보 삽입(불법 복제 방지).
시험: "패킷 도청=스니핑", "대량 트래픽 마비=DDoS", "공격자 유인=허니팟"이 단골.

🦠 7장 ③ 악성코드 · 방화벽

웜(Worm) 숙주 파일 없이 스스로 복제하며 네트워크로 퍼지는 독립형 악성코드. 트로이 목마=정상 프로그램으로 위장, 자기 복제 능력 없음.
매크로 바이러스 엑셀·워드 문서 파일의 매크로 기능을 타고 감염(대표: 멜리사). "실행 파일만 감염"은 오답. 님다=메일 본문(HTML)만 읽어도 감염.
방화벽 외부→내부 불법 침입·해킹 차단. 바이러스 감염·내부 위협은 막지 못함. Windows Defender 방화벽(침입 방어)·BitLocker(드라이브 암호화)·Windows Update(보안 패치).
예방 백신 최신 업데이트, 출처 불명 첨부·메일 열지 않기, 중요 자료 정기 백업, OS 보안 패치. "백신 있으니 백업 불필요"는 함정.
시험: "방화벽이 바이러스까지 막는다"는 오답. "의심 메일은 열어보고 삭제"도 오답(열지 말고 삭제).

🔑 7장 ④ 암호화 — 대칭키 vs 공개키

대칭키(=비밀키=단일키) 암호화·복호화에 같은 키 1개. 빠르지만 사람이 많으면 키 관리가 어려움(DES·AES·SEED).
공개키(=비대칭키) 공개키·개인키 2개(쌍). 암호화는 공개키, 복호화는 개인키. 키 관리 쉬움·느림(RSA).
전자 서명(디지털 서명) 공개키 방식을 거꾸로 — 보내는 사람이 개인키로 서명, 받는 사람이 공개키로 확인. 인증·무결성·부인 방지.
전자 봉투 빠른 대칭키로 본문을 암호화하고, 그 대칭키를 다시 공개키로 감싸 보냄(두 방식의 장점 결합). DNS 설정 변경은 보안 대책이 아님(방화벽·암호화·접근 통제가 보안 수단).
시험: "송·수신이 같은 키=대칭키", "키가 서로 다르고 RSA=공개키". 비밀키·단일키·대칭키가 같은 방식임을 함정으로 냄.

🎬 6장 마무리 — 멀티미디어 서비스 · 용량 계산

스트리밍 다운로드하며 동시 재생. 샘플링=아날로그 소리를 일정 시간마다 잘라 측정(디지털 변환). PCM=샘플한 값을 디지털 부호로 표현.
멀티미디어 특징 디지털화·쌍방향성·비선형성·통합성.
서비스 용어 VCS(화상회의)·MOD(주문형 음악)·VOD(주문형 비디오)·키오스크(무인 안내기)·스마트TV·MHEG(멀티미디어 배열·출력 국제 표준)·웹 호스팅(서버 대여). DHTML=동적 웹·VRML=웹 3D.
이미지 용량 가로픽셀×세로픽셀×픽셀당 바이트÷압축률. 256색=8비트=1바이트. 예: 300×200×1÷10=6,000B≒약 5.9KB. 해상도=픽셀 수가 결정.
시험: "음악을 실시간 스트리밍 요청=MOD", "멀티미디어 배열·출력 국제 표준=MHEG".

⭐ 단골 함정

가로채기와 가로막기를 바꿔서 골라요

가로채기는 몰래 도청(기밀성), 가로막기는 흐름 차단(가용성)이에요. "가로채기=회선을 끊는 것"은 오답.

가로채기=기밀성(비밀 새감) / 가로막기=가용성(못 쓰게) / 수정·위조=무결성.

7장 · 자주 틀림

방화벽이 바이러스까지 막아준다고 생각해요

방화벽은 외부의 불법 침입·해킹을 차단할 뿐, 바이러스 감염이나 내부 위협은 막지 못해요.

바이러스는 백신의 몫. 방화벽=외부 침입 차단 전용.

7장 · 자주 틀림

웜이 숙주 파일에 기생해야 퍼진다고 생각해요

웜은 숙주 파일 없이 스스로 복제하며 네트워크로 퍼지는 독립형이에요. 트로이 목마는 복제를 못 해요.

웜=숙주 불필요·자기 복제 / 트로이 목마=위장·복제 안 함.

7장 · 자주 틀림

매크로 바이러스가 실행 파일만 감염한다고 생각해요

매크로 바이러스는 엑셀·워드 문서 파일의 매크로를 타고 퍼져요(대표: 멜리사).

매크로 바이러스=문서 감염 / 예루살렘·CIH=실행 파일 감염형.

7장 · 자주 틀림

대칭키와 공개키의 키 개수를 헷갈려요

대칭키는 같은 키 1개, 공개키는 공개키·개인키 2개(쌍)예요. 비밀키·단일키·대칭키는 전부 같은 방식.

대칭키=1개·빠름(DES·AES) / 공개키=2개·느림(RSA).

7장 · 자주 틀림

의심스러운 이메일을 열어보고 삭제해요

의심 메일은 열지 말고 바로 삭제해야 해요. "열어서 확인 후 삭제"는 오답이에요.

출처 불명 메일·첨부는 열지 않기. 님다는 본문만 읽어도 감염.

7장 · 자주 틀림

DNS 설정 변경을 보안 대책으로 골라요

DNS 설정 변경은 도메인 변환 방식 조정일 뿐 보안 대책이 아니에요.

직접적 보안 수단=방화벽·암호화·접근 통제.

6장 · 자주 틀림

공개 가격 정보로 비교표 만들기를 범죄로 봐요

공개된 정보를 정상 이용하는 건 컴퓨터 범죄가 아니에요. 불법 복사·개인정보 유출·해킹·위변조가 범죄입니다.

정상 활동을 범죄로 끼워 넣은 보기가 함정.
