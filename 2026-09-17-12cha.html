📊 피벗 테이블 🧮 데이터 표 🖨 스풀 🖥 설정 창 🖼️ 그림 10장

📌오늘 배운 핵심 요약

★피벗 테이블만 «삽입 탭»에 있다

분석 작업으로 배우는 부분합·데이터 표·목표값 찾기·시나리오·통합은 모두 데이터 탭인데, 피벗 테이블만 삽입 탭에서 시작합니다.

메뉴를 못 찾아 시간을 버리는 자리

피벗은 10점 · 부분 점수가 없다

분석 작업의 피벗 문제는 10점 통째로입니다. 하나라도 틀리면 10점이 전부 날아갑니다. 지시문을 한 줄씩 손으로 짚어 가며 순서대로 처리하세요.

기본 작업·차트와 달리 부분 점수 없음

값을 2개 넣으면 «Σ 값»이 생긴다

값 영역에 항목을 두 개 이상 넣으면 내가 만들지 않은 Σ 값이 열 영역에 저절로 생깁니다. 표가 옆으로 길어지면 이 Σ 값을 행으로 끌어내립니다.

보기 편해지고, 시험에도 그대로 나옵니다

🔄 원본을 고쳐도 피벗은 안 바뀐다

원본 데이터를 수정해도 피벗 테이블은 자동으로 갱신되지 않습니다. 피벗 테이블 분석 → 새로 고침을 눌러야 반영돼요.

필기에서 「자동 업데이트된다」는 틀린 보기

그룹화가 회색이면 «셀 포인터»부터

날짜 데이터에 문제가 없는데 그룹 메뉴가 눌리지 않는다면, 열에 아홉은 셀 포인터가 엉뚱한 곳에 있는 겁니다. 행 레이블(1월·2월…) 안에 두면 활성화됩니다.

"안 되는데요"의 대부분이 이것

🧮 데이터 표는 30초짜리 행운의 문제

왼쪽 위 빈 칸에 =원래 수식 셀을 당겨 오고 → 표 전체를 선택 → 데이터 → 가상 분석 → 데이터 표. 행 입력 셀·열 입력 셀만 구분하면 끝납니다.

가상 분석 3형제 중 첫째

🖨 스풀은 «CPU»를 위한 기능

느린 프린터와 빠른 CPU를 함께 굴리려고 인쇄할 내용을 하드디스크에 잠깐 맡겨 둡니다. 좋아지는 것은 컴퓨터 전체(CPU)의 효율이고, 인쇄 속도 자체가 빨라지지는 않습니다(한 단계를 더 거치므로 오히려 느려질 수 있어요).

「인쇄 속도가 빨라진다」는 틀린 보기

🖥 해상도를 높이면 아이콘은 «작아진다»

해상도 = 화면에 찍는 점(픽셀)의 개수입니다. 점이 많을수록 화면은 선명해지고, 같은 화면에 더 많이 담기니 바탕 화면 아이콘은 작아집니다.

설정 → 시스템 → 디스플레이

💡개념 다시 보기

먼저 — 오늘 배운 것이 «어느 시험»에 나오는지

실기는 손으로, 필기는 눈으로 묻습니다. 오늘 실기에서 만든 피벗 테이블·부분합·표는, 필기 2과목(스프레드시트 일반)에서 완성된 화면 사진을 보여 주고 「이 설명 중 옳지 않은 것은?」으로 나옵니다.
그래서 실기를 배우면 필기가 딸려 옵니다. 단, 방향이 한쪽입니다 — 필기 스프레드시트는 실기 내용을 거의 다 포함하지만, 필기에만 나오고 실기에는 전혀 안 나오는 것도 있어요.
오늘 나온 «판별을 요구하는» 항목 부분합의 「그룹 사이에서 페이지 나누기」와 피벗의 행/열 총합계 구분이 그렇습니다. 실기는 지시문대로 메뉴에서 고르면 그만이지만, 필기는 사진만 보고 판별해야 합니다.
오늘 «필기 전용» 과목 1교시·2교시에 한 컴퓨터 일반(윈도우 설정 창·프린터·스풀)은 실기와 무관한 필기 1과목입니다.

📊 피벗 테이블 ① — 만드는 순서와 네 개의 영역

피벗이 무엇인가 세로로 쌓인 원본 데이터를 돌려서 가로·세로 표로 바꿔 주는 기능입니다. 「부서별·직위별 평균 급여」를 AVERAGEIFS로 만들려면 인수를 다섯 개 넣고 혼합참조까지 따져야 하는데, 피벗은 끌어다 놓기만 하면 같은 표가 나옵니다.
1단계 셀 포인터를 데이터 안에 둡니다. Ctrl + A를 눌러 범위가 제대로 잡히는지 확인하면 안전해요.
2단계 삽입 탭 → 피벗 테이블. 분석 작업으로 배우는 기능 가운데 피벗 테이블만 삽입 탭에서 시작합니다.
3단계 「표 또는 범위」를 확인하고, 위치는 시험에서 기존 워크시트를 지정하라고 나옵니다(예: A18). 실무에서는 새 워크시트를 씁니다.
4단계 오른쪽 작업창에서 필터 · 행 · 열 · 값 네 영역에 필드를 끌어다 놓습니다. 지시문에 적힌 순서 그대로 넣으세요.
5단계 값의 계산 방법을 바꾸려면 값 필드 설정. 여기서 합계 → 평균 · 최대 · 최소로 바꾸고, 표시 형식(숫자·천 단위 구분 기호)도 이 안에서 지정합니다.
표시 형식은 «아래쪽» 것을 씁니다 값 필드 설정 안에는 표시 형식이 두 군데 보이는데, 컴활 2급에서는 대화상자 아래쪽의 「표시 형식」 단추를 씁니다. 값 하나하나에 따로 지정해야 해요.

📊 피벗 테이블 ② — 값을 2개 넣으면 생기는 「Σ 값」

내가 만들지 않은 것이 생깁니다 값 영역에 기본급·상여금처럼 두 개 이상을 넣으면, 열 영역에 Σ 값이라는 항목이 저절로 들어갑니다.
그러면 표가 옆으로 길어집니다 직위 × 값 2개 = 열이 두 배로 늘어나 화면 밖으로 나갑니다. 보기 불편해요.
해결 그 Σ 값을 «행» 영역으로 끌어내립니다. 표가 아래로 펼쳐지면서 훨씬 읽기 편해집니다.
작업창이 안 보인다면 먼저 셀 포인터를 피벗 테이블 안쪽으로 옮겨 보세요. 그래도 안 나오면 피벗 테이블 분석 → 필드 목록이 꺼져 있는 것이니 다시 켜면 됩니다.
필기에서는 완성된 사진을 주고 「Σ 값을 열에서 행으로 옮겼다」가 맞는지 묻습니다. 값이 세로로 나란히 적혀 있으면 행으로 내린 것입니다.

📊 피벗 테이블 ③ — 행 총합계와 열 총합계 가려내기 (필기 전용)

실기는 걱정할 게 없습니다 「행 및 열의 총합계를 모두 해제」라고 나오면 메뉴에서 그대로 고르면 끝입니다. 문제는 필기예요 — 사진만 보고 어느 쪽인지 가려내야 합니다.
기준은 «사용한 데이터»입니다 화면에 보이는 위치가 아니라, 어느 방향의 데이터를 더해서 만든 값인가로 이름이 정해집니다.
행 총합계 한 행에 놓인 값들을 쭉 더한 것 → 결과는 표의 오른쪽 끝 세로줄에 나타납니다.
열 총합계 한 열에 놓인 값들을 위아래로 더한 것 → 결과는 표의 맨 아래 가로줄에 나타납니다.
헷갈리는 이유 「행」이라는 말과 그 값이 보이는 자리가 서로 어긋나기 때문입니다. 이름은 더한 방향, 위치는 그 반대라고 외우세요.
메뉴는 두 군데 디자인 탭 → 총합계, 또는 피벗 테이블 분석 → 옵션 → 요약 및 필터. 어느 쪽으로 들어가도 결과는 같습니다.

📊 피벗 테이블 ④ — 새로 고침 · 빈 셀 · 그룹화

새로 고침 원본의 기본급을 2,800 → 3,000으로 고쳐도 피벗은 그대로입니다. 피벗 테이블 분석 → 새로 고침을 눌러야 바뀝니다. 필기에서 「자동으로 업데이트된다」는 틀린 보기예요.
빈 셀 표시 해당하는 사람이 없어 비어 있는 칸에 0이나 #, - 같은 표시를 넣을 수 있습니다. 분석 → 옵션 → 레이아웃 및 서식의 「빈 셀 표시」에 적으면 됩니다.
그룹화 — 셀 포인터부터 봅니다 날짜를 월 단위로 묶으려는데 그룹 메뉴가 회색으로 눌리지 않는다면, 셀 포인터를 묶을 필드(행 레이블의 날짜 칸) 안으로 옮기세요. 값 칸이나 피벗 바깥에 있으면 활성화되지 않습니다. (날짜 칸에 빈 셀이나 «글자» 날짜가 섞여 있어도 묶이지 않으니, 그때는 원본을 고쳐야 합니다.)
월 단위로만 묶기 필드 그룹화 대화상자에서 「월」만 선택하고 기본으로 잡혀 있는 「일」은 해제합니다. 숫자 필드라면 「10개씩」처럼 구간으로도 묶을 수 있어요.
보고서 레이아웃 디자인 탭 → 보고서 레이아웃에서 압축 형식 / 개요 형식 / 테이블 형식을 고릅니다. 개요 형식으로 바꾸면 값이 오른쪽으로 한 칸 떨어져 나옵니다.
모두 지우기 ≠ 삭제 분석 탭의 「모두 지우기」는 설정만 비웁니다. 피벗 테이블 자체를 없애려면 범위를 선택해 홈 탭에서 모두 지우기를 하세요.

📋 표 만들기 — 삽입 탭의 「표」

들어가는 문이 두 개입니다 홈 탭의 「표 서식」으로도, 삽입 탭 → 표로도 같은 «표» 개체가 만들어집니다. 수업에서는 삽입 탭 쪽으로 해 봤어요 — 지시문에 적힌 경로를 따르면 됩니다.
만드는 법 데이터 안에 셀 포인터를 두고 삽입 → 표. 범위와 「머리글 포함」을 확인하고 확인을 누릅니다. 머리글 = 필드명입니다.
달라지는 것 세 가지 ① 머리글에 필터 단추가 자동으로 붙고 ② 테이블 디자인 리본 메뉴가 새로 생기며 ③ 스크롤을 내리면 열 문자(A·B·C) 자리에 필드명이 나타납니다 — 틀 고정을 하지 않아도 머리글이 보입니다.
요약 행 테이블 디자인에서 「요약 행」을 켜면 맨 아래에 줄이 생기고, 칸마다 합계·평균·개수를 클릭만으로 고를 수 있습니다. 함수를 쓰지 않아도 됩니다.
리본 메뉴가 사라졌다면 셀 포인터가 표 바깥에 있는 겁니다. 개체를 선택해야 그 개체의 리본이 나타납니다 — 피벗도 차트도 모두 같은 규칙이에요.
슬라이서 표나 피벗에 붙여 단추로 걸러 보는 기능입니다. 컴활 2급 시험에는 나오지 않지만 실무에서 많이 씁니다.

🧮 데이터 표 — 가상 분석 3형제의 첫째

무엇을 하나 「값이 이렇게 바뀌면 결과가 얼마가 될까」를 미리 계산해 표로 펼쳐 줍니다. 국어를 80·90·100으로, 수학을 90·95·100으로 바꿔 가며 총점이 어떻게 변하는지 한 번에 보는 식입니다.
가상 분석 3형제 데이터 표 · 시나리오 · 목표값 찾기. 셋 다 데이터 탭 → 예측 → 가상 분석 안에 함께 들어 있습니다. 메뉴에서 「데이터 표」를 바로 찾으면 안 보여요.
1단계 · 왼쪽 위 빈 칸에 수식 당겨 오기 그 칸에 = 를 치고 원래 결과가 계산되어 있던 셀을 클릭한 뒤 Enter. 복사·붙여넣기는 하지 마세요 — 상대참조가 밀려 엉뚱한 값이 나옵니다(수업에서 해 봤을 때는 0이었어요). 시험에서는 =로 결과 셀을 참조시키는 방식이 가장 안전합니다.
2단계 · 표 전체 선택 셀 포인터만 두면 안 됩니다. 채워야 할 표 영역을 통째로 드래그하세요.
3단계 · 데이터 → 가상 분석 → 데이터 표
4단계 · 행 입력 셀 / 열 입력 셀 표에서 가로로 놓인 항목이 행 입력 셀, 세로로 놓인 항목이 열 입력 셀입니다. 넣는 값은 그 항목이 원래 수식에서 쓰이던 셀 주소입니다 — 표 안의 값이 아닙니다.
익숙해지면 30초 손에 붙으면 문제를 읽지 않고도 풀 수 있는 행운의 문제입니다. 행·열 입력 셀만 헷갈리지 않으면 됩니다.

📑 부분합 복습 — 「그룹 사이에서 페이지 나누기」 (주로 필기에서 묻습니다)

어제 배운 것 다시 ① 그룹으로 묶을 항목으로 먼저 정렬 → ② 데이터 → 개요 → 부분합 → ③ 두 번째 부분합은 「새로운 값으로 대치」 해제 → ④ 되돌릴 때는 「모두 제거」.
오늘 새로 나온 항목 부분합 대화상자 아래쪽의 「그룹 사이에서 페이지 나누기」입니다. 체크하면 그룹이 바뀔 때마다 인쇄 페이지가 넘어갑니다.
확인하는 법 오른쪽 아래의 페이지 나누기 미리 보기로 전환하면 그룹 경계마다 파란 구분선이 들어가 있는 것이 보입니다.
실기에서는 거의 볼 일이 없습니다 강사가 수업에서 짚은 부분입니다. 실기라면 지시문에 적힌 대로 체크만 하면 되고, 판별을 요구하는 쪽은 필기입니다.
데이터 아래에 요약 표시 체크를 해제하면 각 그룹의 부분합 행이 그 그룹 데이터 위쪽에 표시됩니다. 기본값(체크됨)은 아래쪽이고, 보기에도 그편이 낫습니다.

🖥 필기 · 윈도우 설정 창 — 「어느 범주에 있나」를 묻습니다

여는 법 Windows + I. 예전 제어판에서 보던 항목들이 범주별로 모여 있습니다. 메뉴가 달라 보이면 왼쪽 「홈」으로 나가면 됩니다.
시험이 묻는 방식 기능 하나를 주고 「어느 범주에서 설정하나」를 묻습니다. 「모니터 해상도를 개인 설정에서 바꾼다」 같은 보기가 틀린 보기예요.
시스템 — 가장 많이 나옵니다. 디스플레이(해상도·방향·주 모니터·확장/복제·야간 모드), 알림과 집중 지원, 전원, 저장 공간, 정보.
개인 설정 — 지극히 «나»에 관한 것. 배경 화면·테마·색·잠금 화면·화면 보호기·마우스 커서 모양. 화면 보호기는 디스플레이별로 따로 설정할 수 없습니다(모니터가 여러 대여도 하나로 적용).
앱 — 설치된 프로그램 확인·제거, 연결 프로그램(기본 앱), 시작 프로그램, 선택적 기능. 윈도우 업데이트는 여기가 아니라 「업데이트 및 보안」입니다.
계정 · 접근성 · 장치 · 업데이트 및 보안 — 계정에는 사용자 계정 컨트롤(UAC), 장치에는 마우스(한 번에 1~100줄 스크롤, 왼손잡이 단추 바꾸기, 비활성 창 스크롤), 업데이트 및 보안에는 Windows Defender 방화벽이 있습니다.
방화벽의 한계 외부의 침입은 막지만, 내부에서 생기는 위협이나 모든 바이러스를 막아 주지는 않습니다. BitLocker는 드라이브 암호화, 멀웨어는 악성 프로그램을 통틀어 부르는 말입니다.
해상도 화면에 찍는 점(픽셀)의 개수입니다. 높일수록 선명해지지만 같은 화면에 더 촘촘히 담기니 바탕 화면 아이콘은 작아집니다.

🖨 필기 · 프린터와 스풀

로컬 프린터 내 컴퓨터에 선으로 직접 연결한 프린터. 설정할 것은 포트입니다. 교재에 나오는 로컬 포트는 LPT1·LPT2(병렬)와 COM1·COM2(직렬)이고, 요즘 USB로 연결한 프린터는 USB001 같은 USB 포트로 잡힙니다.
네트워크 프린터 사무실 복합기처럼 네트워크에 물린 프린터. 프린터의 공유 이름과 연결된 컴퓨터 이름, 또는 IP 주소를 알아야 합니다. 컴활 문제에서는 여기에 「LPT1 같은 포트를 지정한다」고 써 놓고 틀린 보기로 씁니다 — 포트는 로컬 쪽 표현이라고 기억하세요.
기본 프린터 Ctrl + P를 눌렀을 때 처음 잡히는 프린터. 한 대만 지정할 수 있고, 로컬이든 네트워크든 상관없습니다.
인쇄 대기열에서 되는 것 일시 중지 · 계속 · 다시 시작 · 취소. 인쇄 «중»인 문서도 중간에 취소할 수 있습니다.
인쇄 대기열에서 «안» 되는 것 대기 중인 문서의 용지 방향·용지 공급·인쇄 매수를 바꾸는 것. 이건 인쇄 명령을 내리기 전에 정하는 값이라, 고치려면 취소하고 다시 인쇄해야 합니다.
스풀(SPOOL)이란 느린 프린터와 빠른 CPU를 함께 굴리기 위해, 인쇄할 내용을 CPU가 계속 붙들고 있지 않고 하드디스크(보조기억장치)에 잠깐 맡겨 두는 기능입니다.
★ 스풀의 함정 좋아지는 것은 컴퓨터 전체(CPU)의 효율입니다. 스풀은 프린터의 인쇄 속도를 빠르게 해 주는 기능이 아니고, 보조기억장치를 한 번 더 거치므로 오히려 느려질 수 있습니다. 「스풀을 쓰면 인쇄가 빨라진다」는 틀린 보기예요.
