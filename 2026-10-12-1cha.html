이름이 정해져 있습니다

시험 문제는 기능이 아니라 이름을 묻습니다. 화면의 위치와 이름을 같이 외워 두세요.

1빠른 실행 도구 모음 — 저장·실행 취소·다시 실행이 기본으로 있습니다
2리본 메뉴 — 탭으로 나뉘고, 탭 안은 그룹으로 나뉩니다
3이름 상자 — 지금 선택한 셀의 위치
4수식 입력줄 — 셀에 실제로 들어 있는 값이나 수식
5상태 표시줄 — 범위를 선택하면 합계·평균·개수
명령을 찾아가는 방법먼저 탭을 고르고, 그 안의 그룹에서 아이콘을 찾습니다. 아이콘이 무엇인지 모르겠으면 마우스를 올려 설명(스크린 팁)을 보고, 더 자세한 설정이 필요하면 그룹 오른쪽 아래 작은 버튼으로 대화 상자를 엽니다.

필기 · 메모

셀 내용이 지워져도
메모는 지워지지 않습니다

1삽입: 검토 탭 → 새 메모 또는 Shift+F2
2표시 여부는 검토 탭 → 메모 모두 표시 로 켜고 끕니다.
3인쇄는 페이지 설정 → 시트 → 메모 에서 「시트에 표시된 대로」 또는 「시트 끝」을 고릅니다.
4위치 이동·크기 조절·글꼴 변경이 모두 됩니다.
자동 크기가 안 보일 때메모 안에 커서가 들어가 있으면 글꼴 탭만 나옵니다. 메모 테두리를 눌러 개체로 선택한 뒤 메모 서식 → 맞춤에서 「자동 크기」를 찾으세요.
