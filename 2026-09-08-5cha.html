고급 필터 조건: AND는 같은 줄, OR는 다른 줄

조건 범위는 맨 윗줄에 필드명을 적고 그 아래에 조건을 씁니다. 두 조건을 같은 줄에 나란히 적으면 "둘 다 만족"(AND), 다른 줄에 계단처럼 적으면 "둘 중 하나"(OR)가 됩니다.

줄이 같으면 그리고, 줄이 다르면 또는 — 이 한 줄로 외웁니다

자동 필터로 안 되는 것이 고급 필터가 필요한 이유

자동 필터는 AND 조건이면 필드가 몇 개든 됩니다. 막히는 건 서로 다른 필드 2개 이상에 OR를 걸 때예요. 이때부터 고급 필터를 써야 합니다.

필기 단골: "자동 필터로 가능한가?" → OR + 다른 필드 2개면 불가

동일한 레코드는 하나만 = 중복 제거

고급 필터 대화상자 아래의 이 체크는 결과에서 중복된 행을 한 번만 남깁니다. 조건 범위를 비우고 이것만 켜면 순수 중복 제거 도구가 돼요.

활용: 뽑아낸 목록을 데이터 유효성 검사의 원본으로 연결

F4 순환 순서 — 상대 → 절대 → 행절대 → 열절대

F4를 누를 때마다 C7 → $C$7 → C$7(행 고정) → $C7(열 고정) → 다시 C7로 돌고 돕니다. 지우고 다시 칠 필요가 없어요.

기본은 상대 참조 — 셀을 클릭하면 여기서 시작합니다

★채우는 방향이 무엇을 고정할지 정한다

오른쪽으로 채우면 열 문자가 변하고, 아래로 채우면 행 번호가 변합니다. 그러니 오른쪽으로 끌 때 안 변해야 하는 건 열을, 아래로 끌 때 안 변해야 하는 건 행을 고정해요.

수식을 쓰기 전에 "나는 어느 방향으로 끌 것인가"부터 정합니다

COUNT 삼형제 — 무엇을 세느냐가 다르다

COUNT는 숫자가 든 셀만, COUNTA는 숫자·문자 가리지 않고 값이 있는 셀을, COUNTBLANK는 반대로 빈 셀을 셉니다. 셋 다 세는 대상만 다릅니다.

COUNT·COUNTA는 빈 셀을 세지 않는다는 점이 공통

반복할 행 $3:$3 읽는 법

페이지 설정 → 시트 → 반복할 행에 $3:$3이라고 적혀 있으면 3행만 모든 페이지에 반복해 인쇄한다는 뜻입니다. $1:$3이면 1~3행을 함께 반복해요.

필기에서 이 입력란을 그대로 사진 찍어 물어봅니다

인쇄 마무리 — 어제 배운 것을 실제 문서에 적용하기

페이지 나누기 조절 페이지 나누기 미리 보기에서 경계선에 마우스를 올리면 포인터가 양쪽 화살표로 바뀝니다. 이때 드래그해서 인쇄 범위를 줄이거나, 잘린 열을 한 페이지 안으로 끌어들일 수 있어요.
회색 영역 인쇄에서 빠진 영역은 회색으로 보입니다. 내용이 지워진 게 아니라 비활성처럼 보이게 한 것뿐이에요.
페이지 설정 4개 탭 페이지(용지 방향·배율) / 여백(가로·세로 가운데 맞춤) / 머리글·바닥글 / 시트(반복할 행). 글자가 작으면 가로 방향으로 돌리고 배율을 120~130%까지 올립니다.
바닥글 페이지 번호 # 아이콘은 페이지 번호, 여러 장 겹친 아이콘은 전체 페이지 수입니다. 1 / 7처럼 넣어야 인쇄물이 몇 장 빠졌는지 바로 보여요.
⚠️인쇄 미리 보기에서 안 되는 것 미리 보기 상태의 페이지 설정에서는 시트 탭이 통째로 비활성화됩니다. 행·열을 고를 수 없기 때문이에요. ESC로 빠져나와 페이지 레이아웃 탭에서 열어야 반복할 행을 지정할 수 있습니다.
세로 가운데 맞춤 주의 여러 페이지 문서에서 세로 가운데 맞춤을 켜면 마지막 페이지의 몇 줄이 한가운데 떠 보여 어색합니다. 이럴 땐 세로만 꺼두는 편이 낫습니다.
레코드를 페이지마다 고르게 필드명을 뺀 첫 데이터 셀에서 Ctrl+Shift+↓를 누르면 레코드 전체가 선택되고 상태 표시줄에 개수가 뜹니다. 그 수를 페이지 수로 나눠 경계선을 맞춰 주면 돼요.
시험 예시: 반복할 행은 인쇄 미리 보기 화면에서도 지정할 수 있다 → 틀린 설명. 시트 탭이 비활성화됩니다.

고급 필터 — 조건 범위를 내가 직접 만든다

자동 필터와의 갈림길 자동 필터는 목록 단추에서 고르는 방식이라 서로 다른 필드 2개 이상에 OR를 걸 수 없습니다. 그럴 때 조건을 표로 직접 써 주는 고급 필터가 필요해요.
조건 범위 만들기 빈 곳에 원본과 똑같은 필드명을 적고, 그 아래 줄에 조건을 씁니다. 필드명이 원본과 다르면 동작하지 않아요.
★AND와 OR 조건을 같은 줄에 쓰면 그리고(AND), 다른 줄에 쓰면 또는(OR)입니다. 예를 들어 「부서=영업」과 「점수>=80」을 같은 줄에 쓰면 둘 다 만족하는 행만, 위아래로 나눠 쓰면 둘 중 하나만 만족해도 나옵니다.
실행 데이터 탭 → 정렬 및 필터 → 고급. 대화상자에서 ①현재 위치에 필터 / 다른 장소에 복사 ②목록 범위(원본 표) ③조건 범위 ④복사 위치를 지정합니다.
특정 필드만 뽑기 복사 위치에 원하는 필드명만 미리 적어두면 그 열만 추출됩니다. 예를 들어 「등급」만 적어두면 조건에 맞는 사람들의 등급만 나와요.
동일한 레코드는 하나만 대화상자 아래의 이 체크를 켜면 중복된 행이 하나만 남습니다. 조건 범위 없이 이것만 써서 중복 제거 용도로도 씁니다.
만능 문자 조건에 김*이라고 쓰면 김으로 시작하는 모든 이름이 걸립니다. ?는 한 글자, *는 여러 글자예요.
시험 예시: 목록 범위를 A2:A10(등급 열)만 잡아놓고 조건 범위에 「이름」 필드를 쓰면 → 동작하지 않습니다. 조건은 목록 범위 안에 있는 필드로만 걸 수 있어요.

참조 — 상대·절대·혼합, 그리고 F4

상대 참조 기본값입니다. 채우기 핸들로 끌면 끄는 방향에 따라 셀 주소가 따라 움직입니다. 아래로 끌면 행 번호가, 오른쪽으로 끌면 열 문자가 하나씩 밀려요.
절대 참조 $C$7처럼 행·열 앞에 모두 $를 붙이면 어느 방향으로 끌어도 그 자리에 못 박힙니다. 부가세율처럼 한 셀에 적어둔 상수를 참조할 때 씁니다.
혼합 참조 C$7은 행만 고정(열은 움직임), $C7은 열만 고정(행은 움직임)입니다. 오른쪽·아래 양쪽으로 끌어야 하는 표(환율표·구구단 같은 교차표)에서 필요해요.
★F4 순환 주소에 커서를 두고 F4를 누를 때마다 상대 → 절대 → 행 고정 → 열 고정 → 다시 상대로 돕니다. 원하는 모양이 나올 때까지 누르면 되고, $를 지우려고 백스페이스를 칠 필요가 없어요.
상수는 셀에 따로 담는다 수식에 *0.1이라고 직접 쓰지 말고 부가세율 10%를 한 셀에 적어두고 그 셀을 참조하세요. 나중에 11%로 바뀌어도 그 한 칸만 고치면 수백 개 수식이 한꺼번에 바뀝니다.
시험 예시: 오른쪽으로 채울 때 열이 밀려서 틀렸다면 → 열을 고정한 $C7이 필요합니다. 아래로 채울 때 행이 밀려서 틀렸다면 → 행을 고정한 C$7이 필요해요.

수식이 틀렸을 때 원인을 눈으로 찾는 법

F2 — 참조 셀을 색 상자로 값이 이상한 셀을 클릭하고 F2를 누르면 그 수식이 참조하는 셀들이 색 테두리 상자로 표시됩니다. 엉뚱한 칸을 가리키고 있으면 바로 눈에 들어와요.
Ctrl+` — 수식 전체 보기 물결표(`, ESC 바로 아래) 키를 Ctrl과 함께 누르면 시트 전체가 결과 대신 수식으로 바뀝니다. 다시 누르면 원래대로 돌아와요. 다만 어느 셀을 참조하는지는 눈으로 따라가야 합니다.
채우기 핸들 더블 클릭 채우기 핸들을 더블 클릭하면 아래로 자동으로 채워집니다. 단 왼쪽 열에 데이터가 이어져 있어야 어디까지 채울지 엑셀이 판단할 수 있어요.
괄호 색으로 확인 수식을 닫을 때 마지막 괄호가 검은색이면 제대로 닫힌 것입니다. 함수가 하나면 안 닫아도 엑셀이 닫아 주지만, 함수를 겹쳐 쓸 때는 꼭 직접 닫는 습관을 들이세요.
Ctrl+Shift+↓ 습관 실무 데이터는 1000행이 넘어 마우스로 못 끕니다. 첫 데이터 셀에서 Ctrl+Shift+↓로 범위를 잡는 연습을 지금부터 해 두세요.
시험 예시: 결과가 아니라 수식 자체를 화면에 표시하는 단축키는 Ctrl+` 입니다.

기본 함수 — 인수를 외울 필요 없는 것들부터

SUM 범위의 합계. =SUM(범위)
AVERAGE 범위의 평균. =AVERAGE(범위) — 이름이 길어 AVE까지 치고 목록에서 골라 Tab으로 넣으면 편합니다.
MAX / MIN 범위에서 가장 큰 값 / 가장 작은 값. =MAX(범위), =MIN(범위)
★COUNT 범위에서 숫자가 들어 있는 셀의 개수만 셉니다. 문자가 섞여 있으면 그 칸은 세지 않아요.
★COUNTA 숫자든 문자든 무언가 들어 있는 셀을 전부 셉니다. 이름·비고처럼 문자로 된 열의 개수를 셀 때 씁니다.
★COUNTBLANK 반대로 비어 있는 셀을 셉니다. 데이터 분석에서 말하는 결측치를 세는 것과 같아요.
공통점 이 여섯 함수는 괄호 안에 범위만 넣으면 되어서 인수 순서를 외울 필요가 없습니다. 어려운 함수는 그다음부터예요.
시험 예시: 문자와 숫자가 섞인 범위에서 값이 있는 칸을 모두 세려면 COUNT가 아니라 COUNTA를 씁니다.

고급 필터 조건을 같은 줄에 쓸지 다른 줄에 쓸지 헷갈려요

조건을 어디에 쓰느냐가 곧 AND냐 OR냐를 정합니다. 같은 줄이면 둘 다 만족, 다른 줄이면 둘 중 하나입니다.

"줄이 같으면 그리고, 줄이 다르면 또는" — 조건표를 그려 보고 시작하세요.

자주 하는 실수

채우기를 하고 값이 이상한데 원인을 못 찾아요

거의 대부분 참조 문제입니다. 오른쪽으로 끌었는데 열이 따라 움직여 버렸거나, 아래로 끌었는데 행이 밀린 경우예요.

문제 생긴 셀에서 F2를 눌러 색 상자가 어디를 가리키는지 확인하고, F4로 고정하세요.

자주 하는 실수

인쇄 미리 보기 화면에서 반복할 행을 지정하려고 해요

미리 보기 상태에서는 페이지 설정의 시트 탭이 통째로 비활성화됩니다. 행·열을 선택할 수 없기 때문이에요.

ESC로 빠져나온 뒤 페이지 레이아웃 탭에서 페이지 설정을 여세요.

자주 하는 실수

문자가 섞인 열의 개수를 COUNT로 세요

COUNT는 숫자가 든 칸만 셉니다. 이름처럼 문자로 된 열에 쓰면 0이 나와요.

값이 있는 칸을 모두 세려면 COUNTA, 빈 칸을 세려면 COUNTBLANK입니다.

자주 하는 실수

수식에 0.1처럼 상수를 직접 타이핑해요

나중에 비율이 바뀌면 그 수식을 전부 찾아 고쳐야 합니다. 수백 개면 손도 못 대요.

상수는 셀 하나에 적어두고 절대 참조로 가져다 쓰세요. 그 한 칸만 고치면 전부 바뀝니다.
