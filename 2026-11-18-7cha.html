3조건 목록은 복사 · 붙여넣기 해도 됩니다. 서식이 바뀌는 것은 신경 쓰지 않아도 됩니다

복습 · 데이터베이스 함수

1=DAVERAGE(A3:G63,E3,I20:I21)

세 수식은 결과가 같습니다
2데이터베이스 — 머리글부터 아래 레코드 전체. 이 문제처럼 한 셀만 구하면 절대 참조는 필요 없습니다
3필드 — 열 번호는 반드시 숫자로 씁니다. 세 방법의 결과는 같습니다
복습 · 찾기 함수

표 범위는 세 가지 규칙으로

1=VLOOKUP(I32,$I$27:$J$29,2,FALSE) → 냉동이면 50
2기준표 규칙 3가지 — 검색값이 첫 열 · 머리글은 보통 제외 · 복사할 때 절대 참조
3이 문제처럼 구분을 정확히 찾을 때는 FALSE로 씁니다
4열 번호는 기준표 안에서 센 순서입니다(구분 1, 할증률 2)
복습 · 찾기 함수

VLOOKUP을 수식 안에 넣기

1=ROUNDDOWN(K32*(1+VLOOKUP(I32,$I$27:$J$29,2,FALSE)/100),-1)
2안쪽 함수 먼저 — VLOOKUP이 할증률(50)을 찾아 /100으로 0.5가 됩니다
3괄호가 여러 개일 때는 마지막 닫는 괄호가 검은색인지 확인합니다
실무 연결

선택하면 결과가 바뀌는 표

1중복 제거 목록 — 고급 필터의 동일한 레코드는 하나만
2선택 상자 — 데이터 유효성 검사에서 제한 대상을 목록으로
3시험 범위라기보다 실무에서 기능을 이어 쓰는 예시입니다
텍스트 함수

UPPER · LOWER · PROPER

1=PROPER(A5) → Seoul Fresh Mart
2PROPER는 각 단어의 첫 글자를 대문자로, 나머지 영문자를 소문자로 바꿉니다
3한글에는 영향이 없고 영문자만 바뀝니다
텍스트 함수

SEARCH: 위치 번호

1=SEARCH("kr",A19) → 1 (FIND는 오류)
2SEARCH는 대소문자를 구분하지 않고, FIND는 구분합니다
3위치 번호는 LEFT · MID와 짝을 지어 부분 글자를 꺼낼 때 씁니다
텍스트 함수

쉼표 앞 글자 꺼내기

1=LEFT(A13,SEARCH("@",A13)-1) → minsu
2-1을 하지 않으면 구분 문자(@, 쉼표)까지 함께 가져옵니다
3수업에서는 쉼표, 수업 파일에서는 @로 연습했습니다. 방법은 같습니다
통계 함수

RANK.EQ: 점수 · 범위 · 정렬

1=RANK.EQ(C6,$C$6:$C$15,0) → 기사01은 2
2인수 순서 — 개인 점수, 전체 범위, 정렬 방식
3동점이면 같은 순위를 주고 다음 순위는 건너뜁니다(2, 2, 2 다음은 5)
4RANK.AVG는 동점의 순위를 평균으로 구하는 함수입니다
통계 함수

정렬 방식: 0과 1

1=RANK.EQ(C6,$C$6:$C$15,1) → 기사01은 7
20 — 큰 값이 1등(점수) · 1 — 작은 값이 1등(달리기 기록). 0 이외의 값은 오름차순입니다
3생략하면 0(내림차순)으로 계산합니다. 연습 때는 직접 써 보세요
통계 함수

k번째로 큰 값 · 작은 값

1=LARGE(C6:C15,3) → 91 (91이 세 번 나와 3번째도 91)
2k는 몇 번째인지 쓰는 숫자입니다. 생략할 수 없습니다
3LARGE(범위,1)은 MAX와 같은 결과입니다
통계 함수

MODE.SNGL · MEDIAN

1=MODE.SNGL(C6:C15) → 91 · =MEDIAN(C6:C15) → 86
2MEDIAN — 점수를 세우면 5번째와 6번째가 86, 86이라 중앙값은 86
3반복되는 값이 없으면 MODE.SNGL은 #N/A가 됩니다
통계 함수

STDEV.S · VAR.S

1=STDEV.S(C6:C15) → 약 11.74
2표준편차 = √분산
3이 문제에서는 점수 범위 하나를 인수로 씁니다
찾기 · 참조 함수

INDEX: 행 번호와 열 번호

1=INDEX($B$6:$E$10,B14,C14) → 행 3, 열 3 = 9,500
2행 번호 · 열 번호에는 숫자가 들어갑니다. 문자는 안 됩니다
3번호는 선택한 범위 안에서 1부터 세므로 범위를 어디서 시작했는지 확인합니다
찾기 · 참조 함수

결과가 될 수 있는 범위만 선택

1INDEX($B$6:$F$10, …) — 요금 숫자만 범위로 잡습니다
2머리글과 지역 열을 포함하면 번호를 하나씩 더 세야 해서 헷갈립니다
3결과 범위는 채우기 핸들을 쓰므로 절대 참조합니다
찾기 · 참조 함수

MATCH: 몇 번째인지

1=MATCH(E6,$B$6:$B$10,0) → WB-1044는 4번째
2MATCH는 위치 번호만 돌려주므로 INDEX와 짝으로 씁니다
3이름을 정확히 찾을 때 일치 유형은 0입니다. 생략하지 않습니다
찾기 · 참조 함수

번호를 MATCH가 대신 찾기

1=INDEX($B$6:$F$10,MATCH(B14,$A$6:$A$10,0),C14) → 대전, 3구간 = 4,700
2행 번호 = MATCH(지역, 지역 열, 0) · 열 번호 = 구간 번호
3값이 이상하면 MATCH 부분만 드래그해 행 번호를 확인하고, 범위의 절대 참조를 점검합니다
4괄호는 마지막 닫는 괄호가 검은색으로 끝나는지 확인합니다
찾기 · 참조 함수

검색 열이 오른쪽에 있을 때

1=INDEX($A$21:$A$25,MATCH(B28,$B$21:$B$25,0)) → 조하린 = 78라9140
2VLOOKUP은 검색값이 첫 열(왼쪽)이어야 해서 이 표는 못 찾습니다
3실무에서는 열을 옮길 수 없는 경우에 INDEX + MATCH를 씁니다
INDEX · MATCH · 2차원

행도 열도 MATCH로

1=INDEX($B$6:$D$8,MATCH(B12,$A$6:$A$8,0),MATCH(C12,$B$5:$D$5,0))
2대인 · 종일권 → 행 2, 열 3 = 17,000
3행은 세로 범위(A6:A8), 열은 가로 범위(B5:D5)에서 찾습니다
4요금이 바뀌면 표만 고치면 되고 수식은 그대로입니다
응용

번호를 구하는 함수를 바꾸기

1=INDEX($B$24:$E$26,MATCH(B29,$A$24:$A$26,0),MATCH(C29,$B$23:$E$23,1)) → 중부권 7kg = 5,000
2중량 7kg → 5 이상 10 미만 → 두 번째 열(MATCH 1은 이하 중 가장 큰 기준의 위치)
3지역은 이름이므로 정확히(0), 중량은 구간이므로 1
실기 적용 · 마지막 문제

매출 2번째 기사 이름 찾기

1=INDEX(A6:A17,MATCH(LARGE(D6:D17,2),D6:D17,0)) → 임지후
2LARGE → MATCH → INDEX 순서로 생각하고, 수식은 바깥 INDEX부터 씁니다
3LARGE는 값(5,310,000)을 구하고, MATCH는 그 값의 위치(3)를 구해 INDEX가 이름을 꺼냅니다
4MATCH의 마지막 인수는 값을 정확히 찾으므로 0
실기 적용 · 마지막 문제

안쪽부터 확인하며 쓰기

1범위 짝 맞추기 — 이름 열(A6:A17)과 매출 열(D6:D17)은 같은 행에서 시작하고 끝나게 맞춥니다
2점검 — 수식 안에서 LARGE 부분 선택 후 F9로 값을 보고 반드시 Esc로 되돌립니다(Enter를 누르면 계산된 값이 수식에 남습니다)
3비슷한 문제는 LARGE 대신 SMALL로, 3번째 · 5번째로 바뀝니다
실기 적용 · 마지막 문제

지역과 면적으로 예치금 찾기

1=INDEX(G6:J8,MATCH(G11,F6:F8,0),MATCH(G12,G5:J5,0)) → 기타광역시 · 102㎡이하 = 400(만원)
2행 = 거주 지역을 F6:F8에서, 열 = 희망 면적을 G5:J5에서
3표의 값은 연습용 가상 금액입니다
