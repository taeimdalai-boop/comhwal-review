📌오늘 배운 핵심 요약

[필기] ★가장 많이 나오는 건 PC

프로그램 카운터(PC)는 다음에 실행할 명령어의 «주소»를 기억합니다. 명령 레지스터(IR)는 현재 실행 중인 명령어 «자체»를 담아요. 이 둘이 제어장치의 핵심입니다.

주소는 PC · 명령어는 IR

[필기] 보수기 = 뺄셈 담당

연산장치에는 더하는 가산기는 있어도 감산기는 없습니다. 그 자리를 보수기가 대신해 뺄셈을 처리해요. 강사가 "제일 잘 까먹는다"고 별표한 항목입니다.

누산기(AC)는 연산 결과를 잠시 보관

[필기] 캐시는 «속도차», 가상은 «용량»

캐시 메모리(SRAM)는 빠른 CPU와 느린 주기억장치 사이의 속도 차이를 메웁니다. 가상 메모리는 하드디스크 일부를 빌려 용량 부족을 해결하고요.

가상 메모리를 쓰면 속도는 느려질 수 있음

[필기] 밀 · 마 · 나 · 피 · 펨 · 아

처리 속도 단위는 ms → μs → ns → ps → fs → as 순으로 빨라지고, 지수는 10⁻³부터 3씩 내려가 10⁻¹⁸까지 갑니다.

순서를 묻는 문제가 실제로 나옵니다

[필기] USB는 «직렬» — 한 비트씩

이름부터 범용 직렬 버스라서 데이터를 한 비트씩 보냅니다. 「8비트씩」은 틀린 보기예요. 최대 127개 연결, 핫 플러그·플러그 앤 플레이 지원.

[실기] 매크로 키는 엑셀 기본보다 우선 — 어제 69%

차트 문제는 2점씩 5개, 총 10점이라 부분 점수가 있습니다. 다만 차트를 지우고 새로 만들면 채점이 안 됩니다 — 실수로 지웠다면 즉시 Ctrl + Z.

실기에서 배웠지만 필기에도 나오는 것 오늘치는 시나리오의 「숨기기」와 시트 보호, 매크로 바로 가기 키·Alt+F8·Alt+F11, 차트의 Alt+F1·F11과 구성 요소 이름입니다.

🧠 [필기] 중앙처리장치(CPU) — 제어장치와 연산장치

제어장치(CU) 컴퓨터에 연결된 모든 장치의 동작을 지시·감독합니다. 구성 요소를 쌍으로 외우세요.
PC(프로그램 카운터) ↔ IR(명령 레지스터) PC는 다음에 실행할 명령어의 «번지»를, IR은 현재 실행 중인 명령어 «자체»를 기억합니다. 출제 빈도가 가장 높은 것이 PC입니다(프로그램 계수기라고도 부름).
해독기(디코더) ↔ 부호기(인코더) 기계어로 된 명령어를 해독해 CPU가 알아듣게 만들고, 반대로 제어 신호를 만들 때는 부호기가 씁니다.
MAR ↔ MBR MAR(Memory Address Register)은 주소를, MBR(Buffer)은 내용(명령어·데이터)을 잠시 담아 두는 버퍼입니다. A는 Address라고 외우면 쉽습니다.
연산장치(ALU) 산술·논리·관계·시프트 연산을 합니다. 가산기(Adder)는 2진수 덧셈, 보수기는 뺄셈 담당 — 컴퓨터에는 감산기가 따로 없어, 값을 반대로 바꾼 보수를 더해 뺄셈을 흉내 냅니다.
누산기(AC) 연산의 중간·최종 결과를 일시적으로 저장합니다. 「연산 중 발생하는 상태(부호·자리 올림·오버플로·인터럽트)」를 기억하는 것은 상태 레지스터로, 누산기와 헷갈리게 내는 문제가 나옵니다.
그 밖에 데이터 레지스터(연산할 값), 인덱스 레지스터(주소 변경), 범용 레지스터. 그리고 레지스터는 모든 기억장치 중 가장 빠릅니다.

💾 [필기] 주기억장치 — ROM · RAM과 기타 메모리

ROM 전원을 꺼도 내용이 남는(비휘발성) 읽기 전용 메모리. 바이오스(BIOS·기본 입출력 시스템), 글자 폰트, POST(자가 진단 프로그램)가 들어 있어 부팅에 꼭 필요합니다. POST는 전원을 켰을 때 주변 장치가 제대로 붙어 있는지 검사하고, 이상이 있으면 «삐» 소리로 알립니다.
EEPROM ROM 중에서 전기적인 방법으로 여러 번 지우고 다시 쓸 수 있는 것. 요즘 출제는 거의 여기에 몰려 있습니다.
RAM 현재 실행 중인 프로그램과 데이터가 올라가는 곳. 전원이 꺼지면 내용이 사라집니다(휘발성). DRAM이 주기억장치로 쓰이고, SRAM은 더 빠릅니다 — S라인이 빠르고 D라인이 느리다로 외우세요.
캐시 메모리 = SRAM 아주 빠른 CPU와 상대적으로 느린 DRAM 사이의 속도 차이를 메우는 완충 지대입니다.
가상 메모리 보조기억장치(하드디스크)의 일부를 주기억장치처럼 빌려 쓰는 기법. 주기억장치보다 큰 프로그램, 또는 여러 개를 동시에 돌릴 때 유용합니다. 다만 보조기억장치를 거치므로 처리 속도는 오히려 느려질 수 있습니다.
플래시 메모리 EEPROM의 일종으로 비휘발성이고, 데이터를 블록 단위로 다룹니다(원판을 쓰는 하드디스크의 트랙·섹터 단위가 아닙니다 — 이 대비로 출제됩니다). 스마트폰·디지털카메라·블랙박스·SSD에 쓰입니다.
연관 메모리 주소가 아니라 내용으로 검색해 찾아가는 방식. 버퍼 메모리는 속도가 다른 두 장치 사이에 두는 임시 공간입니다.

🗄 [필기] 보조기억장치 · 용량 단위 · 접근 속도

하드디스크(HDD) 자성 물질을 입힌 금속 원판을 겹쳐 돌리며 읽습니다. 값이 싸고 용량이 크지만 충격에 약해 본체 안에 고정해 씁니다.
SSD 반도체를 쓰므로 원판·헤드 같은 기계 장치가 없습니다. 그래서 충격에 강하고 발열·소음이 적으며 빠르고 가볍습니다. 교재는 「기계적 지연이나 에러 발생 확률이 낮다」고 설명해요. 단점은 하드디스크보다 비싸다는 점입니다(쓰기 수명에도 한계가 있습니다).
광디스크 DVD는 4.7~17GB, 블루레이는 25~50GB로 DVD보다 훨씬 많이 담습니다.
기억 용량 단위 B → KB → MB → GB → TB → PB → EB. 한 단계 올라갈 때마다 2¹⁰(=1,024)배입니다. "1GB는 정확히 몇 바이트인가" 같은 문제가 나와요.
접근 속도 순서 레지스터 → 캐시(SRAM) → 주기억장치(RAM·ROM) → 보조기억장치. 굳이 표를 외우지 않아도 «CPU에 가까울수록 빠르다»로 정리됩니다.
처리 속도 단위 — 밀·마·나·피·펨·아 ms(10⁻³) → μs(10⁻⁶) → ns(10⁻⁹) → ps(10⁻¹²) → fs(10⁻¹⁵) → as(10⁻¹⁸). 뒤로 갈수록 빠릅니다. 순서를 묻는 문제가 실제로 출제됩니다.

⌨️ [필기] 입력장치와 출력장치 · 프린터

입력장치 키보드·마우스·터치스크린/터치패드·트랙볼·스캐너·디지타이저와 태블릿·디지털카메라. 판독기 4종(OMR 광학 마크, OCR 광학 문자, MICR 자기 잉크 문자, 바코드)도 입력장치입니다.
키오스크 터치스크린·사운드·통신 카드를 갖춘 무인 종합 정보 안내 시스템. 요즘 이 단원에서 가장 자주 나옵니다(전시장·쇼핑센터·터미널의 안내 단말, 무인 주문기).
UPS 무정전 전원 공급 장치 — 정전이 되어도 잠시 전원을 공급해 줍니다.
모니터 용어 픽셀(화면을 이루는 점), 해상도(점의 개수 — 많을수록 선명), 재생률, 점 간격.
프린터 5종 도트 매트릭스(핀으로 리본을 때리는 충격식) · 잉크젯(노즐로 분사) · 레이저(드럼에 토너를 묻혀 인쇄, 비충격식이라 빠르고 조용하지만 비쌈) · 감열식(영수증·휴대용 프린터) · 열전사(리본을 녹여 유통기한 등 인쇄).
프린터 단위 CPS(초당 문자) · LPM(분당 줄) · PPM(분당 페이지) · DPI(인치당 점). 그리고 국제 표준화 기구(ISO)가 정한 것은 IPM(분당 이미지 수) — 「표준」이라는 말이 보이면 IPM입니다.

🔌 [필기] 채널 · 포트 · HDMI

채널 CPU가 입출력까지 전부 맡으면 다른 일을 못 하니, 입출력에 대한 제어권을 넘겨받아 대신 처리하는 장치입니다. 「입출력」이 보이면 채널로 연결하세요. 작업이 끝나거나 문제가 생기면 인터럽트 신호를 보냅니다.
주의 「CPU와 주기억장치 사이의 속도 차이를 해결한다」는 채널이 아니라 캐시 메모리 설명입니다 — 채널 문제의 단골 오답입니다.
포트 본체 뒤쪽에 꽂는 구멍. 직렬은 한 번에 1비트씩, 병렬(LPT)은 여러 비트를 한꺼번에 보냅니다. PS/2는 예전 키보드·마우스용으로 요즘은 쓰지 않습니다.
USB 범용 직렬 버스 — 이름 그대로 한 비트씩 전송합니다(「8비트씩」은 틀린 보기). 기존 직렬·병렬·PS/2를 통합했고, 허브를 쓰면 최대 127개까지 연결합니다. 전원이 켜진 채로 꽂는 핫 플러그와 플러그 앤 플레이를 지원해요.
USB 단자 색 교재와 시험은 2.0 이하 검정(또는 흰색) · 3.0 파랑 · 그 이후 하늘색이나 빨강으로 정리합니다 — 버전이 올라갈수록 색이 화려해진다로 외우세요. 실제 제품의 색은 제조사마다 다를 수 있고, 속도도 포트·케이블·장치가 모두 그 규격을 지원해야 나옵니다.
HDMI 영상과 음향을 압축하지 않고 하나로 전송하는 고화질 멀티미디어 인터페이스. 「영상과 음성을 한 케이블로」가 보이면 HDMI입니다.

🎯 [실기] 목표값 찾기 다시 — 지난 퀴즈 62%

가장 많이 틀린 문항이었습니다. 「월 상환액이 20,000원이 되려면 상환 기간이 얼마여야 하나」에서 값을 바꿀 셀에 무엇을 넣느냐를 묻는 문제였어요.
세 칸의 뜻을 문장으로 「이 «수식 셀»이 «찾는 값»이 되게 하려면, 이 «값을 바꿀 셀»을 얼마로 해야 하나?」 — 대화상자를 이 문장 그대로 읽으면 헷갈리지 않습니다.
결과 ↔ 원인 수식 셀은 결과(수식이 들어 있어야 함), 값을 바꿀 셀은 원인입니다. 상환액을 바꾸려고 상환액 칸을 바꿀 셀에 넣으면 안 됩니다.
오늘 해 본 예 순수 매출액을 60만 원으로 만들려고 단가를 조정했습니다. 수식 셀 = 순수 매출액, 찾는 값 = 600000, 값을 바꿀 셀 = 단가.
단위 주의 표에 «단위: 천 원»처럼 0 세 개가 생략돼 있으면 목표 금액도 그 단위로 적습니다. 잘못했으면 Ctrl + Z로 즉시 되돌리면 됩니다.

⚙️ [실기] 매크로 다시 — 지난 퀴즈 69% · 단축키가 헷갈립니다

바로 가기 키의 우선순위 매크로에 Ctrl + G를 지정하면, 그 통합 문서가 열려 있는 동안 Ctrl + G는 원래 기능(이동)이 아니라 매크로를 실행합니다. 기본은 Ctrl + 문자, 대문자로 입력하면 Ctrl + Shift + 문자가 되고 Alt 조합은 지정할 수 없습니다.
Alt + F8 매크로 대화상자가 열립니다 — 실행·편집·삭제는 되지만 여기서 «기록»은 할 수 없습니다. 기록은 리본의 매크로 기록 단추로만 시작합니다(이 단추에는 단축키가 없습니다).
Alt + F11 VBA 편집기가 열립니다. 개발 도구 탭이 없어도 열 수 있고, 삽입 → 모듈에 코드를 붙여 넣을 수 있어요.
「상대 참조로 기록」을 누르지 마세요 매크로 기록 단추 옆에 있어서 실수로 눌리기 쉽습니다. 켜져 있으면 «어디서 실행하든 같은 칸»이 아니라 현재 위치 기준으로 동작해 채점이 틀어집니다.
서식 매크로 검증법 수식 매크로는 결과를 지우고 눌러 보면 되는데, 서식은 헷갈립니다 — 채우기 색을 「없음」이나 다른 색으로 바꾼 뒤 단추를 눌러 원래 색이 다시 칠해지는지 보면 됩니다. 글자 색 매크로면 글자 색을 바꿔 놓고 확인하세요.
잘못 만들었으면 지우고 다시 코드를 고치려 들지 말고 개발 도구 → 매크로 → 삭제 후 처음부터 다시 기록하는 편이 빠릅니다.
