복습 · 12차시

다시 짚어 두는 2가지

1IPCONFIG는 컴퓨터의 IPv4 · IPv6 주소, 서브넷 마스크, 기본 게이트웨이 같은 네트워크 설정 정보를 보여 주는 명령입니다. PING 주소는 대상과 신호가 오가는지 확인하고, DIR은 현재 폴더의 목록을 보여 줍니다
2니블은 4비트이고 n비트는 2ⁿ가지를 표현하므로 4비트는 16가지입니다. 바이트(8비트)는 256가지(0~255)입니다
3고정 IP를 직접 설정할 때는 IP 주소와 서브넷 마스크를 입력하고, 외부 통신과 이름 해석이 필요하면 기본 게이트웨이와 DNS 서버 주소도 입력합니다. DHCP는 IP를 자동으로 할당합니다
필기 · 컴퓨터 분류

세대별 주요 소자

1교재에서는 컴퓨터를 1세대 진공관 › 2세대 트랜지스터 › 3세대 집적회로(IC) › 4세대 고밀도 집적회로(LSI) › 5세대 초고밀도 집적회로(VLSI)와 인공지능 순으로 분류합니다. 3세대부터 집적회로를 사용합니다
2컴활 교재의 전통적 분류에서는 처리 능력에 따라 슈퍼 › 메인프레임 › 미니 › 마이크로컴퓨터 순이고, 데이터 취급 방식으로는 디지털 · 아날로그 · 하이브리드로 나눕니다. 두 분류를 섞은 보기에 주의합니다
3교재의 비교표에서는 디지털 컴퓨터를 정밀도가 높고 프로그램과 기억 장치가 필요한 범용 컴퓨터, 아날로그 컴퓨터를 연속적인 신호를 처리하는 용도가 정해진 컴퓨터로 정리합니다
필기 · 진법

3비트는 8진수, 4비트는 16진수

1진법은 숫자를 표현하는 규칙입니다. 10진수는 0~9, 2진수는 0과 1을 씁니다. 컴퓨터는 2진수를 쓰는 것이 편하기 때문에 시험에는 2진수를 8진수 · 16진수로 바꾸는 문제가 나옵니다
22진수를 오른쪽부터 3비트씩 묶으면 8진수, 오른쪽부터 4비트씩 묶으면 16진수로 바꿀 수 있습니다. 묶음마다 오른쪽 자리부터 1 · 2 · 4(16진수는 1 · 2 · 4 · 8)를 부여하고 비트가 1인 자리만 더합니다
3예) 101 → 4+1 = 5, 101101을 3비트씩 나누면 101 101 → 8진수 55
필기 · 진법

16진수에서 10~15는 A~F

116진수는 0~9와 A~F를 씁니다. 10=A, 11=B, 12=C, 13=D, 14=E, 15=F입니다
210진수 10은 2진수 1010입니다(8+2). 4비트가 모두 1인 1111은 15이므로 16진수로 F입니다
32진수 → 8진수 · 16진수 변환은 묶는 비트 수(3, 4)와 오른쪽부터 나눈다는 점, 16진수의 10~15를 숫자가 아닌 A~F로 쓴다는 점이 핵심입니다
필기 · CPU

제어 장치 · 연산 장치 · 레지스터

1CPU는 제어 장치 · 연산 장치 · 레지스터로 구성됩니다. SSD는 CPU의 구성 요소가 아니라 보조기억장치입니다
2프로그램 카운터(PC)는 다음에 실행할 명령어의 주소를, 명령 레지스터(IR)는 현재 실행할 명령어를 기억합니다. PC와 IR을 한 쌍으로 외웁니다
3명령 해독기(디코더)는 가져온 명령을 해독하고, 부호기(인코더)는 각 장치에 보낼 제어 신호를 만듭니다
4MAR은 접근할 메모리 주소를, MBR은 메모리와 주고받는 명령이나 데이터를 잠시 저장합니다. 이름이 비슷한 쌍을 구분합니다
필기 · 연산 장치 · 레지스터

이름과 역할을 짝지어 외웁니다

1가산기는 2진수 덧셈을 합니다. 교재에서는 뺄셈을 보수를 취해 덧셈하는 방식으로 설명하며, 보수기는 진수 변환 장치가 아니라 뺄셈을 위한 장치입니다
2누산기는 연산의 중간 결과를, 상태 레지스터는 캐리 · 오버플로 · 언더플로 · 인터럽트 같은 상태를 기억합니다. 두 가지를 혼동하지 않습니다
3레지스터는 CPU 안의 소량의 임시 기억 장치이며 기억 장치 중 가장 빠릅니다
필기 · 기억장치

ROM은 비휘발성, RAM은 휘발성

1ROM은 기본적으로 읽기 전용이고 비휘발성입니다. 교재에서는 BIOS · 글자 폰트 같은 기본 정보를 ROM에 저장한다고 설명합니다. POST는 전원을 켤 때 주변 장치를 검사해 문제가 있으면 신호음으로 알리는 부팅 시 검사입니다. EEPROM은 전기적으로 읽고 쓸 수 있는 ROM이며, 플래시 메모리는 EEPROM 계열입니다
2RAM은 자유롭게 읽고 쓸 수 있고 운영체제와 실행 중인 프로그램이 적재되며, 전원이 꺼지면 내용이 사라지는 휘발성 기억 장치입니다
3DRAM은 주기억장치에 쓰이고 주기적인 재충전이 필요합니다. SRAM은 DRAM보다 빠르고 비싸며 캐시 메모리에 씁니다
필기 · 기억장치

캐시 · 가상 · 연관 메모리

1캐시 메모리는 CPU와 주기억장치 사이에서 속도 차이를 줄이는 버퍼 메모리입니다. 속도 차이를 해결하는 것은 채널이 아니라 캐시입니다
2가상 메모리는 보조기억장치의 일부를 주기억장치처럼 써서 큰 프로그램이나 여러 프로그램을 실행할 수 있게 합니다. 실행 가능한 프로그램의 크기와 수가 늘 뿐, 실제 RAM보다 느려 수행 속도가 빨라지는 것은 아닙니다
3연관 메모리는 주소가 아니라 저장된 내용의 일부를 이용해 검색하고, 플래시 메모리는 비휘발성이며 교재에서는 트랙이 아니라 블록 단위로 저장한다고 정리합니다
필기 · 보조기억장치

HDD와 SSD의 차이

1HDD는 자성 물질을 입힌 원판에 저장하며 용량이 크고 저렴하지만 충격과 자석에 약합니다
2SSD는 반도체를 사용해 충격에 강하고 속도가 빠르며 발열과 소음이 적지만 가격이 높습니다. 일반 하드디스크의 대체 저장 장치로 쓰입니다
3보조기억장치는 주기억장치에 비해 속도가 느리고 저장 용량이 크며, 전원이 꺼져도 기억된 내용이 사라지지 않습니다
필기 · 단위

기억 용량 단위와 처리 속도 단위

1기억 용량 단위는 B › KB › MB › GB › TB › PB › EB 순이며 컴활 교재의 용량 환산 문제에서는 각 단계를 1,024배로 계산합니다(제품 표기에는 1,000배를 쓰기도 합니다)
2처리 속도 단위는 ms(밀리초) › μs(마이크로초) › ns(나노초) › ps(피코초) › fs(펨토초) › as(아토초) 순이고 지수는 10⁻³, 10⁻⁶, 10⁻⁹, 10⁻¹², 10⁻¹⁵, 10⁻¹⁸입니다. 뒤로 갈수록 더 짧은 시간이므로 더 빠릅니다
3문제에서 목록에 아토초가 없으면 그중 가장 뒤에 있는 단위(예: 피코초)가 가장 빠릅니다

필기 · 입출력 제어

채널과 인터럽트

1채널은 CPU로부터 입출력 장치의 제어권을 넘겨받아 입출력 작업을 관리합니다. CPU는 그동안 다른 작업을 처리할 수 있습니다
2작업이 끝나면 CPU에 인터럽트 신호를 보냅니다. 인터럽트는 소프트웨어나 하드웨어의 문제 · 상태를 알리는 신호입니다
3CPU와 주기억장치의 속도 차이를 해결하는 것은 채널이 아니라 캐시 메모리입니다
필기 · 포트

USB · HDMI · 블루투스

1USB(범용 직렬 버스)는 교재에서 비트를 한 줄로 차례로 보내는 직렬 방식(한 번에 1비트씩)으로 분류하고, 한 USB 버스에는 허브를 포함해 최대 127개의 장치를 연결할 수 있다고 설명합니다. 플러그 앤 플레이와 핫 플러그인을 지원합니다
2USB 단자는 버전을 색으로 구분하는 경우가 많습니다(대개 USB 2.0은 검정색 · 흰색, USB 3.0은 파란색). 장치 · 포트 · 케이블 중 낮은 규격의 속도 제한을 받으므로 같거나 높은 버전의 포트에 연결해야 제 속도를 낼 수 있습니다
3HDMI는 영상과 음향 신호를 하나의 케이블로 전송하고, 블루투스는 장치를 무선으로 연결합니다
필기 · BIOS

BIOS · CMOS · 펌웨어

1교재에서는 BIOS(기본 입출력 시스템)를 ROM에 저장된, 하드웨어와 소프트웨어의 중간 형태인 펌웨어로 설명합니다
2CMOS Setup에서는 날짜 · 시간, 전원 관리, 하드디스크 종류, PnP, 부팅 순서, 칩셋과 시스템 암호 등을 설정합니다. 여기서의 암호는 Windows 로그인 암호와 다릅니다
3펌웨어는 하드웨어를 바꾸지 않고 소프트웨어 업그레이드로 기능이나 성능을 개선할 수 있습니다

필기 · 업그레이드 · 파티션

파티션과 업그레이드 판단

1교재에서는 물리적 파티션을 장치 자체가 분리된 것, 논리적 파티션을 하나의 디스크를 여러 드라이브로 나눈 것으로 설명합니다. 호환되는 부팅 환경에서는 파티션마다 서로 다른 운영체제를 설치할 수 있습니다
2문제가 생겼다고 모든 파티션을 제거하는 것은 맞는 조치가 아닙니다
3같은 계열 · 같은 조건의 사양 비교에서는 클럭 · 용량은 클수록, 접근 시간은 작을수록 좋다고 판단합니다. 메모리가 부족할 때는 RAM 증설을 우선 고려합니다
실기 · 데이터 표

일부 셀만 지울 수 없습니다

1데이터 표는 입력값이 바뀔 때 결과가 어떻게 달라지는지 여러 조합을 미리 계산합니다. 예제에서는 결과 수식을 B5로 연결하고 국어 점수를 행 입력 셀, 수학 점수를 열 입력 셀로 지정했습니다
2데이터 표의 결과 영역은 배열 형태({=TABLE(…)})로 입력되므로 일부 셀만 수정 · 삭제할 수 없습니다. 전체 결과 영역을 선택하고 Delete로 지웁니다
3가상 분석의 세 가지: 데이터 표는 여러 입력값의 결과를 한꺼번에, 시나리오는 몇 가지 상황을 비교, 목표값 찾기는 입력 셀 하나를 바꿔 원하는 결과를 역산합니다
실기 · 시나리오

이름 정의와 시트 보호

1시나리오는 A · B 반품 수량을 줄여 매출이 늘어나는 «증가», 늘려 매출이 줄어드는 «감소»처럼 몇 가지 상황을 만들고 결과 셀(예: H14)을 지정해 요약으로 비교합니다
2변경 셀과 결과 셀에 이름을 정의하면 요약에 주소 대신 이름이 나옵니다. 이름 상자에 직접 입력하거나 수식 탭 › 선택 영역에서 만들기를 씁니다. 병합된 셀은 «선택 영역에서 만들기»가 잘되지 않으니 쓰지 않습니다
3시나리오의 «변경 금지»는 기본으로 선택되어 있으며, «숨기기»와 함께 시트 보호(검토 탭)를 해야 실제로 적용됩니다
실기 · 통합 · 목표값

통합은 레이블 선택에 주의

1통합은 떨어진 여러 범위에서 같은 항목을 찾아 합계 · 평균 · 최대 · 최소 등으로 계산합니다. 레이블로 통합할 때는 문제를 보고 첫 행 · 왼쪽 열 중 필요한 것을 정확히 선택합니다
2현대*(현대로 시작), *코리아(코리아로 끝남)처럼 와일드카드를 넣은 레이블을 결과 영역에 먼저 입력한 뒤 통합합니다. 이 예제에서는 «원본 데이터에 연결»을 선택하지 않았습니다
3목표값 찾기는 원하는 결과를 먼저 정하고 입력 셀 하나를 바꿔 구합니다. 예) 월 상환액을 20,000원으로 만들려면 상환 기간을 바꿔 구합니다
실기 · 매크로

개발 도구 탭 표시와 매크로 보안

1매크로는 반복 작업을 기록해 다시 실행하는 기능입니다. 기록할 수 있는 Excel 작업은 자동으로 VBA 코드로 저장됩니다
2개발 도구 탭이 보이지 않으면 파일 › 옵션 › 리본 사용자 지정에서 개발 도구를 체크합니다. 매크로 보안으로 실행 보안 수준을 정합니다
3매크로가 들어 있는 파일은 코드에 악성 내용이 들어갈 수 있으므로 출처가 불분명하면 함부로 열지 않습니다
4실기에서는 수식을 입력하는 매크로와 서식을 적용하는 매크로 두 가지를 다룹니다
실기 · 수식 매크로

기록은 작업 범위 밖에서 시작합니다

1실기에서 고정된 작업 셀을 선택하는 동작까지 기록하려면, 기록 전에 셀 포인터가 작업 셀에 있지 않도록 작업 범위 밖에서 시작합니다(이미 그 셀에 있으면 선택 동작이 기록되지 않음)
2수식 입력이나 채우기가 끝나면 즉시 기록을 중지합니다. 기록 중지 전에 단추나 도형을 그리면 그 동작까지 기록되어 실행할 때마다 단추가 새로 생깁니다
3검증은 결과를 지운 뒤 셀 포인터 위치와 관계없이 단추를 눌러 같은 결과가 나오는지 확인합니다
실기 · 매크로

단추와 단축키, 저장 위치

1양식 컨트롤 단추는 그리자마자 매크로 지정 창이 뜨고, 일반 도형은 우클릭 › 매크로 지정으로 따로 지정합니다. 둘의 방법을 혼동하지 않습니다. Alt를 누른 채 그리면 셀 경계에 맞춰집니다
2매크로 단축키는 문자 키를 지정해 Ctrl+문자 또는 Ctrl+Shift+문자로 씁니다. 매크로가 들어 있는 통합 문서가 열려 있고 매크로가 활성화된 동안에는 같은 엑셀 단축키보다 매크로가 우선합니다 (예: Ctrl+G를 지정하면 «이동» 대신 매크로 실행)
3저장 위치는 개인용 매크로 통합 문서 · 새 통합 문서 · 현재 통합 문서 중에서 고르며, 실기에서는 현재 통합 문서를 씁니다
실기 · 서식 매크로

코드를 고치지 말고 다시 기록합니다

1서식 매크로도 같은 이유로 작업 범위 밖에서 기록을 시작하고, 서식(예: 셀 채우기)을 지정한 뒤 기록을 중지합니다. 이어서 도형에 매크로를 지정하고 검증합니다
2기록이 잘못됐을 때 코드를 직접 고치기 어려우면 매크로를 삭제하고 처음부터 다시 기록합니다
3검증할 때는 서식을 지운 뒤 도형을 눌러 같은 서식이 다시 적용되는지 확인합니다
실기 · 차트

차트 영역과 그림 영역을 구분합니다

1차트 영역은 차트 바깥쪽 전체이고, 그림 영역은 데이터 계열이 실제로 그려지는 안쪽 영역입니다. 둘을 특히 혼동하지 않습니다
2일반적인 세로 막대형 · 꺾은선형 차트에서는 세로축이 값축, 가로축이 항목축입니다(차트 종류에 따라 달라질 수 있습니다). 차트 제목과 값축 제목을 구분하고, 눈금선에는 가로 · 세로 · 보조 눈금선이 있습니다
3추세선은 데이터 계열의 추세를 나타내는 선입니다. 데이터 계열은 막대 · 선 같은 실제 데이터 표현이고, 데이터 레이블은 계열 위에 표시하는 수치나 이름표입니다
4범례는 각 데이터 계열의 이름을 보여 주고, 데이터 테이블은 차트에 쓴 원본 데이터를 차트 아래에 표로 보여 줍니다

1✕ 16진수의 10~15를 숫자 10~15로 그대로 씀○ A~F로 바꿔 씁니다. 10=A, 15=F입니다.
2✕ 2진수를 왼쪽부터 3비트씩 묶음○ 오른쪽부터 묶습니다. 모자라는 자리는 0으로 채웁니다.
3✕ 캐시 메모리를 채널과 혼동함○ CPU와 주기억장치의 속도 차이는 캐시가 완화하고, 채널은 입출력을 관리합니다.
4✕ 주기억장치 전체를 비휘발성이라고 함○ ROM은 비휘발성, RAM은 휘발성입니다.
5✕ 용량 단위를 1,000배씩 올라간다고 계산함○ 교재의 환산 문제에서는 1,024배씩 올라갑니다.
6✕ USB를 한 번에 8비트씩 전송한다고 생각함○ 교재에서는 USB를 직렬(1비트씩)로 분류합니다. 병렬 방식이라고 외우지 않습니다.
7✕ 수식 매크로를 작업 셀에 서 있는 채로 기록 시작○ 작업 범위 밖에서 기록을 시작해야 작업 셀 선택 동작까지 기록됩니다.
8✕ 기록을 중지하기 전에 단추를 그림○ 기록을 중지한 뒤 단추를 그리고 매크로를 지정합니다.
9✕ 차트 영역과 그림 영역을 같은 곳으로 봄○ 차트 영역은 바깥쪽 전체, 그림 영역은 계열이 그려지는 안쪽입니다.
