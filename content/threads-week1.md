## 스레드 글 (Day 1~7)

### Day 1 — 진법 변환 (13차시, 수강생 제보 단골문제) ★첫 글
```
컴활 필기 단골인데 매번 틀리는 문제.

16진수 F는 10진수로 몇일까?

A=10, B=11, C=12, D=13, E=14, F=15.
"A부터 10"만 기억하면 끝.

실제 시험에서 2진수↔16진수 변환으로 나옵니다.
2진수 4자리 = 16진수 1자리. 1111 = F.

수강생이 시험장에서 보고 온 진짜 문제 유형입니다.
내일: 엑셀에서 앞자리 0이 사라지는 이유
```

### Day 2 — 앞자리 0 사라짐 (1차시)
```
"전화번호 입력했는데 010이 10으로 바뀌어요"

엑셀이 숫자로 인식해서 그렇습니다.
숫자는 앞자리 0을 버려요.

해결 3가지:
① 앞에 작은따옴표(') 붙이기 → 문자로 입력
② 표시형식을 '텍스트'로 바꾸고 입력
③ 사용자지정 형식 000-0000-0000

컴활 실기에서도, 회사에서도 매일 쓰는 지식.
```

### Day 3 — Alt+Enter vs Ctrl+Enter (1차시)
```
이름이 비슷해서 시험에서 제일 많이 헷갈리는 단축키.

Alt+Enter = 한 셀 안에서 줄바꿈
Ctrl+Enter = 여러 셀에 같은 값 한 번에 입력

암기법:
Alt = "아래로" 줄바꿈
Ctrl = "쫙" 뿌리기

필기에도 실기에도 나옵니다.
```

### Day 4 — #### 는 오류가 아니다 (1차시)
```
셀에 #### 뜨면 당황하는 분들.

오류 아닙니다. "칸이 좁아요"라는 뜻.
숫자나 날짜가 열 너비보다 길면 나타나요.

열 경계선 더블클릭 → 자동 맞춤 → 끝.

컴활 필기 보기에 "####은 오류값이다"가 함정으로 나옵니다. X입니다.
```

### Day 5 — 매크로 바로가기 키 (13차시, 강사 지적 반영 소재)
```
컴활 필기 함정문제.

매크로 바로가기 키를 Ctrl+C로 지정하면?
→ 복사가 아니라 "매크로"가 실행됩니다.

매크로 지정 키가 엑셀 기본 단축키보다 우선.

이거 실기가 아니라 "필기" 출제 포인트인 것도 함정.
```

### Day 6 — VLOOKUP 4번째 인수 (7·8차시)
```
VLOOKUP 쓸 때 마지막에 붙는 0 (또는 FALSE), 뭔지 모르고 쓰는 분들.

0 = 정확히 일치하는 것만 찾아라
1(TRUE/생략) = 비슷한 범위로 찾아라

실기에서 점수→등급 문제는 1,
사번→이름 문제는 0.

"구간이면 1, 콕 집으면 0"
```

### Day 7 — 보안 3요건 (16차시) + 첫 주 마무리
```
컴활 필기 최신 경향, 보안 파트.

정보보안 3요건:
기밀성 - 허락된 사람만 본다
무결성 - 아무도 못 고친다
가용성 - 필요할 때 쓸 수 있다

"기무가"로 외우세요.

---
일주일간 컴활 포인트 7개 올렸습니다.
전부 실강에서 수강생들이 실제로 틀린 것만 골랐어요.
팔로우하면 매일 아침 1개씩.
```
