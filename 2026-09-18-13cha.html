[필기] 진법 — 8진은 3자리, 16진은 4자리

2진수를 오른쪽부터 3자리씩 끊으면 8진수, 4자리씩 끊으면 16진수. 각 묶음은 1·2·4·8을 곱해 더합니다. 16진수 10~15는 A~F.

교재에 없는 내용 — 오늘 따로 나눠 준 자료

[실기] 시나리오는 «이름 정의»부터

지시문에 이름 정의가 있으면 그걸 먼저 하고 시나리오로 갑니다. 그래야 요약 보고서에 $E$4 대신 「A반품수량」처럼 이름이 찍힙니다.
이름 규칙 — 공백 불가, 첫 글자는 문자·밑줄(_)·역슬래시(\)만. 숫자로는 시작할 수 없습니다(1분기 ✗ → _1분기 ○). 셀 주소와 같은 이름(A1)도 안 됩니다. 필기에 나옵니다.

힘 빼도 되는 것 컴퓨터의 기원·발달 순서는 외우지 말라고 했고(예전엔 A등급, 지금은 C등급), 하드웨어/소프트웨어 구분도 요즘은 거의 안 나옵니다. SSD의 트림(TRIM)은 아직 출제가 많지 않습니다.
힘 줘야 하는 것 디지털 vs 아날로그 비교표(이 단원에서 가장 많이 나옴), 자료 단위 순서, 문자 코드 비트 수, 진법 변환. 분석 작업(실기)은 6가지 기능 중 2개가 나와 20점이고, 그중 피벗·시나리오가 10점짜리 긴 문제입니다.

[필기] 2장 복습 — 설정 창 · 접근성 · 프린터

시스템 디스플레이(해상도·방향·여러 디스플레이), 소리, 알림, 전원, 정보(하드웨어·운영 체제 사양, PC 이름 바꾸기). "웬만한 중요한 건 시스템에 있다."
개인 설정 배경·색(테마 색)·잠금 화면(Windows + L 화면)·화면 보호기·작업 표시줄 옵션. 주의 — 개인 설정 안에 보이는 「화면 시간 제한 설정」은 실제로는 시스템 → 전원 항목이라, 누르면 그쪽으로 넘어갑니다.
계정 관리자 계정은 프로그램 설치·제거와 중요한 설정 변경이 되고, 표준 사용자 계정은 이용은 되지만 그런 변경은 못 합니다.
접근성 몸이 불편한 분을 돕는 기능 — 글자·마우스 포인터 확대, 돋보기(Windows + +, 보기 3가지: 도킹·전체 화면·렌즈), 내레이터(화면 내용을 읽어 줌), 고정 키·토글 키. 「내레이터는 시스템의 소리 설정에 있다」는 틀린 보기입니다.
프린터·스풀 (어제 내용) 로컬은 포트, 네트워크는 공유 이름·컴퓨터 이름 또는 IP. 기본 프린터는 1대. 스풀은 인쇄 내용을 보조기억장치에 잠깐 맡겨 CPU 효율을 높이는 기능이고, 인쇄 속도를 빠르게 하는 기능은 아닙니다.

💽 [필기] 드라이브 조각 모음 vs 디스크 정리

단편화란 하드디스크(원판)에 파일을 쓰고 지우다 보면 한 파일이 여기저기 조각나 흩어집니다. 헤드가 이리저리 오가느라 읽는 속도가 느려져요.
드라이브 조각 모음 및 최적화 흩어진 조각을 연속된 공간으로 모아 접근 속도와 안정성을 높입니다. 있는 물건을 버리지 않고 집 안에서 정리만 한 것이라 용량은 늘지 않습니다.
교재 포인트 분석 결과 조각화 비율이 10%를 넘으면 최적화를 권장 · 일정을 정해 예약 실행 가능 · USB 같은 이동식 저장 장치도 가능 · CD-ROM·네트워크 드라이브, 윈도우가 지원하지 않는 파일 시스템으로 포맷된 드라이브는 불가.
SSD는? 반도체라 원판이 돌지 않으니 조각 모음이 필요 없고, 대신 트림(TRIM)으로 지운 공간을 다시 쓸 수 있게 비워 둡니다. (시험 출제는 아직 많지 않음)
디스크 정리 임시 인터넷 파일·휴지통·다운로드한 프로그램 파일·임시 파일·미리 보기(썸네일) 같은 필요 없는 파일을 지워 사용 가능한 용량을 늘립니다.
작업 관리자 Ctrl + Shift + Esc. 실행 중인 프로세스와 CPU·메모리·네트워크 사용량을 보고, 응답 없는 앱을 강제 종료합니다. 「계정을 만든다」 같은 보기는 작업 관리자 기능이 아닙니다.

⌨️ [필기] 명령 프롬프트 · ipconfig · ping · 고정 IP

명령 프롬프트 열기 Windows + R(실행) → cmd → Enter. cmd는 command의 약자입니다. 검은 창에 명령어를 글자로 쳐서 작업합니다(예: dir는 폴더 안 목록 보기).
ipconfig 내 컴퓨터에 설정된 IP 주소(IPv4 주소 등)를 보여 줍니다. 네트워크 속성을 찾아 들어가는 것보다 빠릅니다.
ping 주소 상대에게 작은 데이터 묶음(패킷)을 보내 응답이 오는지, 손실이 있는지 봅니다. 네트워크가 연결되어 있는지 확인하는 명령이에요. 브라우저로 확인이 안 될 때(예: DNS 문제)도 쓸 수 있습니다.
고정 IP로 직접 설정할 때 넣는 4가지 ① IP 주소 ② 서브넷 마스크(네트워크 주소와 호스트 주소를 구분) ③ 기본 게이트웨이(다른 네트워크로 나가는 출입구 역할) ④ DNS 서버 주소. WINS·어댑터 같은 보기는 반드시 넣는 항목이 아닙니다.
DNS가 하는 일 사람이 기억하기 쉬운 도메인 이름(www.naver.com)을 컴퓨터가 쓰는 IP 주소로 바꿔 줍니다. ping은 되는데 사이트가 안 열리면 DNS 주소를 의심해 볼 수 있어요.

🖥 [필기] 3장 컴퓨터 시스템 개요 — 분류와 디지털/아날로그

자료와 정보 가공하지 않은 사실(로우 데이터)이 자료, 의사 결정에 쓰도록 가공한 것이 정보입니다. 좋은 자료를 넣어야 좋은 결과가 나온다는 뜻의 GIGO(Garbage In, Garbage Out)도 최근까지 출제되고 있어요.
세대 1세대 진공관 → 2세대 트랜지스터 → 3세대 집적 회로(IC)부터 반도체 → 4세대 고밀도 → 5세대 초고밀도. "3세대부터 반도체" 정도만 기억하면 됩니다. 기원·발달 순서는 외우지 마세요.
처리 능력에 따른 분류 슈퍼컴퓨터(일기 예보·자율 주행처럼 대량 계산) > 메인프레임(은행·병원·정부의 대형 서버) > 미니컴퓨터(학교·연구소) > 마이크로컴퓨터(우리가 쓰는 것). 마이크로컴퓨터 안에는 워크스테이션·데스크톱·휴대용(노트북·팜톱)이 있고, 몸에 착용하는 것은 웨어러블입니다.
취급 데이터에 따른 분류 — 이 단원에서 가장 많이 나옵니다 디지털은 켜짐/꺼짐(0과 1)처럼 끊어진 값, 아날로그는 조명의 밝기 조절처럼 연속된 값(곡선)을 다룹니다. 외우기보다 이 그림을 머리에 넣으면 표가 저절로 채워집니다.

🔢 [필기] 자료 단위 · 문자 코드 · 에러 검출 — 이제부터 «외우는» 구간

비트(bit) 정보 표현의 최소 단위. 0 또는 1, 두 가지 상태. 비트 n개로는 2ⁿ가지를 표현합니다.
니블(nibble) 4비트 → 2⁴ = 16가지(0~15). 그래서 16진수 한 자리를 표현하기에 딱 맞습니다.
바이트(byte) 8비트 → 2⁸ = 256가지(0~255). 문자를 표현하는 최소 단위입니다. 영문·숫자는 1바이트(반각), 한글·한자는 2바이트(전각). 「0~255」라는 숫자가 보이면 1바이트를 떠올리세요.
워드(word) CPU가 한 번에 처리하는 명령의 단위. 하프 워드 2바이트 · 풀 워드 4바이트(32비트) · 더블 워드 8바이트(64비트). 프로그램 설치 때 보는 «32비트 / 64비트»가 이 이야기입니다.
필드 → 레코드 → 파일 → 데이터베이스 필드(항목 하나, 파일 구성의 최소 단위)가 모여 레코드(한 줄), 레코드가 모여 파일, 파일들이 모여 데이터베이스. 엑셀에서 쓰던 필드·레코드 그대로입니다.
문자 표현 코드 — 6 · 7 · 8 · 16 BCD 6비트(존 2 + 디지트 4, 64가지, 영문 소문자 표현 불가) · ASCII 7비트(존 3 + 디지트 4, 128가지, 통신·개인용 컴퓨터, 패리티 비트를 붙인 확장 ASCII는 8비트) · EBCDIC 8비트(존 4 + 디지트 4, 256가지, 대형 컴퓨터) · 유니코드 16비트(2바이트, 65,536자, 국제 표준, 한글 완성형·조합형 모두 지원).
에러 검출 코드 패리티 비트는 오류가 있는지 검출하는 비트, 해밍 코드는 2비트 오류 검출 · 1비트 오류 교정까지 합니다. 「다음 중 문자 표현 코드가 아닌 것」에 해밍 코드가 끼어 나옵니다.

🔢 [필기] 진법 변환 — 교재에 없지만 시험에 나옵니다

표현 범위 2진수 0~1 · 8진수 0~7 · 10진수 0~9 · 16진수 0~15. 16진수는 10 이상을 한 자리로 쓰려고 10=A, 11=B, 12=C, 13=D, 14=E, 15=F로 씁니다.
자리의 무게 10진수 12는 1×10 + 2×1. 2진수도 같은 규칙으로 오른쪽부터 1 · 2 · 4 · 8의 무게를 가집니다. 2진수 1010 = 8 + 2 = 10.
2진수 → 8진수 8 = 2³이라 오른쪽부터 3자리씩 끊고, 각 묶음을 1·2·4로 계산합니다. 모자란 앞자리는 0으로 채웁니다.
2진수 → 16진수 16 = 2⁴라 오른쪽부터 4자리씩 끊고, 각 묶음을 1·2·4·8로 계산한 뒤 10 이상은 A~F로 바꿉니다. (니블 = 4비트 = 16진 한 자리와 같은 이야기)
10진수 → 2진수 2로 계속 나누며 나머지를 적고, 아래에서 위로 읽습니다(10 → 1010). 강사는 "이건 아직 잘 안 나온다"고 했고, 시험에 나온 건 2진 → 8진·16진과 16진 문자(A~F) ↔ 10진 짝 맞추기입니다.

📊 [실기] 피벗 · 데이터 표 복습 — 어제 가장 많이 틀린 것부터

어제 퀴즈에서 두 문항이 65%였습니다. 하나가 「데이터 표의 행 입력 셀에 무엇을 넣나」였어요. 오늘 3교시에 다시 짚은 내용이라 그림으로 한 번 더 봅니다.
행 입력 셀 = 표 «맨 윗줄(가로)»에 늘어놓은 값이, 원래 수식에서 어느 셀에 들어가 있던 값인지 그 셀 주소를 넣습니다. 열 입력 셀은 맨 왼쪽 열(세로)에 늘어놓은 값의 원래 셀. 표 안의 숫자(80·90·100)를 찍는 게 아닙니다. 원래 셀이 절대참조로 들어가도 신경 쓰지 않아도 됩니다.
범위는 «수식이 있는 칸부터» 왼쪽 위 칸에 =원래 결과 셀을 먼저 넣고, 그 칸을 포함해 표 전체를 선택한 뒤 데이터 → 예측 → 가상 분석 → 데이터 표. 수식 칸을 빼고 선택하면 값이 나오지 않습니다.
피벗 — 원본이 늘어났다면 레코드가 추가됐을 때 피벗을 지우고 다시 만들 필요 없이 피벗 테이블 분석 → 데이터 원본 변경으로 범위만 늘리면 됩니다. 값만 바뀌었다면 새로 고침.
피벗 — 계산 필드 값 영역에 원본에 없는 계산 항목을 직접 만들어 넣을 수 있습니다. 실기에는 안 나오지만 필기에 「만들 수 있다」 문구로 나옵니다. 디자인 탭의 보고서 레이아웃·피벗 스타일(밝게·보통·어둡게)은 실기에 나옵니다.
어제 65%였던 또 한 문항은 피벗 총합계 판별이었습니다. 다시 한 줄로 — 행 총합계는 한 행을 가로로 더한 값이라 표 오른쪽 끝 세로줄에, 열 총합계는 한 열을 세로로 더한 값이라 맨 아래 가로줄에 보입니다.

🏷 [실기] 이름 정의 → 시나리오 (10점)

왜 이름부터 시나리오 요약 보고서에는 변경 셀·결과 셀이 표시되는데, 이름을 정의하지 않으면 $E$4처럼 셀 주소가 찍혀 무슨 뜻인지 알 수 없습니다. 이름을 정의해 두면 「A반품수량」처럼 나옵니다. 지시문에 이름 정의가 있으면 반드시 먼저 하세요.
이름 정의하는 법 셀을 선택하고 수식 입력줄 왼쪽의 이름 상자에 이름을 쓴 뒤 Enter. 옆에 이미 제목 글자가 있다면 범위를 잡고 수식 탭 → 선택 영역에서 만들기(첫 행 / 왼쪽 열)로 한 번에 만들 수 있습니다.
잘못 만들었다면 수식 탭 → 이름 관리자에서 편집·삭제합니다. 이걸 못 찾으면 10점이 날아가니 메뉴 위치를 꼭 기억하세요.
이름 규칙(필기에 나옴) 공백 불가 · 숫자는 넣을 수 있지만 첫 글자로는 불가 · A4·E5처럼 셀 주소와 같은 이름 불가 · 참조 대상은 기본적으로 절대참조로 들어갑니다.
시나리오 순서 데이터 → 예측 → 가상 분석 → 시나리오 관리자 → 추가 → 시나리오 이름·변경 셀 지정 → 값 입력(10%는 10%로도, 0.1로도 됨) → 다시 추가로 두 번째 시나리오 → 요약 → 결과 셀을 지시문대로 바꾸기 → 확인.
마지막 확인 두 가지 ① 결과 셀이 «영업 이익»인지 «영업 이익률»인지처럼 지시문과 같은 셀인가 ② 생성된 시나리오 요약 시트의 위치가 지시대로인가 — 다르면 시트 탭을 끌어 옮깁니다. 이걸 빼먹으면 통째로 감점입니다.

🎯 [실기] 목표값 찾기 — «쌍» 두 개를 맞추세요

가상 분석 3형제 정리 데이터 표는 여러 경우를 표로 한꺼번에 · 시나리오는 2~3가지 상황을 직접 넣어 비교 · 목표값 찾기는 답 하나를 거꾸로 찾아옵니다.
예 100만 원을 6%로 빌려 2년이면 월 44,000원. 「한 달에 2만 원만 내려면 몇 년 동안 갚아야 하나?」 — 결과(월 상환액)를 먼저 정해 두고 원인(상환 기간)을 찾는 것입니다.
세 칸 데이터 → 예측 → 가상 분석 → 목표값 찾기. 수식 셀(결과가 계산되는 셀, 수식이 들어 있어야 함) · 찾는 값(목표 숫자) · 값을 바꿀 셀(바꿔 볼 원인). 수식 셀 ↔ 찾는 값이 한 쌍, 값을 바꿀 셀이 그 답을 담을 칸입니다.
단위 주의 표에 «단위: 천 원»처럼 뒤 0 세 개가 생략돼 있으면, 5천만 원을 목표로 할 때 50000을 넣습니다.
잘못했으면 Ctrl + Z로 바로 되돌리고 다시 하면 됩니다.

🔁 [실기] 통합 — «첫 행 · 왼쪽 열»을 체크합니다

무엇을 하나 서울 대리점·부산 대리점처럼 따로 떨어진 표를 항목별로 모아 합계·평균·최대 등을 냅니다. (실무에서는 처음부터 한 표에 «지역» 필드를 두는 편이 낫다고 강사가 덧붙였습니다 — 그래야 피벗도 됩니다.)
1 · 결과 자리 선택 결과를 넣을 표의 필드명(첫 행)과 왼쪽 열까지 포함해 선택하고 시작합니다. 항목 순서가 원본과 뒤죽박죽이어도 이렇게 하면 다 맞춰집니다.
2 · 데이터 → 데이터 도구 → 통합 사용할 함수(합계·평균·최대 …)를 고릅니다.
3 · 참조 추가 원본 범위도 같은 모양으로 — 필드명과 왼쪽 열을 포함해 잡고 추가. 두 번째 원본도 똑같이 추가합니다. 결과 표에 없는 열(예: «구분»)이 원본 중간에 끼어 있으면 그 열은 빼고 필요한 열만 잡습니다.
4 · 사용할 레이블 — 첫 행 · 왼쪽 열 모두 체크 이걸 빼면 엑셀은 항목 이름을 보지 않고 같은 위치의 칸끼리 계산해서, 순서가 다른 표가 엉뚱하게 합쳐집니다.
와일드카드 「현대로 시작하는 매장」은 결과 표 왼쪽 열에 현대*, 「코리아로 끝나는 매장」은 *코리아를 먼저 적어 두고 통합합니다. 원본 데이터에 연결하기는 같은 시트 안에서는 쓸 수 없습니다.

⚙️ [실기] 매크로 — 기록 순서와 필기에 나오는 규칙

준비 ① 저장 형식 매크로를 함께 저장하려면 Excel 매크로 사용 통합 문서(.xlsm)로 저장합니다. (시험에 나오지는 않지만 실제로 쓰려면 필요) 인터넷에서 받은 파일은 속성(Alt + Enter)의 차단 해제가 필요할 수 있습니다.
준비 ② 개발 도구 탭 기본으로는 없습니다. 파일 → 옵션 → 리본 사용자 지정에서 «개발 도구»를 체크해 표시합니다.
준비 ③ 매크로 보안(필기에 나옴) 개발 도구 → 매크로 보안. 기본값은 «알림이 포함된 VBA 매크로 사용 안 함». 「VBA 매크로 사용」 옆에는 (권장 안 함, 위험한 코드가 시행될 수 있음)이라고 적혀 있습니다 — 매크로에는 악성 코드를 심을 수 있어서입니다.
기록 순서 ① 셀 포인터를 작업과 관계없는 빈 셀에 둔다 → ② 매크로 기록(이름·바로 가기 키·저장 위치) → ③ 작업할 셀을 클릭하는 것부터 시작해 수식·서식을 입력 → ④ 기록 중지(빼먹는 사람이 아주 많음) → ⑤ 단추·도형에 매크로 지정 → ⑥ 검증: 결과를 지우고 단추를 눌러 다시 나오는지 확인.
왜 셀 포인터를 밖에 두나 시험은 «셀 포인터 위치에 상관없이» 실행돼야 합니다. 처음부터 결과 칸에 서 있으면 «그 칸을 선택하는 동작»이 기록되지 않아, 나중에 다른 곳에 서서 실행하면 엉뚱한 칸에 수식이 들어갑니다.
바로 가기 키(필기 단골) 기본은 Ctrl + 문자, 대문자를 입력하면 Ctrl + Shift + 문자가 됩니다. Alt 조합은 안 됩니다. Ctrl + G(원래 «이동»)처럼 엑셀 기본 단축키와 겹치면, 그 통합 문서가 열려 있는 동안은 매크로가 우선합니다.
저장 위치 3가지 현재 통합 문서(실기는 이것) · 새 통합 문서 · 개인용 매크로 통합 문서(엑셀을 열 때마다 쓸 수 있음).
단추와 도형 개발 도구 → 삽입 → 양식 컨트롤의 단추를 그리면 매크로 지정 창이 바로 뜹니다. 도형은 바로 뜨지 않으니 오른쪽 버튼 → 매크로 지정. 「셀에 꼭 맞게」는 Alt를 누른 채 그리거나 크기를 조절합니다. 단추 글자는 지시대로 바꿉니다.
코드 보기 매크로 → 편집을 누르면 기록된 동작이 VBA(Visual Basic for Applications) 코드로 보입니다. 필기에 용어가 나옵니다.
