★조건부 서식은 순서가 반이다

①범위 선택 ②새 규칙 ③수식을 사용하여 서식 지정 ④조건식 ⑤서식. 강사가 "수업해 보면 ①에서 제일 많이 틀린다"고 했습니다. 머리글(필드명)을 넣지 말고 데이터(레코드)만 선택하세요.

실기에 5점짜리 단독 문항으로 나옵니다

★행 전체를 칠하려면 열 절대참조

조건식 안의 참조는 $F4처럼 열만 $로 묶습니다. 어느 행을 검사하든 보는 열은 합계 열 하나여야 하기 때문이에요. 헷갈리면 "행 전체 → 열 절대"로 외웁니다.

F4 키를 세 번 눌러 $F4를 만듭니다

대화상자 자체가 IF문이다

안에 넣는 건 질문(조건식)뿐입니다. 결과가 TRUE면 서식이 칠해지고 FALSE면 안 칠해집니다. 참일 때 값·거짓일 때 값을 적는 자리는 없습니다.

IF의 첫 칸만 떼어 넣는다고 생각하세요

조건만 넣고 서식을 빼먹는 실수

규칙을 만들고 아래쪽 「서식」 단추를 눌러야 색이 지정됩니다. 그리고 "연한 파랑 채우기"는 글꼴 탭이 아니라 채우기 탭이에요.

실제 시험에서도 글자색으로 잘못 하는 분이 많습니다

"크거나 같다"는 기타 규칙에 있다

셀 강조 규칙에는 보다 큼·보다 작음·같음은 있지만 크거나 같음 항목이 바로 없습니다. 190점 이상을 지정하려면 기타 규칙으로 들어가 「셀 값 >= 190」으로 적습니다.

상위/하위 규칙으로 상위 1개만 강조도 가능

규칙 수정은 「규칙 관리」에서

규칙이 안 보이면 「서식 규칙 표시」를 현재 선택 영역 → 현재 워크시트로 바꿉니다. 결과가 이상하면 ①적용 대상 ②규칙 편집 순으로 확인하세요. 규칙을 지우지 말고 적용 대상만 다시 잡습니다.

서식이 부딪히면 목록 위쪽 규칙이 우선입니다

AND는 모두, OR는 하나만

"엑셀과 워드가 모두 80 이상" → AND. "엑셀이 90 이상이거나 워드가 90 이상" → OR. 조건은 하나씩 따로 적는 연습을 합니다.

AVERAGE 범위만은 행·열 모두 고정($F$4:$F$13)

시작 전에 — 어제 가장 많이 틀린 것 되짚기

어제 퀴즈에서 두 문항이 기준선 아래였습니다. MID 결과를 IF로 비교하는 문항이 62%, MATCH의 번호를 묻는 문항이 69%였어요.
오늘 바로 이어집니다. 조건부 서식에서 =LEFT($C4,1)="C"를 쓰는데, 여기 따옴표가 빠지면 어제 62%짜리 실수가 그대로 재현됩니다.
MATCH는 범위 안에서 셉니다. 범위가 A3부터면 A3이 1번이에요. 시트의 행 번호가 아닙니다.

🎨 조건부 서식 — 다섯 단계를 순서대로

①범위 선택 조건부 서식은 셀 포인터의 위치부터입니다. 문제에 "요 범위에 하세요"가 적혀 있으니 머리글은 빼고 데이터만 선택합니다. 실무에서는 열 전체를 잡아도 되지만 시험은 지정 범위가 정해져 있어요.
②새 규칙 이미 만들어진 데이터 막대·색조는 쓰지 않습니다. 홈 → 조건부 서식 → 새 규칙으로 들어갑니다.
③수식을 사용 「수식을 사용하여 서식을 지정할 셀 결정」을 고릅니다.
④조건식 여기에 넣는 것은 질문 한 줄입니다. "너 190점 넘니?" → =$F4>=190. 결과는 TRUE 아니면 FALSE고, TRUE인 행에만 서식이 들어갑니다.
⑤서식 아래 「서식」 단추를 눌러 색을 지정합니다. 여기를 빼먹는 실수가 잦습니다.

🔒 행 전체 강조 = 열 절대참조 $F4 (오늘 최고 강조)

왜 절대참조는 안 되나 =$F$4>=190이면 모든 셀이 F4 한 칸만 쳐다봅니다. F4가 190을 넘으면 전체가 다 칠해지고, 안 넘으면 한 칸도 안 칠해집니다.
왜 상대참조도 안 되나 =F4>=190이면 오른쪽 칸을 검사할 때 보는 열이 G·H로 따라 밀려갑니다. 학번을 보고 색을 정하게 되는 셈이에요.
그래서 열만 고정 =$F4>=190. 열은 합계 열에 붙잡아 두고, 행 번호는 내려가며 바뀌게 둡니다. F4 키를 세 번 누르면 이 모양이 됩니다.
외우는 문장 "행 전체를 칠하라 → 열 절대". 강사가 "헷갈리면 그냥 외우라"고 한 부분입니다. (드물게 열 전체를 칠하는 문제면 반대로 행 절대입니다.)

🧮 조건식에 함수 넣기 — LEFT · AND · OR · AVERAGE

LEFT "C로 시작하는 반의 행 전체" → =LEFT($C4,1)="C". 반 이름을 통째로 비교하지 않고 왼쪽에서 한 글자를 떼어 비교합니다.
AND "엑셀과 워드가 모두 80 이상" → =AND($D4>=80, $E4>=80). 조건을 하나씩 따로 적습니다.
OR "엑셀이 90 이상이거나 워드가 90 이상" → =OR($D4>=90, $E4>=90).
AVERAGE "합계가 평균보다 큰 행" → =$F4>AVERAGE($F$4:$F$13). 앞은 열 절대, 평균 범위는 행·열 모두 고정합니다. 조건부 서식도 채우기 핸들처럼 아래로 내려가며 검사하므로, 고정하지 않으면 평균 범위가 같이 밀려 내려갑니다.

🛠 대화상자가 불편할 때 · 규칙을 고칠 때

대화상자 안에서는 함수 자동완성이 안 됩니다. 방향키도 셀 이동으로 먹혀서 커서를 옮기기 어려워요. 스펠링을 모르면 쓸 수가 없습니다.
해결 빈 셀에 수식을 먼저 적어 TRUE/FALSE가 제대로 나오는지 확인하고, Ctrl+X로 잘라내어 규칙 수식 칸에 붙여넣습니다. (붙여넣기가 아니라 잘라내기여야 그 셀이 원래대로 비워집니다.)
규칙이 겹칠 때 같은 셀에 규칙이 두 개 걸려도 서식이 서로 겹치지 않으면 둘 다 적용됩니다. 채우기 색처럼 같은 항목이 부딪히면 규칙 관리 목록에서 위에 있는 규칙이 이깁니다. 새로 만든 규칙이 목록 맨 위로 올라가므로, 보통은 나중에 만든 규칙의 색이 보입니다. 순서는 규칙 관리에서 위·아래 화살표로 바꿀 수 있어요.
규칙이 안 보일 때 조건부 서식 → 규칙 관리 → 「서식 규칙 표시」를 현재 워크시트로 바꿉니다.
결과가 이상할 때 ①적용 대상이 맞는지 먼저 봅니다. 잘못됐으면 규칙을 지우지 말고 적용 대상 칸만 비우고 범위를 다시 잡으세요. ②그다음 규칙 편집으로 수식을 확인합니다.
덤 방향키가 셀 이동을 안 하고 화면만 움직이면 Scroll Lock이 켜진 것입니다. 한 번 눌러 끄면 됩니다.

⏱ 1교시 되짚기 — 시간은 연산 먼저, 날짜는 따로 추출

시간 이용 시간을 구할 땐 셀을 먼저 빼고 그 결과를 감쌉니다. =HOUR(출차-입차), =MINUTE(출차-입차).
왜 시·분을 각각 빼면 10:30~11:20(50분)이 "11-10=1시간"으로 잘못 계산됩니다.
날짜 나이·근속은 반대입니다. 따로 뽑아서 뺍니다. =YEAR(TODAY())-YEAR(생일).
표시 형식 결과가 시간 모양으로 이상하게 보이면 표시 형식을 일반으로 바꾸고 F2 → Enter로 다시 확정합니다.

🖥 필기 컴퓨터 일반 — Windows 10 (첫날)

사용자 인터페이스 GUI는 그림·아이콘·마우스, CLI는 명령어를 직접 입력하는 방식입니다.
선점형 멀티태스킹 운영체제가 모든 작업을 관리합니다. 문제가 생긴 프로그램을 OS가 강제로 종료할 수 있어요.
PnP(플러그 앤 플레이) USB 같은 장치를 연결하면 자동으로 인식해 바로 쓰게 해 줍니다.
OLE(개체 연결 및 삽입) 엑셀에서 만든 차트를 파워포인트·워드에 넣는 것처럼 다른 앱의 개체를 연결·삽입합니다.
파일 시스템 FAT / NTFS / exFAT. NTFS는 FAT보다 성능·보안이 뛰어나고 윈도우에서 쓰는 방식입니다(맥에서는 그대로 쓰기가 어렵습니다). exFAT는 FAT의 용량 한계를 개선해 여러 환경에서 호환성이 좋아 USB 같은 이동식 저장장치에 적합합니다.
바로가기 아이콘 확장자는 .lnk, 좌측 하단에 화살표가 붙습니다. 원본의 위치 정보(경로)만 가지고 있어 지워도 원본은 그대로고, 여러 개 만들 수 있습니다(이름은 달라야 함).
속성 창 Alt+Enter로 열면 위치·이름·크기·수정한 날짜 등이 나옵니다.
작업 표시줄 위치를 위·아래·좌·우로 옮길 수 있고, 자동 숨기기·잠금·단추 하나로 표시가 됩니다. 크기는 화면 절반까지 늘어납니다. 모니터가 두 대면 양쪽 모두 표시할 수 있어요.
작업 표시줄에서 안 되는 것 아이콘 형식·정렬(바탕 화면·파일 탐색기에서 합니다), 개인 설정, 전원 관리(설정 창에서). 바로가기 메뉴의 "정렬"은 아이콘이 아니라 창을 정렬합니다.
점프 목록 작업 표시줄 아이콘에서 마우스 오른쪽 클릭하면 최근 문서가 나옵니다. 고정은 압정으로, 해제도 압정을 다시 눌러서 합니다 — Delete 키가 아닙니다(기출 오답 단골).
