과정 개요

대표 과정은 두 가지입니다. 무엇을 해결하고 싶은가에 따라 고르시면 됩니다.

과정 AAI가 제대로 일하게 만드는 업무 설계
질문만 잘하는 사람에서, AI와 함께 일하는 사람으로

프롬프트 기법을 가르치는 과정이 아닙니다. 수강생 본인의 업무 하나를 골라 AI가 처리할 수 있는 단위로 분해하고, 반복 사용 가능한 구조로 설계하게 만듭니다. 도구에 종속되지 않아 사내 AI 도구가 바뀌어도 그대로 쓸 수 있습니다.

  • 이런 조직에 맞습니다 — AI를 도입했는데 쓰는 사람만 쓰고 성과가 안 보이는 경우
  • 이런 수강생에 맞습니다 — 써봤지만 결과가 들쭉날쭉한 실무자, 문서·기획 업무 중심
최종 산출물 — 업무 설계도 1장 · 구조화 프롬프트 1개 (4시간 과정은 다단계 업무 흐름 1건 추가)
과정 BAI 3사 완전 비교 활용법
ChatGPT · Claude · Gemini, 업무별로 골라 쓰고 이어 쓰는 법

세 서비스를 같은 자료·같은 질문으로 동시에 돌려보고 업무별로 어느 도구를 쓸지 스스로 결정하게 만듭니다. "어느 게 제일 좋냐"가 아니라 "이 업무엔 뭐가 맞냐"로 질문을 바꾸는 것이 목표입니다.

  • 이런 조직에 맞습니다 — 도구 선정을 앞두고 있거나, 직원마다 다른 도구를 쓰는 경우
  • 이런 수강생에 맞습니다 — 하나만 써봤거나, 유료 결제를 고민 중인 실무자
최종 산출물 — 내 AI 도구 배치도 1장 (4시간 과정은 조합 워크플로우 1건 추가)
📌 어느 과정을 먼저 할까
  • AI를 이미 쓰고 있는데 성과가 안 보이는 조직 → 과정 A (업무 설계)
  • AI를 이제 도입하려는데 도구 선정이 안 된 조직 → 과정 B (3사 비교)
  • 연간 교육으로 둘 다 할 경우 → B를 먼저, A를 나중에. 도구를 정한 뒤 설계를 배우는 순서가 자연스럽습니다

    시간별 구성 비교

    과정 A · AI가 제대로 일하게 만드는 업무 설계

    시간다루는 범위실습산출물
    90분1·2단계 맛보기 + 구조화 프롬프트 개념요청 고쳐 쓰기프롬프트 1개
    2시간1~4단계 실습 + 설계도 작성2종설계도 + 프롬프트
    3시간1~5단계 전체 + 문서 기반 AI 개념4종설계도 + 프롬프트
    4시간위 전체 + 문서 기반 AI 실습 + 다단계 흐름 설계5종설계도 + 프롬프트 + 업무 흐름
    6시간위 전체 + 팀 표준 프롬프트 카드 + 조직 적용 계획7종위 전체 + 팀 카드 3종
    💡 시간 선택 기준 2시간은 "AI를 왜 써야 하는지"를 설득해야 하는 자리에 맞습니다. 4시간은 수강생이 이미 AI를 쓰고 있고 제대로 쓰고 싶어하는 경우에 효과가 가장 큽니다. 3시간은 둘 사이 균형점이고, 6시간은 조직 단위 도입을 전제로 합니다.

    과정 B · AI 3사 완전 비교 활용법

    시간다루는 범위실습산출물
    2시간3사 지형도 + 핵심 활용법 12가지비교 2종도구 배치도
    3시간위 + 활용법 36가지 + 조합 5종 소개비교 3종도구 배치도
    4시간위 전체 + 조합 워크플로우 직접 설계 + 요금 판단비교 3종 + 조합 설계배치도 + 조합 1건
    ⚠ 과정 B 운영 시 반드시 확인할 것
    • 교육장에서 3사 접속이 모두 가능한지 사전 확인 (기업 사내망에서 막히는 경우가 있습니다)
    • 수강생 계정 종류에 따라 Gemini 화면이 다르게 보입니다 (Gems → Skills 전환 진행 중)
    • 요금·모델명은 수개월 단위로 바뀌므로 강의 1주 전 재확인이 필요합니다

    과정별 강사 자료 구성

    각 과정마다 세 가지 파일이 한 세트입니다. 파일명 규칙은 course-{과정}-{종류}입니다.

    파일내용용도
    -script.html전체 진행표, 블록별 강의 대본(말할 문장 그대로), 진행 지시, 주의·팁, 사전 준비, 시간이 밀릴 때 자르는 순서, 돌발 상황 대응, 예상 질문 답변, 강의 성패 판정 기준인쇄해서 손에
    -deck.html발표용 슬라이드. 브라우저에서 전체화면 발표. N키로 슬라이드별 강사 노트, 좌우 키·스와이프로 이동, Ctrl+P로 전체 PDF 저장현장 발표
    -deck.pptx같은 슬라이드의 파워포인트 파일. 고객사 템플릿에 붙이거나 직접 편집할 때편집·제출

    대본 읽는 법

    • 파란 박스 (이렇게 말합니다) — 실제로 말할 문장입니다. 그대로 읽어도 되고 흐름만 참고하셔도 됩니다
    • 초록 박스 (진행) — 말이 아니라 동작입니다. 슬라이드 넘기기, 타이머 걸기, 순회하기 등
    • 노란 박스 (팁) — 효과를 높이는 운영 요령
    • 빨간 박스 (주의) — 놓치면 강의가 어긋나는 지점
    • 굵은 글씨 — 강조해서 말할 부분입니다

    제안과 운영 체크리스트

    문의를 받았을 때 확인할 것

    확인 항목왜 필요한가
    교육 시간2시간이면 설득 중심, 4시간이면 설계 중심으로 구성이 완전히 달라집니다
    인원권장 20~30명. 40명을 넘으면 실습 순회가 불가능해 산출물 완성도가 떨어집니다
    AI 사용 경험거의 없는 조직이면 실습 시간을 늘리고 설명을 줄여야 합니다
    직군 구성교육 담당자·관리자 비중이 높으면 조직 적용 블록을 늘립니다
    사내망 접속 가능 여부가장 자주 발생하는 사고입니다. 반드시 사전에 담당자에게 확인하십시오
    노트북 지참 여부지참이 어려우면 실습을 조별 1대로 재설계해야 합니다
    AI 사용 지침 유무지침이 있으면 보안 안내를 그 지침에 맞춰 바꿔야 합니다

    강의 1주 전 재확인

    • 3사 공식 요금 페이지에서 금액·플랜명 확인 (과정 B는 필수)
    • 각 서비스에 로그인해 기능 메뉴 위치가 바뀌지 않았는지 확인 — 화면 시연에 직결됩니다
    • Gemini 계정 종류별로 Gems/Skills 중 어느 화면이 보이는지 확인
    • 실습 프롬프트를 직접 돌려보고 결과를 캡처해 백업 — 네트워크 장애·서비스 점검 대비
    • 실습용 공통 자료(회의 녹취록, 문서 샘플)의 원문을 강사가 숙지 — 즉석 대조에 필요합니다

    구분항목
    인쇄물강사 대본, 실습 워크시트, 최종 산출물 양식 (인원 + 5부)
    장비노트북, 타이머, 보조 모니터(3사 비교 과정은 권장)

    백업모든 시연 결과의 캡처 파일. 오프라인으로도 진행 가능해야 합니다
    ⚠ 실습 시작 전 반드시 공지할 보안 3원칙
    • 지우고 올린다 — 고객 개인정보, 계약 금액, 미공개 사업 정보, 주민번호·연락처는 삭제하거나 가명 처리

    • 공유 범위를 확인한다 — 맞춤 봇·노트북을 만들었다면 공개 범위가 '나만'인지 확인
