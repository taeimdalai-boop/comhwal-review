💿 4장 ① 소프트웨어 분류 · 사용권 (단골)

분류 시스템 SW=운영체제(Windows·Linux)·언어 번역·유틸리티 / 응용 SW=워드·엑셀 등. 기기가 동작하려면 가장 핵심적인 시스템 SW = 운영체제(OS).
운영체제 목적 처리 능력(Throughput)↑ · 응답 시간↓ · 신뢰도↑ · 사용 가능도↑.
사용권 분류 프리웨어(무료 계속) · 셰어웨어(기능·기간 제한 후 구매 유도) · 트라이얼(상용을 기간만 체험) · 애드웨어(광고 대가 무료) · 공개 SW(오픈소스, 소스 공개) · 데모(홍보 맛보기) · 알파/베타(내부/공개 테스트) · 패치(오류 수정) · 번들(기기 구매 시 끼워주기).
시험: "정식 구매 유도 위해 기능·기간 제한 배포 = 셰어웨어". 번들·패치·프리웨어와 설명을 바꿔치기하는 보기가 정답.

🔁 4장 ② 언어 번역 · 번역 절차 · 객체 지향

컴파일러 vs 인터프리터 컴파일러=전체 일괄 번역·목적 프로그램 생성·실행 빠름(C·Java·COBOL). 인터프리터=한 줄씩 번역·즉시 실행·목적 프로그램 없음·실행 느림(BASIC·LISP·Python).
번역 절차(순서 그대로 출제) 원시 프로그램 → 컴파일러(번역) → 목적 프로그램 → 링커(연결) → 실행 모듈 → 로더(적재) → 실행. "링커=연결, 로더=적재" 역할이 함정.
객체 지향(OOP) 4대 특성=추상화·캡슐화·상속성·다형성("그룹화·구조화"는 특성 아님). Java=JVM 위에서 실행돼 운영체제에 독립적.
시험: "목적 프로그램을 생성하지 않는 번역기 = 인터프리터". OOP 특성에 "구조화"를 끼워 넣는 함정.

📶 5장 ① 통신망 · 토폴로지 · 네트워크 장비

통신망 범위 LAN(근거리·빠름) < MAN < WAN(광역). VAN=통신사 회선을 임차해 부가 서비스 제공·재판매. 무선랜 3요소=랜카드+AP+안테나.
전송 방향 단방향(라디오·TV) · 반이중(무전기 — 번갈아) · 전이중(전화 — 동시).
토폴로지 스타형=중앙 허브(고장 시 전체 마비) · 버스형=한 회선 공유 · 링형=원형 · 메쉬형=모두 연결(신뢰성 최고·비용 최대) · 트리(계층)형=분산 처리에 적합.
장비 리피터=약해진 신호 증폭·재생 / 허브=집선 / 브리지=LAN 연결(MAC) / 라우터=최적 경로(IP) / 게이트웨이=프로토콜 다른 망 연결 / 모뎀=디지털↔아날로그.
시험: "신호 복원·증폭 = 리피터", "범위는 LAN<MAN<WAN"(MAN이 WAN보다 넓다=오답).

🌐 5장 ② IP · 프로토콜 · 도메인 · WWW

IPv4 vs IPv6 IPv4=32비트·8비트씩 4부분·점(.)·10진수 / IPv6=128비트·16비트씩 8부분·콜론(:)·16진수, 주소 부족 해결·보안 강화·유니/멀티/애니캐스트.
프로토콜 TCP=신뢰성(순서·오류 제어)·전송 계층 / IP=주소·경로 지정 / DNS=도메인↔IP / DHCP=IP 자동 할당 / ARP=IP→MAC 변환.
도메인 호스트.기관.국가(www.snu.ac.kr). co(회사)·go(정부)·or(비영리)·ac(대학)·re(연구). 개인이 임의 설정 불가(KISA·ICANN 등록).
WWW·웹 언어 하이퍼텍스트/하이퍼링크로 문서 연결. URL=프로토콜://호스트[:포트]/경로. HTML5=추가 프로그램 없이 브라우저에서 멀티미디어 재생.
시험: "IP→MAC=ARP", "플러그인 없이 멀티미디어=HTML5", "IPv6가 느리다"는 오답.

📮 5장 ③ 전자우편 · 인터넷 서비스 · 신기술

이메일 기본 7비트 ASCII → 멀티미디어는 MIME로 인코딩 첨부. SMTP=발송(25) / POP3=수신·내려받기(110) / IMAP=서버 동기화(143). 주소="ID@호스트". CC=참조 공개, BCC=숨은 참조.
인터넷 서비스 쿠키=방문 정보 저장 / 포털=검색+메일+쇼핑 / 그룹웨어=협업 SW / 인트라넷=사내망(TCP/IP)·엑스트라넷=협력사 확장 / VOD·스트리밍.
신기술 RFID=전자 태그 무선 인식 / IoT=사물인터넷 / 클라우드·빅데이터·블록체인·NFT·메타버스. VR=완전 가상 / AR=현실+가상 덧입힘 / MR=상호작용 / XR=셋 포괄.
시험: "발송=SMTP·수신=POP3"(뒤바꾸면 오답), "전자 태그 무선 인식=RFID", AR·MR 설명 맞바꾸기 함정.

🎨 6장 ① 그래픽 데이터 · 처리 기법

비트맵 vs 벡터 비트맵(래스터)=픽셀 집합·확대 시 계단 현상·용량 큼(BMP·JPG·GIF·PNG) / 벡터=점·선의 수학 계산·확대해도 품질 유지·용량 작음(AI·WMF·SVG).
처리 기법(용어 매칭 단골) 렌더링=3D에 빛·명암·색·질감 부여 / 모델링=형태 제작(렌더링 전) / 안티앨리어싱=계단(앨리어싱) 완화 / 디더링=적은 색 섞어 새 색 / 모핑=한 이미지→다른 이미지 변형 / 인터레이싱=점진 표시.
시험: "3D에 질감·현실감=렌더링"(모델링·디더링과 구분), "계단 현상=앨리어싱".

🎬 6장 ② 동영상 · 압축 표준

이미지 형식 JPEG=정지 영상 손실 압축 / GIF=256색·무손실·애니메이션 / PNG=무손실·투명도(GIF 대체) / BMP=무압축·용량 큼.
사운드 WAV=원음·대용량 / MP3=손실 압축 / MIDI=연주 정보(음높이·길이·세기)만·용량 작음·실제 음/효과음 저장 불가.
스트리밍·코덱 스트리밍=다운로드하며 동시 재생(ram·wmv·asf)·서버→클라이언트 단방향. 코덱=압축(Coder)·복원(Decoder) 방식(DivX·H.264).
MPEG 규격 MPEG-1=비디오CD / MPEG-2=디지털 방송·DVD / MPEG-4=인터넷·모바일 / MPEG-7=멀티미디어 검색 / MPEG-21=제작~유통 통합.
시험: "받으며 동시 재생=스트리밍", "BMP는 압축 안 해 크다", "MIDI는 작다·실제 음 저장 불가"가 자주 나옵니다.

셰어웨어·프리웨어·번들을 헷갈려요

이름을 바꿔치기한 보기가 정답으로 자주 나와요.

셰어웨어=기능·기간 제한 후 구매 / 프리웨어=무료 계속 / 번들=기기 구매 시 끼워주기 / 패치=오류 수정.

4장 · 자주 틀림

인터프리터가 목적 프로그램을 만든다고 생각해요

인터프리터는 한 줄씩 번역·즉시 실행하며 목적 프로그램을 만들지 않아요(그래서 링커·로더 단계도 없음).

목적 프로그램 생성=컴파일러 / 미생성=인터프리터. "전체 일괄 번역 후 실행"은 컴파일러.

5장 · 자주 틀림

MAN이 WAN보다 넓다고 생각해요

범위 순서는 LAN < MAN < WAN이에요. MAN이 WAN보다 넓다는 설명은 오답.

LAN(근거리) → MAN(도시) → WAN(국가·대륙 광역).

5장 · 자주 틀림

IPv6가 IPv4보다 느리다고 골라요

IPv6는 128비트로 주소 부족을 해결하고 헤더를 간소화해 오히려 효율적이에요.

"IPv6=속도 느리다"는 틀린 보기. 보안 기능 내장·주소 확장성이 장점.

5장 · 자주 틀림

SMTP와 POP3의 방향을 바꿔 써요

SMTP=발송(보내기), POP3=수신(받기)인데 서로 바꿔 놓은 보기가 정답으로 나와요.

보내기=SMTP(25) / 받기=POP3(110)·IMAP(143). MIME=멀티미디어 첨부.

5장 · 자주 틀림

POP3가 멀티미디어를 재생한다고 생각해요

POP3는 서버의 메일을 내려받는 수신용 프로토콜일 뿐, 멀티미디어 재생과는 무관해요.

재생은 메일 클라이언트의 몫. POP3=수신 전용.

6장 · 자주 틀림

BMP가 압축돼서 용량이 작다고 생각해요

BMP는 압축하지 않는 형식이라 같은 이미지라도 GIF·JPG·PNG보다 용량이 커요.

BMP=무압축·용량 큼 / JPEG=손실 압축 / PNG=무손실·투명 지원.

6장 · 자주 틀림

MIDI가 실제 음을 저장해 파일이 크다고 생각해요

MIDI는 연주 정보(음높이·길이·세기)만 기록해 용량이 작고, 음성·효과음은 저장하지 못해요.

MIDI=연주 정보·작음 / WAV=원음·대용량 / MP3=손실 압축.

6장 · 자주 틀림

스트리밍을 쌍방향 통신이라고 생각해요

스트리밍은 서버 → 클라이언트 단방향 전송이라 "양방향 실시간 소통이 목적"은 오답이에요.

스트리밍=받으며 동시 재생(ram·wmv·asf), 단방향.

6장 · 자주 틀림

렌더링과 모델링·디더링을 바꿔 써요

3D에 빛·질감을 입혀 현실감을 주는 건 렌더링이에요. 모델링은 형태 제작, 디더링은 색 표현 보완.

렌더링=질감·현실감 / 모델링=형태 / 디더링=적은 색 혼합 / 모핑=변형.
