구분작동 방식업무에서의 의미
챗봇질문하면 답한다매번 새로 설명해야 함. 결과가 들쭉날쭉
업무형 AI정해진 자료와 기준으로 결과를 만든다같은 걸 넣으면 같은 품질이 나온다
에이전트목표를 받고 작업을 나누고 점검한다여러 단계를 매번 지시하지 않아도 된다
1고정 지시문
역할·포함·제외·형식·기준. 문서로 저장해 두고 복사해 쓴다
2입력 자료 위치
매번 바뀌는 자료를 어디에 어떤 이름으로 둘지 정한다
3검토 체크리스트
사람이 눈으로 볼 3~5개. 평가 프롬프트와 같은 문장
4결과물 보관 규칙
파일명과 저장 위치. 다음번 예시 자료가 된다

최종 산출물 · 내 업무 설계도

항목작성 예시 · 교육계획서 작성
1. 이 업무의 목적문의 후 3일 안에 제안 가능한 상태로 만들어 결재를 올리게 한다
2. 최종 사용 대상교육 담당자 → 결재권자. 결재권자는 목적·대상·시간·비용만 본다
3. AI에게 제공할 자료문의 메일 원문, 지난 계획서 2건, 표준 커리큘럼 표
4. AI가 수행할 작업요청 정리 / 누락 표시 / 확인 질문 / 시간 배분 / 초안 작성
5. 작업 순서분석 → 질문 → 반영 → 배분 → 초안 → 자체 점검 → 사람 검토
6. 결과물의 형식A4 2장. 개요 표 1개 + 시간표 1개 + 기대효과 5줄
7. 좋은 결과의 기준추가 질문 없이 공유 가능 / 시간 합계 일치 / 미확정은 '협의 예정'
8. 사람이 검토할 부분비용, 날짜, 강사 일정, 고객사 표기 — 그대로 쓰지 않는다
9. 반복 사용 구조고정 지시문은 저장 / 바뀌는 건 문의 메일뿐
!
