1=SUMIF(C2:C5,">=300000") → 1,200,000

3숫자 조건 — 검사한 범위 자체를 더할 때, 이상 · 이하 · 초과 · 미만에서 자주 사용
4인수 이름이 [ ]로 묶여 있으면 생략 가능

2조건이 세로 · 가로 양쪽에 있으면 혼합 참조
3결과가 이상하면 셀에서 F2를 눌러 범위가 밀렸는지 확인
4fx 인수 상자에서 보면 달러 표시를 찾기 쉬움

1=DSUM(A1:D5,"판매 금액",F1:G2) → 700,000
2DSUM · DAVERAGE · DCOUNT · DMAX · DMIN — 일반 함수 앞에 D
3데이터베이스는 필드명(머리글)까지 포함한 표 전체

1=DSUM(A1:D5,C1,F1:G2)
2=DSUM(A1:D5,"판매 금액",F1:G2)
3=DSUM(A1:D5,3,F1:G2) → 모두 700,000
4필기는 세 방법 모두 알아야 하고, 실기는 셀 선택이 편함
데이터베이스 함수

조건 범위 만들기

1필드명 + 조건 — 고급 필터 조건표와 같은 형식
2같은 행은 그리고(AND), 다른 행은 또는(OR)
3SUMIFS 계열의 조건 쌍은 기본적으로 그리고 · D 함수는 조건표 다른 행으로 또는도 표현
4SUMIFS는 채우기로 표를 만들기 쉬움 — 상황에 맞게 선택
데이터베이스 함수

D 함수 종류

1인수 세 개가 모두 같음 — 함수 이름만 바꾸면 됨
2완성한 수식을 복사해 이름만 DMAX → DMIN처럼 변경
3결과는 같은 표 · 같은 조건 범위로 계산
데이터베이스 함수

DCOUNT와 DCOUNTA

1DCOUNT — 필드에 숫자가 있는 셀만 셈
2DCOUNTA — 비어 있지 않은 셀을 셈 · 문자 포함
3“DCOUNT로 인원 수”라는 문제 → 숫자가 들어 있는 필드 선택
4빈 셀은 세지 않음
실기 적용

비율: 부분 ÷ 전체

1=SUMIF(A2:A5,"서울",C2:C5)/SUM(C2:C5) → 78.6%
2함수 중간에 연산자(/)를 넣어 연결할 수 있음
3수식은 구하는 순서대로 입력 — 부분 먼저, 전체 다음
4결과값은 약 0.7857 · 백분율 소수 첫째 자리 형식이면 78.6%
실기 적용

COUNTIFS와 DCOUNT 조건

1=COUNTIFS(A2:A5,"서울",C2:C5,">=300000") → 2
2D 함수 조건표 — 지역 아래 서울, 판매 금액 아래 >=300000 (같은 행)
3수식 안 조건은 큰따옴표, 조건표 셀은 따옴표 없이 입력
실기 적용

함수 중첩: 안쪽부터

1=AVERAGE(DMAX(A1:D5,"판매 금액",I1:I2),DMIN(A1:D5,"판매 금액",I1:I2))
2평균을 구하려면 최대 · 최소가 먼저 있어야 함
3DMAX 수식을 복사해 이름만 DMIN으로 바꿈
4쉼표로 이어 AVERAGE( ) 안에 넣어 완성
수학 함수

ROUND 계열: 자릿수

1양수 — 소수점 아래 자릿수 · 0 — 정수 · 음수 — 정수 부분
2-1이면 일의 자리가 0, -2이면 일 · 십의 자리가 0
3소수점을 기준으로 어느 자리까지 나타낼지 보고 자릿수를 정함
수학 함수

ROUNDUP과 ROUNDDOWN

1ROUNDUP — 버려지는 자리에 숫자가 있으면 0에서 먼 방향으로 올림
2ROUNDDOWN — 0에 가까운 방향으로 버림
3인수 순서는 모두 숫자, 자릿수
4원 단위 · 10원 단위 절삭에 실무에서도 사용
수학 함수

시험 지시문 읽기

1지시문의 결과 예시를 보고 자릿수를 정함
2백의 자리까지 → -2 · 소수 첫째 자리까지 → 1
3계산 후 반올림 → 안쪽 함수 먼저, ROUND( )로 감쌈
수학 함수

1=INT(B2/7)&"주 "&MOD(B2,7)&"일" → 6주 3일
2INT(숫자) — 그 숫자 이하의 가장 큰 정수로 내림(양수는 소수 부분을 버린 값)
3MOD(숫자, 나누는 수) — 나머지
4&로 숫자와 글자를 이어 붙임
수학 함수

MOD 활용: 홀짝 · 그룹 · 포장

1양의 정수 n으로 나누면 나머지는 0 ~ n-1 — n개 그룹
2홀수 · 짝수에 따라 값을 나누는 문제는 IF와 중첩해서 출제
3INT(몫) + MOD(나머지) — 몇 박스 · 몇 개 남는지
수학 함수

INT와 TRUNC 차이

1양수 — INT와 TRUNC 모두 소수점 아래를 버림
2음수 — INT는 더 작은 정수로 내림(-3.2 → -4), TRUNC는 소수만 제거(-3.2 → -3)
3POWER(2,10)과 2^10은 모두 1024 · ABS(-5)는 5

찾기 · 참조 함수

1세 가지 확인 — 시험에서는 보통 머리글 제외 · 첫 열 검색 · 절대 참조
